## 2. 동작 분기 정리

### 대기콜 클릭 시 (Mock 시나리오)
```
[대기콜 클릭]
    ↓
setIsDirectIncoming(false)
    ↓
setActiveScenario(scenario) ← Mock 시나리오 로드
    ↓
startRecording() ❌ 호출 안함
    ↓
[시나리오 카드 표시] ← 기존 동작 유지
```

### 다이렉트 콜 클릭 시 (실제 백엔드 연동)
```
[다이렉트 콜 클릭]
    ↓
setIsDirectIncoming(true)
    ↓
startRecording() ✅ 웹소켓 연결
    ↓
fetch('/api/v1/customers/random') ✅ 랜덤 고객 API
    ↓
[음성 입력] → [WebSocket] → [Whisper STT] → [RAG]
    ↓
[onmessage] → handleRagResult → [RAG 카드 표시]
```

## 테스트 방법

### 백엔드 준비
```bash
cd backend_dev
uvicorn app.main:app --reload
```

### 프론트엔드 실행
```bash
cd frontend_dev
npm run dev
```

### 테스트 시나리오

1. **대기콜 테스트 (Mock 데이터)**
   - 실시간 상담 페이지 접속
   - 8개 인입케이스 중 하나 클릭
   - → 기존 Mock 시나리오 카드 표시 확인

2. **다이렉트 콜 테스트 (백엔드 연동)**
   - 실시간 상담 페이지 접속
   - 통화 버튼(다이렉트 콜) 클릭
   - 마이크 권한 허용
   - 콘솔에서 확인:
     - `[WebSocket] 연결 성공`
     - `👤 랜덤 고객 정보 수신:`
     - `[RAG] 결과 수신:`
   - 음성 입력 → 칸반보드에 RAG 카드 표시
