## 1. 프로젝트 소개

### 1.1 개요

**CALL:ACT**는 카드사 상담 센터의 상담사를 위한 AI 기반 실시간 상담 지원 시스템입니다. 

STT(Speech-to-Text) 기술로 고객과의 통화 내용을 실시간으로 텍스트화하고, RAG(Retrieval-Augmented Generation) 기반 검색으로 관련 정보를 자동으로 추출하여 **칸반보드** 형태로 시각화합니다.

### 1.2 프로젝트명 의미

- **CALL**: 고객 전화 상담 (Customer Call)
- **ACT**: AI-powered Consultation Toolkit (AI 기반 상담 도구)

### 1.3 개발 배경

카드사 상담 센터에서는 다음과 같은 문제점이 있습니다:

1. **정보 검색 시간 과다**: 상담사가 고객 문의에 답변하기 위해 여러 시스템을 오가며 정보를 검색
2. **신입 상담사 교육 부담**: 방대한 약관과 규정을 모두 숙지하기 어려움
3. **상담 품질 편차**: 상담사 경험에 따라 답변 품질이 달라짐
4. **후처리 시간 과다**: 상담 종료 후 수동으로 요약 및 기록 작성

CALL:ACT는 이러한 문제를 AI로 해결하여 상담사의 업무 부담을 줄이고 고객 만족도를 높이는 것을 목표로 합니다.

## 2. 핵심 기능

### 2.1 실시간 상담 지원

#### 2.1.1 STT 기반 음성 인식
- 고객과의 통화 내용을 **실시간으로 텍스트 변환**
- 한국어 특화 음성 인식 엔진 활용
- 금융 전문 용어 최적화

#### 2.1.2 키워드 자동 추출 및 태깅
- 대화 내용에서 **핵심 키워드 자동 추출**
- 실시간 키워드 태깅 및 화면 표시
- 단어 사전 기반 정확도 향상

#### 2.1.3 RAG 기반 문서 검색
- 추출된 키워드로 **벡터 DB 검색**
- 관련도가 높은 문서 자동 추천
- pgvector를 활용한 고속 검색

#### 2.1.4 수평 슬라이딩 칸반보드
- **Step 1 → Step 2 → Step 3** 형태의 단계별 정보 제공
- 좌→우 슬라이딩 애니메이션으로 자동 전환
- 각 Step별 현재 상황 카드 + 다음 단계 카드 표시

### 2.2 AI 검색 어시스턴트

#### 2.2.1 GPT-4 기반 Q&A
- 상담사의 질문에 **즉시 AI 답변**
- 약관, 규정, 상담 사례 기반 답변 생성
- 출처(Source) 함께 제공하여 신뢰성 확보

#### 2.2.2 컨텍스트 기반 답변
- 현재 진행 중인 상담 맥락을 고려한 답변
- 이전 대화 히스토리 반영
- 고객 정보와 연계된 맞춤형 답변

### 2.3 상담 후처리 자동화

#### 2.3.1 AI 자동 요약
- 상담 내용 **자동 요약 생성**
- 주요 내용, 고객 요청사항, 처리 결과 구조화
- 요약문 수정 및 저장 기능

#### 2.3.2 유사 사례 추천
- 과거 상담 사례 중 **유사 케이스 자동 검색**
- 벡터 유사도 기반 추천
- 참고용 상담 가이드 제공

#### 2.3.3 Next Action 제안
- 후속 조치 사항 자동 제안
- 고객 재연락 필요 여부 판단
- 담당 부서 이관 추천

### 2.4 통계 및 관리

#### 2.4.1 실시간 대시보드
- 금일 상담 건수, 평균 상담 시간 등 **실시간 통계**
- 시나리오별 상담 분포 차트
- 상담사별 성과 모니터링

#### 2.4.2 관리자 기능
- 사원 관리 (등록, 수정, 삭제)
- 공지사항 관리
- 상담 이력 조회 및 검색

## 3. 주요 차별점

### 3.1 실시간 칸반보드 방식

기존 상담 시스템은 검색창에 키워드를 입력하여 문서를 찾는 방식이었지만, CALL:ACT는:

✨ **자동으로 관련 문서를 칸반보드에 표시**
- 상담사가 별도로 검색할 필요 없음
- Step별로 단계적 정보 제공
- 시각적으로 직관적인 UI

### 3.2 수평 슬라이딩 애니메이션

세로 누적 방식이 아닌 **수평 슬라이딩 방식**으로 Step 전환:

✨ **우→좌 슬라이딩 애니메이션**
- Step 1에서 Step 2로 부드럽게 전환
- 화면 공간 효율적 활용
- 상담 진행 상황 시각적 표현

### 3.3 약관 형식의 상세 정보

단순한 한 줄 요약이 아닌 **조항별 구체적인 약관 형식**:

✨ **fullText 약관 형식**
- 제1조, 제2조 등 조항별 구조화
- 구체적인 절차, 예시, 주의사항 포함
- 법적 근거 명시

### 3.4 HD → 4K 수준의 디자인

✨ **고급스러운 디자인**
- 메인 색상: #0047AB (블루), #FBBC04 (옐로우), 화이트/그레이
- 일관된 색상 체계
- 4K 디스플레이 최적화

## 4. 시스템 구성

### 4.1 전체 구조

```
┌─────────────────┐
│   고객 전화     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│   STT 시스템    │ ← 음성을 텍스트로 변환
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 키워드 추출     │ ← 핵심 키워드 자동 태깅
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ RAG 검색        │ ← pgvector 기반 벡터 검색
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 칸반보드 표시   │ ← Step별 카드 자동 배치
└─────────────────┘
```

### 4.2 주요 컴포넌트

#### 4.2.1 프론트엔드
- **React 18.3.1** + TypeScript
- **Tailwind CSS 4.1** (v4 최신 버전)
- **React Router 7.11** (라우팅)
- **Motion/React** (애니메이션)
- **Recharts** (차트 시각화)

#### 4.2.2 백엔드 (계획)
- **FastAPI** (Python)
- **PostgreSQL** (관계형 DB)
- **pgvector** (벡터 DB)
- **OpenAI API** (GPT-4, Embedding)

#### 4.2.3 인프라 (계획)
- **Docker** (컨테이너화)
- **Nginx** (리버스 프록시)
- **AWS/Azure** (클라우드 배포)
