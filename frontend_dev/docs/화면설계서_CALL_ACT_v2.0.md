## 1. 시스템 개요

### 1.1 프로젝트 소개

**CALL:ACT**는 카드사 상담사를 위한 **AI 기반 실시간 상담 지원 시스템**입니다.

**핵심 차별점 (v2.0 기준)**:
- ✅ **STT (Speech-to-Text)**: 실시간 음성 인식으로 고객과 상담사의 대화를 텍스트로 변환
- ✅ **칸반보드 + 검색 레이어**: 2가지 문서 표시 방식 (칸반보드 형태 / 검색 결과)
- ✅ **헤더 배지 시스템**: Phase 1-3 워크플로우 + [가이드 모드]/[교육 모드] 분리
- ✅ **시뮬레이션 교육**: 8개 시나리오 기반 실전 연습 + 튜토리얼 가이드
- ✅ **AI 기반 자동 요약**: 상담 종료 시 자동으로 상담 내용 요약 및 후처리
- ✅ **localStorage 기반 실시간 자동 저장**: 데이터 손실 방지

### 1.2 디자인 철학

1. **고급스러운 느낌**: HD~4K 해상도 최적화, 미니멀한 디자인
2. **일관된 색상 시스템**: 
   - **Primary**: #0047AB (블루) - 신뢰감, 전문성
   - **Secondary**: #FBBC04 (옐로우) - 활력, 강조
   - **Neutral**: 화이트, 그레이 계열 - 가독성
   - **상태 색상**: 
     - 진행중: #EA4335 (빨강)
     - 대기: #0047AB (파랑)
     - 완료: #34A853 (녹색)
3. **직관적인 UX**: 상담사가 빠르게 정보를 찾고 활용할 수 있도록 설계
4. **실시간성 강조**: 로딩, 애니메이션으로 시스템 상태 명확히 표시

### 1.3 핵심 기능 (v2.0)

| 기능 | 설명 | 업데이트 |
|------|------|---------|
| **실시간 상담** | STT로 대화를 텍스트화하고, 키워드 자동 감지 | ✅ Phase 1-3 워크플로우 |
| **칸반보드 + 검색 레이어** | 2가지 문서 표시 방식 (탭 전환) | v2.0 신규 |
| **시뮬레이션 교육** | 8개 시나리오 기반 실전 연습 | v2.0 신규 |

| **고객 정보 조회** | 전화번호 기반 고객 정보 및 최근 상담 이력 조회 | ✅ |
| **상담 후처리** | AI 기반 자동 요약 및 카테고리 분류 | ✅ |
| **대시보드** | 실시간 통계 및 성과 지표 (FCR, 평균 처리 시간 등) | ✅ |

## 3. 헤더 배지 시스템 (핵심 차별점)

### 3.1 개요

**헤더 배지 시스템**은 CALL:ACT만의 독창적인 상담 워크플로우 시각화 시스템입니다.

### 3.2 배지 종류

#### 1️⃣ **Phase 배지** (상담 진행 단계)

| Phase | 표시 | 색상 | 표시 위치 | 설명 |
|-------|------|------|----------|------|
| **Phase 1** | `통화 전 준비` | `bg-emerald-500` | `/consultation/live` (통화 전) | 대기콜 선택 + 사전 정보 확인 |
| **Phase 2** | `진행 중` | `bg-red-500` | `/consultation/live` (통화 중) | 실시간 상담 진행 중 |
| **Phase 3** | `후처리` | `bg-blue-500` | `/acw` | 상담 종료 후 기록 작성 |

**Phase 전환 흐름:**
```
Phase 1 (통화 전) → [통화 시작] → Phase 2 (진행 중) → [통화 종료] → Phase 3 (후처리) → [저장] → 완료
```

---

#### 2️⃣ **모드 배지** (교육/가이드)

| 모드 | 표시 | 색상 | 조건 | 설명 |
|------|------|------|------|------|
| **교육 모드** | `TRAINING MODE` | `bg-gradient-to-r from-purple-500 to-pink-500` | `isSimulationMode = true` | 시뮬레이션 시나리오 실행 중 |
| **가이드 활성** | `가이드` | `bg-yellow-400 animate-pulse` | `isGuideModeActive = true` | 튜토리얼 가이드 표시 중 |
| **가이드 비활성** | `가이드` (버튼) | `bg-emerald-400` | 교육 모드이지만 가이드 off | 가이드 재시작 버튼 |

---

#### 3️⃣ **상태 배지** (실시간)

| 배지 | 표시 | 색상 | 조건 | 설명 |
|------|------|------|------|------|
| **통화 중** | `통화 중 MM:SS` | `bg-gradient-to-r from-red-500 to-red-700` | `activeCallState.isActive = true` | 실시간 통화 시간 표시 |
| **후처리 대기** | `후처리 대기` | `bg-gradient-to-r from-blue-500 to-blue-700` | `pendingACW != null` | 후처리 페이지로 이동 유도 |

---

### 3.3 배지 표시 로직

#### 우선순위 (위에서 아래로)

```typescript
// 1순위: 통화 중 (최우선)
if (activeCallState && activeCallState.isActive) {
  return <Badge type="통화 중" time={currentCallTime} />;
}

// 2순위: 후처리 대기
if (pendingACW && !activeCallState) {
  return <Badge type="후처리 대기" />;
}

// 3순위: 교육 모드
if (isSimulationMode) {
  return <Badge type="교육 모드" />;
}

// 4순위: 가이드 (교육 모드 내에서)
if (isSimulationMode && isGuideModeActive) {
  return <Badge type="가이드 활성" />;
}

// 5순위: Phase 배지 (상담 페이지에서만)
if (location.pathname === '/consultation/live') {
  return <Badge type="Phase 1" />;
}
```

### 3.4 헤더 배지 코드 예시

```tsx
{/* ⭐ 교육 모드 배지 (전체 워크플로우에서 유지) */}
{isSimulationMode && (
  <button className="flex items-center gap-2 px-4 py-2 bg-gradient-to-r from-purple-500 to-pink-500 text-white rounded-lg shadow-lg">
    <span className="text-sm font-extrabold animate-text-shimmer tracking-wider hidden sm:block">
      TRAINING MODE
    </span>
  </button>
)}

{/* ⭐ 가이드 배지 (교육 모드이고 가이드 활성화 시) */}
{isSimulationMode && isGuideModeActive && (
  <span className="flex items-center gap-1.5 px-3 py-1.5 bg-yellow-400 text-gray-900 rounded-lg shadow-sm animate-pulse">
    <AlertCircle className="w-4 h-4" />
    <span className="text-xs font-bold">가이드</span>
  </span>
)}

{/* ⭐ 진행 중 상태 배지 */}
{activeCallState && activeCallState.isActive && (
  <button className="flex items-center gap-1.5 px-2.5 py-1.5 bg-gradient-to-r from-[#EA4335] to-[#D32F2F] text-white rounded-lg">
    <div className="w-1.5 h-1.5 bg-white rounded-full animate-pulse"></div>
    <span>{Math.floor(currentCallTime / 60)}:{String(currentCallTime % 60).padStart(2, '0')}</span>
  </button>
)}
```

##### 칸반보드 레이어 (기본)

**2컬럼 구조:**

| 컬럼 | 설명 | 카드 수 |
|------|------|---------|
| **현재 상황** (Current Situation) | 대기콜 카테고리에 맞는 즉시 처리 문서 | 2개 |
| **다음 단계** (Next Step) | 추가 처리가 필요한 문서 | 2개 |

**카드 구조 (ScenarioCard):**
```typescript
interface ScenarioCard {
  id: number;
  title: string;              // '카드 분실 신고 처리 절차'
  keywords: string[];         // ['#분실신고', '#즉시정지', '#재발급']
  content: string;            // 간단한 설명
  
  // 상담사 핵심 정보
  systemPath: string;         // '고객관리 > 카드관리 > 분실신고 > 즉시정지'
  requiredChecks: string[];   // 필수 확인 사항 (4개)
  exceptions: string[];       // 예외 케이스 (3개)
  regulation: string;         // '카드업무 취급요령 제34조'
  detailContent: string;      // 약관 전문 (전체 조문)
  
  time?: string;              // '처리 시간: 약 3-5분'
  note?: string;              // '분실 신고 후 72시간 내 부정 사용 보상 가능'
}
```

**카드 표시 우선순위:**
1. 🖥️ `systemPath` (시스템 처리 경로) - **배경색 강조**
2. ✅ `requiredChecks` (필수 확인 사항) - **최소 3개 표시**
3. ⚠️ `exceptions` (예외 사항) - **최소 2개 표시, 빨간색**
4. 📋 `title` + `content` (제목 + 설명)
5. 🏷️ `keywords` (키워드)

**[상세보기] 모달:**
- 전체 `systemPath`
- 전체 `requiredChecks`
- 전체 `exceptions`
- `regulation` (약관 제목)
- `detailContent` (약관 전문)

##### 검색 레이어 v2.0 신규

**활성화 조건:**
1. AI 검색 어시스턴트에서 검색 실행
2. 검색 결과가 있을 때 자동으로 `activeLayer = 'search'`로 전환

**레이아웃:**
- 칸반보드와 **완전히 동일한 2컬럼 구조**
- 검색 결과를 2차원 배열로 저장: `searchResults: ScenarioCard[][]`
- `searchResults[0]` → 컬럼 1 (왼쪽)
- `searchResults[1]` → 컬럼 2 (오른쪽)

**코드 예시:**
```typescript

// 검색 실행

  // ... AI 검색 로직
  const results = mockSearchResults; // ScenarioCard[]
  
  // 2차원 배열로 변환 (칸반보드와 동일한 구조)
  const column1 = results.slice(0, 2);
  const column2 = results.slice(2, 4);
  setSearchResults([column1, column2]);
```

## 5. 칸반보드 vs 검색 레이어 시스템

### 5.1 개요

**v2.0의 가장 큰 업데이트**: 실시간 상담 페이지에서 2가지 문서 표시 방식 제공

### 5.2 칸반보드 레이어 (기본)

#### 특징

- 대기콜 선택 시 **자동 생성**
- 2컬럼 구조 (현재 상황 + 다음 단계)
- 각 컬럼당 2개 카드 (총 4개)
- 상담사가 직접 편집 불가 (시스템이 자동 선택)

#### 데이터 소스

```typescript
// 대기콜 카테고리 → 시나리오 ID 매핑
const categoryToScenarioMap = {
  '분실/도난': 'scenario1',
  '한도': 'scenario2',
  '결제/승인': 'scenario3',
  '이용내역': 'scenario4',
  '수수료/연체': 'scenario5',
  '포인트/혜택': 'scenario6',
  '정부지원': 'scenario7',
  '기타': 'scenario8',
};

// 시나리오 데이터에서 카드 가져오기
import { getScenarioById } from '@/data/scenarios/mappings';

const scenario = getScenarioById(categoryToScenarioMap[selectedCategory]);
const currentSituationCards = scenario.steps[0].cards.slice(0, 2);
const nextStepCards = scenario.steps[1].cards.slice(0, 2);
```

### 5.3 검색 레이어 v2.0 신규

#### 특징

- AI 검색 어시스턴트에서 **검색 실행 시 활성화**
- 칸반보드와 **완전히 동일한 2컬럼 레이아웃**
- 검색 결과를 2차원 배열로 저장 (`searchResults: ScenarioCard[][]`)
- 상담사가 직접 검색 가능

#### 활성화 흐름

```
[AI 검색 어시스턴트] 검색어 입력: "해외 결제 차단 해제"
  ↓
[검색 실행] → Mock AI 응답 or 실제 API 호출
  ↓
[검색 결과] → ScenarioCard[] (4-8개 카드)
  ↓
[2차원 배열 변환] → searchResults = [[card1, card2], [card3, card4]]
  ↓
[activeLayer = 'search'] → 검색 레이어로 자동 전환
  ↓
[화면 표시] → 칸반보드와 동일한 2컬럼 레이아웃
```

#### 코드 예시

```typescript
const handleSearch = async (query: string) => {
  setIsSearching(true);
  
  // Mock AI 검색 (실제로는 API 호출)
  const mockResults: ScenarioCard[] = [
    { id: 101, title: '해외 결제 차단 해제 절차', keywords: ['#해외결제', '#차단해제'], ... },
    { id: 102, title: '해외 결제 한도 확인', keywords: ['#해외한도', '#결제한도'], ... },
    { id: 103, title: '해외 결제 수수료 안내', keywords: ['#해외수수료', '#환율'], ... },
    { id: 104, title: '해외 사용 등록 방법', keywords: ['#해외등록', '#사전등록'], ... },
  ];
  
  // 2차원 배열로 변환 (칸반보드와 동일한 구조)
  const column1 = mockResults.slice(0, 2);
  const column2 = mockResults.slice(2, 4);
  setSearchResults([column1, column2]);
  
  // 검색 레이어로 전환
  setActiveLayer('search');
  setIsSearching(false);
  
  // 검색 이력 저장
  const historyItem: SearchHistoryItem = {
    id: Date.now(),
    query,
    timestamp: new Date().toISOString(),
    resultCount: mockResults.length
  };
  setSearchHistory(prev => [historyItem, ...prev].slice(0, 20));
};
```

## 6. 시뮬레이션 교육 시스템

### 6.1 개요

**CALL:ACT의 독창적인 교육 시스템**: 실전과 같은 상담 환경에서 안전하게 연습

### 6.2 시뮬레이션 워크플로우

```
[시뮬레이션 페이지] → [시나리오 선택] → [시작 버튼 클릭]
  ↓
sessionStorage 저장:
  - simulationMode = 'true'
  - educationType = 'basic'
  - scenarioId = 'SIM-001'
  ↓
[실시간 상담 페이지] (/consultation/live)
  - 헤더 배지: [교육 모드] + [가이드]
  - Phase 1-3 워크플로우 동일
  - Mock 데이터 사용 (실제 고객 정보 없음)
  ↓
[후처리 페이지] (/acw)
  - 시뮬레이션 점수 계산
  - 피드백 제공
  ↓
[저장 후 완료] → [시뮬레이션 페이지]로 복귀
  - 시도 기록 추가 (recentAttempts)
  - 점수 통계 업데이트
```

---

### 6.3 가이드 모드 vs 교육 모드 분리

| 항목 | 가이드 모드 | 교육 모드 |
|------|------------|----------|
| **활성화 조건** | `localStorage.getItem('isGuideModeActive') = 'true'` | `sessionStorage.getItem('simulationMode') = 'true'` |
| **헤더 배지** | `[가이드]` (노란색, animate-pulse) | `[TRAINING MODE]` (보라색-핑크 그라데이션) |
| **튜토리얼 가이드** | ✅ 7단계 튜토리얼 표시 | ❌ 표시 안 함 (옵션) |
| **데이터** | 실제 고객 데이터 사용 가능 | Mock 데이터만 사용 |
| **목적** | 실제 상담 중 가이드 표시 | 시뮬레이션 연습 |

## 7. 데이터 흐름

### 7.1 상담 데이터 흐름 (Phase 1-3)

```
Phase 1: 통화 전 준비
  ↓ [대기콜 선택]
  - 대기콜 카테고리 확인
  - 시나리오 ID 매핑 (categoryToScenarioMap)
  - 시나리오 데이터 로드 (getScenarioById)
  - 칸반보드 카드 생성 (currentSituation, nextStep)
  - 고객 정보 로드 (Mock 또는 API)
  ↓ [통화 시작 버튼 클릭]
  - activeCallState 저장 (localStorage)
  - callStartTimestamp 기록
  - Phase 2 전환

Phase 2: 진행 중
  ↓ [실시간 상담]
  - STT 키워드 실시간 추가
  - AI 검색 어시스턴트 사용
  - 검색 레이어 활성화
  - localStorage 자동 저장 (1초마다)
  ↓ [통화 종료 버튼 클릭]
  - 확인 모달 표시
  - 통화 시간 계산 (duration_seconds)
  - pendingACW 저장 (localStorage)
  - Phase 3 전환
  - /loading 페이지 이동 (3초)
  - /acw 페이지 이동

Phase 3: 후처리
  ↓ [후처리 작성]
  - AI 상담 요약 생성
  - 유사 사례 검색
  - 감정 분석
  ↓ [저장 후 완료]
  - consultations 데이터에 추가
  - localStorage 저장
  - activeCallState, pendingACW 삭제
  - 완료 Toast 표시
  - /dashboard 페이지 이동
```
