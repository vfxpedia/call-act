# 🧪 콘솔 로그 테스트 가이드

## 🎯 목적
교육 모드에서 다이렉트 콜 진입 시 **Mock 데이터 연결이 완전히 제거**되었는지 콘솔 로그로 확인

---

## ✅ 정상 동작 시 콘솔 로그 순서

### **교육 모드 진입:**
```
🎓 교육 모드 진입 → 튜토리얼 완료 상태 초기화
🎓 교육 모드 진입 → 가이드 모드 비활성화
```

### **통화 버튼 클릭 (다이렉트 콜):**
```
🎓 교육 모드: 다이렉트 콜 시작 (시나리오 데이터 로드)
🎓 교육 시나리오 데이터 요청: SIM-001
🎓 Mock 시나리오 데이터 생성: 분실/도난
🎓 Mock Timeline 생성 완료: 8 개 이벤트
🎓 시나리오 타임라인 처리 시작: 8 개 이벤트
👤 고객 정보 설정: 김철수
```

### **Timeline 실행 (순차적):**
```
(1초 후)
💬 STT 추가: 안녕하세요.

(2.5초 후)
💬 STT 추가: [고객 대화]

(4초 후)
🔑 키워드 추가: [첫 번째 키워드]

(4.8초 후)
🔑 키워드 추가: [두 번째 키워드]

(6초 후)
📄 정보 카드 추가: [카드 제목]

(7.2초 후)
📄 정보 카드 추가: [카드 제목]

(타임라인 종료 후)
✅ 키워드 추출 완료
```

---

## ❌ 잘못된 동작 시 콘솔 로그 (수정 전)

### **이런 로그가 나타나면 안 됩니다:**
```
❌ 🎓 통화 버튼 클릭 → Phase 1 튜토리얼 자동 완료
❌ 🎓 교육 모드: 대기 콜 자동 선택 - 분실/도난
❌ 📞 대기콜 연결: 분실/도난
❌ 🎯 시나리오 매칭: 분실/도난 → SIM-001
```

**🚨 이 로그들은 `handleCallConnect()`가 호출되는 것을 의미합니다!**
→ Mock 데이터가 즉시 로드되는 잘못된 흐름입니다.

## 🧪 테스트 절차

### **Step 1: 개발자 도구 열기**
```
1. Chrome: F12 또는 Cmd+Option+I (Mac)
2. Console 탭으로 이동
3. "Preserve log" 체크 (페이지 이동 시에도 로그 유지)
```

### **Step 2: 교육 모드 진입**
```
1. 교육 시뮬레이션 페이지 이동
2. "불만 고객 응대" 선택
3. "시작하기" 클릭
4. Console에서 "🎓 교육 모드 진입" 로그 확인
```

### **Step 3: 통화 시작**
```
1. 우측 상단 통화 버튼 클릭
2. Console에서 로그 순서 확인:
   - ✅ "🎓 교육 모드: 다이렉트 콜 시작"
   - ✅ "🎓 교육 시나리오 데이터 요청"
   - ✅ "🎓 시나리오 타임라인 처리 시작"
```

### **Step 4: Timeline 확인**
```
1. 화면에서 순차적 표시 확인:
   - 1초: "안녕하세요" STT 텍스트
   - 2.5초: 고객 대화
   - 4초: 첫 키워드
   - 6초: 첫 정보 카드
   
2. Console에서 타이밍 일치 확인
```

## 🚨 문제 발견 시 조치

### **잘못된 로그가 나타나는 경우:**

**증상 1: "대기 콜 자동 선택" 로그**
```
원인: handleStartCall()에서 handleCallConnect() 호출
확인: /src/app/pages/RealTimeConsultationPage.tsx (1456줄)
해결: 교육 모드 분기가 제대로 동작하는지 확인
```

**증상 2: "가이드 모드 활성화" 로그**
```
원인: localStorage에 isGuideModeActive 플래그 남아있음
확인: 교육 모드 진입 시 초기화 로직 (748줄)
해결: localStorage.removeItem('isGuideModeActive') 실행 확인
```

**증상 3: Timeline 로그 없음**
```
원인: fetchScenarioData() 호출 안 됨
확인: handleStartCall() 교육 모드 분기 (1456줄)
해결: isSimulationMode 플래그 확인
```
