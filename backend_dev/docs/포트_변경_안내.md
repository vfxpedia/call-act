## 📌 변경 사항 요약

### 변경 내용
- **이전**: 호스트 포트 `5432` 사용
- **현재**: 호스트 포트 `5555` 사용
- **컨테이너 내부 포트**: 여전히 `5432` 사용 (변경 없음)
- **포트 매핑**: `호스트:5555 → 컨테이너:5432`

### 변경 이유
Windows 동적 포트 예약 범위(5416-5515)와 충돌하여 다음 오류 발생:
```
Error response from daemon: ports are not available: exposing port TCP 0.0.0.0:5432 -> 127.0.0.1:0: 
listen tcp 0.0.0.0:5432: bind: An attempt was made to access a socket in a way forbidden by its access permissions.
```

### 영향 범위
다음 설정에서 포트를 `5555`로 변경해야 합니다:
1. ✅ `docker-compose.yml` - 이미 수정 완료
2. ⚠️ `.env` 파일의 `DB_PORT` 값
3. ⚠️ DBeaver 연결 설정
4. ⚠️ 기타 DB 연결 코드 (있는 경우)

## 🔧 수정해야 할 파일

### 1. `.env` 파일 수정

**위치**: `backend_dev/app/db/scripts/.env` 또는 프로젝트 루트 `.env`

**변경 전**:
```env
DB_PORT=5432
```

**변경 후**:
```env
DB_PORT=5555
```

### 2. DBeaver 연결 설정 수정

1. DBeaver 실행
2. 기존 연결 선택 → 우클릭 → "편집"
3. **포트** 필드를 `5432`에서 `5555`로 변경
4. "테스트 연결" 클릭하여 확인
5. "저장" 클릭

## 🚀 Docker 컨테이너 재시작

변경사항을 적용하려면 Docker 컨테이너를 재시작해야 합니다:

### PowerShell 또는 CMD에서 실행

```powershell
# 또는 cmd에서
cd c:\SKN_19\project\4th\backend_dev\docker

# 기존 컨테이너 중지 및 제거
docker-compose down

# 새 설정으로 컨테이너 시작
docker-compose up -d

# 포트 매핑 확인 (0.0.0.0:5555->5432/tcp가 표시되어야 함)
docker ps
```

### 실행 확인

다음 명령어로 포트 매핑이 올바르게 설정되었는지 확인:

```powershell
docker ps --filter "name=callact_db_container" --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

**예상 출력**:
```
NAMES                  STATUS           PORTS
callact_db_container   Up X minutes     0.0.0.0:5555->5432/tcp
```

## 🔍 문제 해결

### 포트 5555도 사용할 수 없는 경우

만약 5555 포트도 예약되어 있다면:

1. **예약된 포트 확인**:
   ```cmd
   netsh interface ipv4 show excludedportrange protocol=tcp
   ```

2. **사용 가능한 포트 선택**:
   - 예약 범위 밖의 포트 선택 (예: 3306, 3307 이하, 또는 5555 이상)
   - `docker-compose.yml`의 `ports` 섹션 수정
   - `.env` 파일과 DBeaver 설정도 동일한 포트로 변경

### 여전히 연결이 안 되는 경우

1. Docker Desktop이 실행 중인지 확인
2. 컨테이너가 실행 중인지 확인: `docker ps`
3. 포트 매핑 확인: `PORTS` 컬럼에 `0.0.0.0:5555->5432/tcp` 표시 여부
4. 방화벽 설정 확인 (Windows Defender 방화벽)
5. 다른 프로세스가 5555 포트를 사용 중인지 확인:
   ```cmd
   netstat -ano | findstr :5555
   ```
