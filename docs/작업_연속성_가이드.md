### *_dev vs * (서브모듈) 차이

| 구분 | *_dev 폴더 | * 서브모듈 |
|------|-----------|-----------|
| **용도** | 개인 개발/실험 | 팀 공유 코드 |

| **커밋** | 메인 레포에 직접 커밋 | 별도 레포에 커밋 |

## 7. 알려진 이슈

### RAG 결과 빈 배열 문제
- **증상**: 다이렉트 콜 시 `currentSituation: []`, `nextStep: []` 반환
- **원인 추정**: Whisper STT가 음성을 인식하지 못함
- **확인 방법**:
  1. 백엔드 uvicorn 로그에서 STT 결과 확인
  2. WebSocket으로 전송되는 오디오 데이터 확인
- **상태**: 미해결 (백엔드 조사 필요)

### LFS 포인터 경고
- **증상**: `Encountered X files that should have been pointers, but weren't`
- **원인**: 서브모듈 레포에서 LFS로 커밋되지 않은 파일
- **해결**: 작업에 영향 없음, 무시 가능
- **영구 무시**: `git config submodule.data-preprocessing.ignore all`

## 8. Git 동기화 트러블슈팅

### conflict 발생 시 (stash pop 등)
```bash
# stash 버리고 최신 코드로
git restore --staged .
git restore .
git stash drop
git pull origin main
git lfs pull
```

### modified 파일 무시하기
```bash
# 특정 파일 변경 무시
git update-index --assume-unchanged "파일경로"

# 서브모듈 변경 무시
git config submodule.서브모듈명.ignore all
```

### 완전 초기화
```bash
git reset --hard HEAD
git submodule update --init --force --recursive
git lfs pull
```
