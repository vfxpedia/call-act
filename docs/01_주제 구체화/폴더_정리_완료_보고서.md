## ✨ 개선 효과

### 1. 가독성 향상
- 문서 종류별로 명확하게 분류
- 폴더명에 번호 부여 (01_, 02_, ...)로 순서 명확화

### 2. 버전 관리 개선
- 최신 버전만 메인 폴더에 유지
- 이전 버전은 archive로 분리하여 히스토리 보존

### 3. 협업 효율성
- 팀원들이 필요한 문서를 빠르게 찾을 수 있음
- 폴더 구조만 봐도 프로젝트 전체 흐름 파악 가능

### 4. 유지보수 편의
- 새로운 문서 추가 시 어디에 넣을지 명확함
- 각 폴더의 역할이 명확하여 관리 용이

## 🔍 주의사항

### 1. Archive 폴더의 파일들
- 삭제하지 말 것 (버전 히스토리 보존)
- 필요 시 언제든지 참조 가능
- 새로운 버전 작성 시 이전 버전을 archive로 이동

### 2. 파일명 규칙
- 새 파일 추가 시 기존 명명 규칙 준수
- 날짜: `MMDD_일련번호_문서명.md`
- 버전: `_v##.md` (예: `_v2.0.md`)

### 3. 폴더 추가 시
- 기존 번호 체계 유지 (01_, 02_, ...)
- 새로운 카테고리는 07_, 08_... 순으로 추가
