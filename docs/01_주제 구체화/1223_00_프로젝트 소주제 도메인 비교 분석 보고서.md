## 2. 도메인별 심층 분석

### 2.1 보험 도메인

### 현황 및 시장 동향

- NH농협손보: 2027년까지 AI 고객 상담센터 구축 추진 (연간 300만건 상담)
- 17개 보험사 CEO 설문: AI 챗봇·고객 보장 분석에 집중 투자 예정
- 보험기초서류를 RAG 방식으로 구축 검토 중 (2024~)

### 유즈 케이스

```
[상담사 시나리오]
고객: "암보험 가입했는데, 갑상선암도 보장되나요?"
→ AI가 해당 고객의 약관 문서 검색
→ 갑상선암 관련 조항 자동 추출
→ 상담사 화면에 "갑상선암: 소액암 분류, 진단금 10% 지급" 표시
→ 상담사가 정확한 정보로 즉시 응대

```

### 장점

- 약관, 상품설명서, 보험금 청구 사례 등 문서량 방대
- 상담 케이스가 다양하여 RAG 효과 극대화
- 실제 도입 사례 다수 (삼성화재-위커버, NH농협손보 등)
- 클레임 처리 시간 50% 단축, 고객만족도 40% 상승 사례 존재

### 단점/위험성

- **데이터 확보 어려움**: 약관은 공개되나 내부 상담 매뉴얼은 비공개
- **규제 리스크**: 금융감독원 준법감시, 불완전판매 방지 의무
- **문서 복잡도 높음**: 법률 용어, 조건부 조항 해석 난이도 상
- **할루시네이션 리스크**: 잘못된 보험금 안내 시 법적 책임 문제

### 데이터 확보 전략

| 데이터 유형 | 확보 가능성 | 출처 |
| --- | --- | --- |
| 보험약관 | ★★★★★ | 각 보험사 홈페이지, 금융감독원 |
| 상품설명서 | ★★★★☆ | 보험사 공시자료 |
| FAQ/자주묻는질문 | ★★★★☆ | 보험사 홈페이지 |
| 상담 스크립트 | ★☆☆☆☆ | 비공개 (협력 필요) |
| 보험금 청구 사례 | ★★☆☆☆ | 분쟁조정 사례집 |

### 2.2 카드 도메인

### 현황 및 시장 동향

- 신한카드: AI-SOLa 도입, RAG 구조로 상담정보 10만건 이상 정비
- AI 대체 상담률 목표: 2022년 23% → 2025년 50% (AI 5025 프로젝트)
- 삼성카드: AI 챗봇 '샘', 실시간 빅데이터 기반 AI 큐레이션 서비스

### 유즈 케이스

```
[상담사 시나리오]
고객: "포인트 플랜 카드 연회비가 얼마예요? 해외에서 쓸 때 수수료는요?"
→ AI가 실시간 음성→텍스트 변환
→ "포인트 플랜 카드", "연회비", "해외 수수료" 키워드 추출
→ 관련 문서 자동 검색 및 상담사 화면 표시
→ 상담사: "연회비 15,000원이며, 해외이용 시 1.5% 수수료가 부과됩니다"

```

### 장점

- 카드 혜택, 연회비, 이벤트 정보 등 **구조화된 데이터** 풍부
- 카드고릴라 등 비교 서비스에서 데이터 수집 용이
- 상담 유형이 상대적으로 정형화되어 있음
- 데이터 변경 주기가 명확 (카드 유효기간, 혜택 갱신 시점)

### 단점/위험성

- **데이터 빈번한 변경**: 혜택, 이벤트가 수시로 바뀜 → 지속 학습 필요
- **경쟁 심화**: 이미 각 카드사가 자체 AI 챗봇 운영 중
- **차별화 어려움**: 단순 FAQ 수준의 상담이 많음
- 신한카드 AI 상담사도 아직 정확도 이슈 존재 (연회비 합계 오답 사례)

### 데이터 확보 전략

| 데이터 유형 | 확보 가능성 | 출처 |
| --- | --- | --- |
| 카드 상품정보 | ★★★★★ | 카드사 홈페이지, 카드고릴라 |
| 혜택/이벤트 | ★★★★★ | 카드사 공식 페이지 |
| 연회비/수수료 | ★★★★★ | 여신금융협회 공시 |
| 이용약관 | ★★★★☆ | 카드사 홈페이지 |
| 상담 매뉴얼 | ★★☆☆☆ | 비공개 |

```

→ AI가 "사이판", "로밍 요금" 키워드 추출
→ KMS에서 해당 국가 로밍 요금표 검색
→ 상담사 화면에 "사이판 로밍: 일 11,000원 (데이터 무제한)" 표시

- 상담 유형이 명확: 요금제, 로밍, 부가서비스, 해지, 장애 문의
- 실시간 업데이트가 필요하지만 주기가 예측 가능 (요금제 출시 시점)

- 프로젝트로서 **차별화 포인트 찾기 어려움**

정부24, 국민신문고 등 공공서비스 민원 상담 시스템

### 유즈 케이스

```
[민원 상담사 시나리오]
민원인: "부동산 등기 이전하려면 어떤 서류가 필요한가요?"

→ 필요 서류 목록 + 수수료 + 처리 기간 자동 표시

- 사회적 가치 창출: 공공서비스 접근성 향상
- 멘토링에서 언급된 "공공기관 내부 고객" 개념과 일치

### 단점/위험성

### 3.2 의료/헬스케어 도메인

### 개요

병원 고객센터, 건강보험공단 상담, 의약품 정보 안내

### 유즈 케이스

```
[건강보험공단 상담사 시나리오]
민원인: "MRI 검사 건강보험 적용되나요? 본인부담금은 얼마인가요?"
→ AI가 "MRI", "건강보험", "본인부담금" 키워드 추출
→ 건강보험 급여 기준 문서 검색
→ "MRI: 급여 적용 시 본인부담 30~60%, 비급여 항목 존재" 표시

```

### 장점

### 단점/위험성

- **의료 정보 오류 시 심각한 결과** 초래 가능
- 개인 건강정보 처리 시 개인정보보호법 적용
- 의료법상 진단/처방 관련 제한

### 종합 평가: ⭐⭐⭐☆☆ (3.0/5) - 리스크 높음
