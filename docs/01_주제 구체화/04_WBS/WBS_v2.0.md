## 작업 분류 체계

본 WBS는 프로젝트의 특성을 반영하여 다음과 같은 8개 주요 작업으로 구성됩니다:

| 작업 ID | 주요 업무 | 설명 | 주요 산출물 |
|---------|-----------|------|-------------|
| 1 | 기획 및 요구사항 정의 | 프로젝트 목표 설정, 요구사항 분석 | 기획서, 요구사항 정의서, WBS |
| 2 | 데이터 수집 및 전처리 | 카드사 문서 수집, KMS 연동, RAG용 데이터 준비 | 수집 데이터, 전처리 문서, 벡터 DB |
| 3 | AI 모델 개발 | STT, RAG, 감정 분석, LLM 통합 | AI 모델, 학습 결과서, 테스트 보고서 |
| 4 | 시스템 설계 | 아키텍처, UI/UX, API 설계 | 시스템 구성도, 화면 설계서, API 명세서 |
| 5 | 기능 구현 | Frontend, Backend, 핵심 모듈 개발 | 웹 애플리케이션, 핵심 기능 모듈 |
| 6 | 인프라, 배포, 보안 | 인프라 구축, 배포, 보안 강화 | 배포 환경, 보안 점검 결과 |
| 7 | 테스트 및 검증 | 기능/성능/보안 테스트 | 테스트 결과서, 성능 보고서 |
| 8 | 최종 산출물 및 발표 | 문서화, 교육 자료, 발표 준비 | 매뉴얼, 발표 자료 |
