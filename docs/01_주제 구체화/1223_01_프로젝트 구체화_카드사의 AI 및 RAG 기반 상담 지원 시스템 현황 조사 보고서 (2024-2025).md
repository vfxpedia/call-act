       1.1 신한카드 - AI-SOLa (아이쏠라)

       출시 시기: 2025년 1월 23일

       시스템 개요:
       - 생성형 AI가 탑재된 상담 지원 시스템
       - 고객과 상담사 간의 대화를 실시간으로 분석하여 최적의 솔루션을 제시하는 상담원 지원 시스템

       핵심 기술:
       - STT (Speech-to-Text): 대화 내용을 실시간으로 텍스트로 전환
       - 소형언어모델 (sLLM): 일상 언어를 이해하고 맥락에 맞는 답변 생성
       - RAG (검색증강생성) 기술: 정확한 정보만을 검색하여 제공, 답변의 신뢰도와 속도 향상

       데이터 학습:
       - 1년 6개월간 개발
       - 10만 건 이상의 내부 상담 정보를 RAG 구조로 정비
       - 1만 3,000여 건의 고객 상담 데이터 반복 학습

       상담사 지원 기능:
       1. 실시간 대화 내용 텍스트 전환 및 시각화
       2. AI 기반 문의 내용 분석 및 요약
       3. 예상되는 추가 질문에 대한 맞춤형 답변 실시간 제공
       4. 신입 상담원을 위한 표준 응대 스크립트 제공
       5. AI 오류 대응을 위한 매뉴얼 동시 제공
       6. 상담 후 후속 업무 자동화

       향후 계획:
       - ChatGPT 등 대형언어모델(LLM)을 활용한 업그레이드 예정
       - 2024년 '금융분야 망분리 개선 로드맵'으로 생성형 AI 서비스 활용 혁신금융서비스 지정

       성과 지표:
       - AI 5025 프로젝트: 2025년까지 대고객 상담 커버리지 50% AI 대체 목표
       - 2022년 23% → 2023년 31% → 2025년 50% 목표

       2. RAG (Retrieval-Augmented Generation) 기술 적용 사례

       2.1 RAG 기술의 핵심 개념

       정의: 외부 문서 검색 + 출처 인용을 통해 최신성과 신뢰성을 확보하는 기술

       기본 동작 시나리오:
       1. 자연어 질문 입력
       2. 임베딩 및 검색
       3. 컨텍스트 선정
       4. 프롬프트 증강
       5. 응답 생성

       2.2 신한카드 AI-SOLa의 RAG 적용

       - 10만 건 이상의 내부 상담 정보를 RAG 구조로 정비
       - 고객 질문에 가장 정확하고 구체적인 답변을 생성할 수 있도록 필요한 정확한 정보만 검색 및 제공
       - 답변의 신뢰도와 속도 향상

       2.3 KB국민카드의 RAG 적용

       - 카드상품설명서, 약관 등 문서 참조
       - PDF, 표, 그림 등 각종 서식 정보를 온전하게 추출하는 지능형 문서처리 기술
       - 24시간 365일 정확한 금융 상담 제공

       3. 각 시스템의 주요 기능과 특징

       3.1 상담사 지원 시스템 vs 고객 대면 챗봇

       - 실시간 대화 분석 및 시각화

       - 표준 스크립트 제공으로 신입 상담원 지원
       - 후속 업무 자동화
       - 오류 대응 매뉴얼 제공

       고객 대면 챗봇 (예: 삼성카드 샘, KB국민카드 모두의 카드생활 메이트):
       - 고객이 직접 챗봇과 대화
       - 24시간 365일 자동 응대
       - 카드 신청, 조회, 상품 추천 등 자동화
       - 상담사 연결 전 1차 문의 처리

       - RAG 시스템: 내부 상담 정보시스템 10만 건+ 데이터 검색

       출력 계층:
       - 실시간 답변 생성
       - 시각화 대시보드
       - 표준 스크립트 제공
       - 후속 업무 자동화

       향후 업그레이드:
       - ChatGPT 등 대형언어모델(LLM) 도입 예정

       핵심 기술:
       - RAG (검색증강생성) 기술

       6. 현재 시스템의 한계점과 개선 필요 사항

       6.1 주요 한계점

       고객 이해 부족:
       - AI가 고객 요구를 이해하지 못한다는 응답 73.6%
       - 복잡한 문의나 감정적 상황 대응 미흡

       연결성 문제:
       - AI 상담 후 사람 상담사 연결 과정 불편 (50% 이상)
       - 고객들이 "상담 뺑뺑이"를 돈다는 불만

       신뢰성 및 정확성:
       - AI 응답 오류 발생 시 대응 체계 필요
       - 환각(Hallucination) 문제 - 잘못된 정보 생성 가능성

       고객 만족도:
       - 전반적 만족도 21.6%, 불만족 39.4%
       - AI 도입이 효율과 대응 속도는 높였지만, 신뢰와 고객 경험 개선은 과제

       6.2 개선 과제

       정확도 향상:
       - 대형언어모델(LLM) 도입 (ChatGPT 등)
       - RAG 기술 고도화로 최신 정보 반영
       - 지속적인 학습 데이터 업데이트

       고객 경험 개선:
       - AI와 상담사 간 원활한 전환 시스템 구축
       - 감정 인식 분석 강화 (신한은행 사례)
       - 복잡한 문의는 신속하게 상담사 연결

       거버넌스 및 윤리:
       - AI 거버넌스 체계 구축 (KB국민카드 사례)
       - AI 윤리 가이드라인 수립
       - 보안 및 개인정보 보호 강화

       업무 프로세스:
       - 단순 반복 상담은 AI, 고난이도 상담은 상담사 집중
       - 상담사 역량 강화 교육
       - AI 활용 업무 효율화

       7. 상담사 지원 기능 vs 고객 대면 챗봇 기능 비교

       7.1 상담사 지원 시스템 (Agent-Assist)

       대표 사례: 신한카드 AI-SOLa

       주요 기능:
       - 실시간 대화 분석 및 요약
       - 최적 답변 추천
       - 예상 질문 대비
       - 표준 스크립트 제공
       - 후속 업무 자동화
       - 매뉴얼 동시 제공 (오류 방지)

       장점:
       - 신입 상담원도 일관된 고품질 상담 가능
       - 상담 시간 단축
       - 오류 발생 시 상담원이 직접 대응 가능
       - 복잡한 문의 처리 효율 향상

       적용 영역:
       - 콜센터 상담원 지원
       - 실시간 음성/텍스트 상담
       - 복잡하고 전문적인 문의 처리

       7.2 고객 대면 챗봇 (Customer-Facing Chatbot)

       대표 사례: 삼성카드 샘, KB국민카드 모두의 카드생활 메이트

       주요 기능:
       - 24시간 365일 자동 응대
       - 단순 문의 즉시 처리
       - 카드 신청, 조회, 변경 등 업무 자동화
       - 맞춤형 상품 추천
       - 대기 시간 없이 즉시 응답

       장점:
       - 대기 시간 단축 (62%가 15분 초과 시 챗봇 선호)
       - 24시간 서비스 가능
       - 동시 다수 고객 처리
       - 단순 반복 문의 효율적 처리

       한계:
       - 복잡한 문의 이해 어려움
       - 고객 의도 파악 정확도 문제 (73.6%가 불만)
       - 감정적 상황 대응 미흡
       - 상담사 연결 전환 과정 불편

       7.3 하이브리드 모델 (미래 방향)

       통합 접근:
       - 단순 문의: AI 챗봇이 직접 처리
       - 중간 난이도: AI가 상담사 지원
       - 고난이도/감정적 상황: 즉시 상담사 연결

       기술 융합:
       - 감정 인식 분석 (신한은행 사례)
       - AI가 처리 가능 여부 판단 후 자동 라우팅
       - 고객 맥락 정보를 상담사에게 전달

       8. 실시간 문서 검색 기능 구현 방식

       8.1 RAG 기반 실시간 검색

       신한카드 AI-SOLa 방식:

       1. 데이터 준비:
         - 내부 상담 정보시스템 10만 건+ 데이터를 RAG 구조로 정비
         - 카드상품설명서, 약관, 매뉴얼 등 문서화
       2. 임베딩 및 벡터화:
         - 모든 문서를 벡터로 변환하여 검색 가능한 형태로 저장
         - 의미적 유사도 기반 검색 가능
       3. 실시간 검색 프로세스:
         - 고객 질문 → STT로 텍스트 전환
         - 질문 임베딩
         - 벡터 DB에서 관련 문서 검색
         - 관련 정보만 선별하여 컨텍스트 구성
         - LLM에 컨텍스트 + 질문 전달
         - 답변 생성
       4. 답변 제공:
         - 상담사에게 최적 답변 + 출처 문서 제공
         - 잘못된 답변 방지를 위한 매뉴얼 동시 표시

       8.2 KB국민카드 지능형 문서처리

       특징:
       - PDF, 표, 그림 등 복잡한 서식 정보 추출
       - 구조화된 데이터와 비구조화된 데이터 통합 처리
       - 카드상품설명서, 약관 등 전문 금융 문서 처리

       처리 과정:
       1. 문서 수집 및 전처리
       2. 지능형 OCR 및 구조 분석
       3. 의미 단위로 분할 (Chunking)
       4. 벡터 임베딩
       5. 검색 인덱스 구축
       6. 실시간 검색 및 답변 생성

       9.1 지속적 학습 (Continuous Learning)

       신한카드 방식:
       - 1만 3,000여 건의 고객 상담 데이터 반복 학습
       - 신규 상담 데이터 지속적으로 수집 및 학습
       - 내부 상담 정보시스템 업데이트 시 RAG 데이터베이스 자동 동기화

       9.3 금융권 AI 플랫폼 활용

       정부 지원 방안 (2025년):

       - PoC 환경에서 성능 테스트 후 적용

       9.4 업데이트 주기

       일반적 패턴:
       - 일일: 거래 데이터, 실시간 이벤트 정보
       - 주간: AI 모델 재학습, 고객 문의 패턴 분석
       - 월간: 상품 정보, 약관 변경사항
       - 분기: 대규모 모델 업데이트, 신규 기능 추가

       9.5 RAG의 최신성 보장

       장점:
       - 외부 문서 검색으로 최신 정보 즉시 반영
       - 모델 재학습 없이도 문서 업데이트만으로 최신 답변 가능
       - 출처 인용으로 신뢰성 확보

       한계 극복:
       - 문서 업데이트 프로세스 자동화
       - 변경사항 즉시 반영 시스템 구축
       - 버전 관리 및 롤백 기능

       11. 주요 시사점

       11.1 성공 요인

       1. RAG 기술의 핵심 역할: 최신 정보 반영과 신뢰성 확보의 핵심
       2. 하이브리드 모델: AI + 상담사 협업이 최적의 고객 경험 제공
       3. 지속적 학습: 주 단위 재학습으로 정확도 향상
       4. 거버넌스 체계: AI 신뢰성과 투명성 확보 필수

       11.2 개선 과제

       1. 고객 이해도 향상: 현재 73.6%가 AI가 이해 못한다고 응답
       2. 연결성 개선: AI-상담사 전환 프로세스 최적화 필요
       3. 신뢰성 강화: 환각 현상 방지, 정확도 지속 개선
       4. 고객 경험: 효율성뿐 아니라 만족도 향상 필요

       11.3 미래 방향

       1. LLM 통합: ChatGPT 등 대형 모델로 정확도 획기적 향상
       2. 감정 인식: 고객 감정 상태 파악 후 적절한 대응
       3. 음성 AI: STT/TTS 고도화로 자연스러운 음성 상담
       4. 개인화: 고객별 맥락 이해 및 맞춤형 서비스
