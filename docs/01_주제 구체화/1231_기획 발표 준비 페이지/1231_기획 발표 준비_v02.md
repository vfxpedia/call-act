1. 프로젝트 개요
    - 팀 소개

        팀명 : (가제)1팀

        서비스 명 **콜렉트 (CALL-ACT):**
        **Call + Correct(정확) + Collect(정보) + Act(행동).**
        슬로건 : "CALL-ACT는 카드 상담사가 흩어진 약관과 정책을 한눈에 확인하고 즉시 정확한 처리를 할 수 있도록 돕는 상담 지원 서비스입니다."

    - 프로젝트 소개

        고객 센터의 업무 효율성을 향상시키기 위한 **문서 검색 기반** LLM 플랫폼

    **서비스 기능**

    1. 고객 상담 중
        - 내부 문서 검색 기반 데이터를 이용하여 빠르게 답변 제공
            - 음성 통화 내용을 STT로 변환하여 자동으로 내부 문서 검색하여 답변 제공
            - 상담 내용 키워드를 LLM에 입력하면 내부 문서 검색하여 답변 제공
        - 고객 감정 상태 분석
    2. 고객 상담 종료 후
        - 고객과의 상담 종료 후 직원 피드백 및 케어
            - 상담 데이터 & 내부 매뉴얼(가이드라인) 문서 검색 기반 피드백
        - 상담 내용 요약하여 분류 및 후처리 자동화 (어떤 상담을 했는지 구체적인 정보 남기기)
        - 고객 감정 상태 분석 및 시각화를 피드백에 함께 제공 (분노/편안/만족 등)
            - 내부적으로 정량적 계산(몇 번 화냈는지 등) 후 그래프로 시각화
            - 상담사 본인이 보기 위함보다 동료나 상사의 평가 또는 매뉴얼 반영 지표로 활용
    3.  상담 데이터 시각화
        - 상담 현황 대시보드 제공

        ![상담 현황 대시보드](./내부%20문서/image.png)

    4. 신입 상담사 시뮬레이션 교육
        - 실제 고객의 배경과 정보(상담 사유 등)를 기반으로 페르소나를 생성하여, AI 임의 생성이 아닌 '다른 직원이 상대했던' 고객으로 시뮬레이션
        - 과거 사례 기반 시뮬레이션 교육 및 가이드 제공
        - 시뮬레이션 후 피드백

2. 프로젝트 분석 및 기대 효과
    - 차별점
        - 고객을 대체하는 AI가 아닌, 상담사를 지원하는 보조형 AI
            - 고객이 선호하는 건 여전히 인간 상담원
            - AI가 직접 고객을 응대하지 않고 상담사가 더 빠르고 정확하게 대응할 수 있도록 실시간으로 지원
            - 상담 품질을 유지하면서도 상담사의 업무 효율과 심리적 부담을 동시에 개선
        - 단순 키워드 검색을 넘어서는 STT + RAG 기반 문서 검색
            - 상담 내용을 음성(STT)으로 자동 인식하여 상담사가 직접 키워드를 입력하지 않아도 필요한 정보를 즉시 제공
            - 여러 내부 문서, 약관, 정책을 동시에 탐색해야 했던 기존 KMS의 한계를 개선
            - 상담 맥락을 이해한 RAG 기반 검색을 통해 상황에 맞는 핵심 정보만 요약 제공
            - 검색 부담을 줄여 응답 시간 단축 및 상담 집중도 향상
        - 매뉴얼 중심 교육을 넘어서는 실제 상담 사례 기반 시뮬레이션
            - 이론적 매뉴얼 제공이 아닌 실제 과거 상담 데이터를 기반으로 한 시뮬레이션 환경 제공
            - 다른 상담원이 실제로 응대했던 고객 사례를 바탕으로 한 현실적인 페르소나
            - 신입 상담원이 안전한 환경에서 반복 학습하며 응용력과 자신감을 향상

        - 내부 매뉴얼과 약관 원문을 근거로 "왜 할인이 안 되는지(실적 미충족 사유 등)" 논리적으로 설명하는 Deep Search 지향.
        - 단순 카드 상품 뿐만 아니라 정부 지원 정책(내일배움, 바우처, 세액공제) 데이터를 함께 학습시켜, 공공 데이터와 금융 데이터가 결합된 고차원 상담 지원.
        - 단순 업무 지원을 넘어, 감정 분석 시각화를 통한 멘탈 케어와 과거 실제 사례 기반 페르소나 시뮬레이션 교육 기능 탑재.
    - 기대효과

        https://www.mk.co.kr/news/it/11327962

        https://enterprise.kt.com/bt/mediareport/3376.do

        - 정량적 효과:
            - 평균 상담 처리 시간 단축 (정보 검색 시간 최소화).
            - 상담 후처리 시간 단축 (자동 요약 및 분류).
            - 신입 상담사 온보딩 기간 단축 및 교육 비용 절감.
            - KT 고객센터에서 '믿:음' AICC 솔루션 도입 후 상담 후처리 시간이 40%에서 3%로 단축된 사례가 있음
        - 정성적 효과:
            - 정확한 근거 제시를 통한 고객 신뢰도 상승 및 민원 감소.
            - 상담원의 감정 노동 부담 완화 및 업무 만족도 증대.
    - 성과 지표, 기능 목표 (*선택)
        - 기능 목표:
            - 실시간 RAG 어시스턴트:
                - STT(음성인식) 기반 상담 내용 실시간 분석.
                - 질문 의도 파악 후 관련 약관/매뉴얼 자동 팝업.
                - 카드고릴라 등 외부 비교 데이터와 내부 정책 데이터의 하이브리드 검색.
            - 스마트 후처리 & 감정 케어:
                - 상담 내용 자동 요약 및 카테고리(해지/발급/민원) 자동 분류.
                - 고객/상담원 감정 흐름 시각화 그래프 제공 (관리자 대시보드 연동).
            - AI 페르소나 시뮬레이션:
                - 과거 실제 상담 로그를 기반으로 생성된 '블랙컨슈머' 또는 '복잡한 문의 고객' 페르소나와 모의 상담 진행.
                - 상담 후 "A 규정을 빠뜨렸습니다" 식의 자동 피드백 제공.
        - 성과 목표:
            - 검색 정확도 (Retrieval Accuracy): 골든셋(Golden Set) 기준 상위 3개 문서 내 정답 포함률 n% 이상 목표.
            - 응답 속도 (Latency): 질문 입력 후 답변 생성까지 n초 이내.
            - 요약 품질 (Summarization): ROUGE Score 또는 LLM 평가 기준 '상' 등급 달성.
            - 감정 분석 정확도: 실제 상담원 평가와 n% 이상 일치.
