            - AI가 직접 고객을 응대하지 않고 상담사가 더 빠르고 정확하게 대응할 수 있도록 실시간으로 지원

            - 검색 부담을 줄여 응답 시간 단축 및 상담 집중도 향상
        - 고객 감정 상태까지 제공하는 후처리 보조 기능
            - 고객 감정 상태 분석 결과를 함께 제공하여 상담 품질 개선 및 내부 평가 지표로 활용 가능

            - 현재 상담 내역을 바탕으로 한 다음 안내 문구 자동 생성
        - 상담 현황 제공
            - 현재 통화 시간 제공
            - 고객 개인 히스토리 (과거 상담 내용, 고객 특성 등)
    2. 고객 상담 종료 후
        - 상담 내용 요약하여 분류 및 후처리 보조 (어떤 상담을 했는지 구체적인 정보 남기기)
            - 사용자가 편집 가능
            - 과거 유사 사례에 대해 진행했던 후처리 내용을 함께 표시
        - 고객과의 상담 종료 후 직원 피드백 및 케어
            - 상담 데이터 & 내부 매뉴얼(가이드라인) 문서 검색 기반 피드백
        - 고객 감정 상태 분석 및 시각화 (분노/편안/만족 등)
            - 내부적으로 정량적 계산(몇 번 화냈는지 등) 후 시간의 흐름에 따라 선 그래프로 시각화
        - 추가 메세지 제공 (고객 히스토리 저장용 데이터)
            - 동일 인입 케이스의 경우 : 고객A 의 Task가 하나의 시퀀스에서 끝나지 않은 경우 다음 Task에 대해서 저장 (예, 해외에서 카드 분실했을 경우 임시 카드 발급에 대한 안내(상담 종료) → 카드 배송 부서에 내용 전달(To do list) → Todolist 고객 히스토리에 저장.
    3. 신입 상담사 시뮬레이션 교육
        - 실제 고객의 배경과 정보(상담 사유 등)를 기반으로 페르소나를 생성하여, AI 임의 생성이 아닌 ‘다른 직원이 상대했던’ 고객으로 시뮬레이션
        - 과거 사례 기반 시뮬레이션 교육 및 가이드 제공
        - 시뮬레이션 후 피드백
    4. 상담 현황 대시보드 제공 (월별 아니고 현재 상담에 대한 현황)
        - 이관 내역
        - 공지사항
        - 상담 내역 리스트
        - 상담사 이름
        - 이번주 이슈사항 (이번주 가장 많이 들어온 문의)

- LLM의 신뢰성 평가에 대한 삼성 SDS 연구
    - 데이터셋(정답 데이터) 기반 평가
        - 정량적 평가에 용이하며 명확한 비교 대상이 존재
        - 고정된 상황에 대해서만 평가가 진행되므로 복합적이고 유연한 평가 불가
    - LLM을 활용한 평가
        - 자동화가 가능하고, 데이터 제약이 없음
        - 사람이 개입되지 않으므로 투명성 보장
        - 평가 진행 자체에 LLM이 활용되므로 비용 문제 발생
        - LLM 자체의 내부 동작을 사람이 알 수 없음
    - LLM 평가는 복합적이고 유연한 평가가 가능하고, 사람의 주관이 들어가지 않아 **충분히 인간에 의한 평가를 대체**할 수 있다고 보는 것이 본 연구의 논지

### 회원관리 기능 필요 여부

- 사내 프로그램이므로 회사에서 아이디를 생성해 직원에게 나누어주는 구조
    - 관리자 계정이 필요 → 관리자 계정은 어떻게 생성하는지?
- 관리자 전용 권한 필요 → 관리자 로그인 페이지를 따로 만들기보단 권한만 몇 개 추가되는 식으로
    - 관리자 회원 가입
    - 관리자 로그인
    - 직원 계정 생성
        - 사번, 연락처, 직급, 소속
    - 직원 계정 확인 → 직원 목록(내선번호나 역할)
- 직원 로그인 (사번과 비밀번호)
    - 비밀번호 변경 기능은 필요할듯

1. 모든 사람이 전부 회원가입 → 가입 과정에서 사원/관리자 구분
2. 관리자만 회원가입 → 직원은 관리자가 생성
3. 처음 회사에 넘겨줄 때 슈퍼 계정을 만들어서 넘겨줌 → 담당 관리자 관리자페이지에서 생성, 권한 설정 등 알아서 관리
