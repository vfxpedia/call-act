## 1. 프로젝트 개요

### 1.1 서비스명
**CALL-ACT** (Call + Correct + Collect = Act)

### 1.2 서비스 슬로건
"CALL-ACT는 카드 상담사가 흩어진 약관과 정책을 한눈에 확인하고 즉시 정확한 처리를 할 수 있도록 돕는 상담 지원 서비스입니다."

### 1.3 프로젝트 목적
카드사 상담사의 업무 효율성 향상을 위한 AI 기반 실시간 문서 검색 및 상담 지원 시스템 구축

## 2. 요구사항 명세

#### 2.1.1 기능 분류 체계 (팀 협업 버전)

본 요구사항은 다음과 같은 기능 모듈로 분류됩니다:

| 대분류 | 설명 | 요구사항 범위 |
|--------|------|---------------|

| **EDU (Education)** | 신입 교육, 시뮬레이션, 피드백 | FR-021 ~ FR-022, FR-047 ~ FR-054 |
| **DASH (Dashboard)** | 상담 내역, 이관 내역, 공지/이슈 관리 | FR-019 ~ FR-020, FR-055 ~ FR-060 |
| **SRCH (Search System)** | 문서 검색, 데이터 업데이트 | FR-003 ~ FR-005, FR-023 ~ FR-024 |

## 6. 제약사항 및 가정

### 6.1 제약사항

1. **데이터 접근**: 실제 카드사 내부 데이터 접근 불가 시 공개 데이터 및 시뮬레이션 데이터 활용
2. **개인정보 보호**: 모든 상담 데이터는 익명화 처리 필수
3. **비용**: 클라우드 비용, LLM API 비용 고려 필요
4. **학습 데이터**: 감정 분석 라벨링 데이터 확보 필요

### 6.2 가정

1. 상담사는 인터넷 연결된 환경에서 근무
2. 카드사 공개 문서 및 FAQ 크롤링 가능
3. STT 서비스는 한국어 금융 도메인 용어 지원
4. 상담사는 기본적인 PC 활용 능력 보유

## 7. 성공 기준

| 항목 | 성공 기준 | 측정 방법 |
