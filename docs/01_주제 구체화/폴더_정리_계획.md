## 정리 원칙

### 1. 최신 버전 우선
- 각 문서의 최신 버전만 메인 폴더에 유지
- 이전 버전은 `archive` 서브폴더로 이동

### 2. 기능별 폴더 분류
- 01_멘토링_회의록
- 02_프로젝트_조사_보고서
- 03_요구사항_명세서
- 04_WBS
- 05_기획_발표_준비
- 06_참고자료

### 3. 파일명 일관성
- 날짜 형식 유지: `MMDD_일련번호_문서명.md`
- 버전 표기: `_v##.md` (예: `_v2.0.md`)

### 4. 백업 파일 정리
- `_backup.md` 파일은 archive로 이동
- `.new` 파일은 archive로 이동
- 중복 파일 제거

## 실행 순서

1. ✅ **폴더 생성**
   - 01_멘토링_회의록
   - 02_프로젝트_조사_보고서
   - 03_요구사항_명세서 (기존 폴더 재활용)
   - 04_WBS (기존 폴더 재활용)
   - 05_기획_발표_준비
   - 06_참고자료
   - 각 폴더별 archive 서브폴더

2. ✅ **파일 이동 및 정리**
   - 멘토링 회의록 → 01_멘토링_회의록/
   - 조사 보고서 5개 → 02_프로젝트_조사_보고서/
   - 요구사항 관련 파일 → 03_요구사항_명세서/
   - WBS 관련 파일 → 04_WBS/
   - 기획 발표 관련 파일 → 05_기획_발표_준비/
   - PDF 및 참고자료 → 06_참고자료/

3. ✅ **백업 파일 아카이브**
   - 이전 버전 파일들을 각 폴더의 archive로 이동

4. ✅ **최종 검증**
   - 중복 파일 없는지 확인
   - 최신 파일들이 올바른 위치에 있는지 확인
   - archive 폴더에 이전 버전들이 잘 보관되었는지 확인

## 예상 효과

1. **가독성 향상**: 문서 종류별로 명확하게 분류
2. **버전 관리 용이**: 최신 버전과 이전 버전이 명확히 구분
3. **협업 효율성**: 팀원들이 필요한 문서를 빠르게 찾을 수 있음
4. **유지보수 편의**: 새로운 문서 추가 시 어디에 넣을지 명확함
