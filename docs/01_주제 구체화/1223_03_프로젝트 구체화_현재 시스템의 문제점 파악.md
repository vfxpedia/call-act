아래는 **상담사가 왜 현재 시스템에서 업무 부담을 겪는지**, 그리고 **우리 시스템(예: 상담 중 실시간 문서·약관·정책 조회 + 후처리 지원 RAG 시스템)이 왜 필요한지를 실제 연구/리포트 기반으로 분석한 내용입니다. *가능한 한 공개 자료·공신력 있는 문서/연구를 참고해 근거를 표기했습니다.*

## 1. 상담사 업무 고충: 현실 기반 문제 요약

### 1.1. 상담사 업무의 본질: *고강도 정보처리형 업무*

1.1.1. 상담사는 고객의 다양한 문제(약관, 정책, 혜택/이벤트, 분쟁) 관련 질문을 처리
→ 이는 **복잡한 도메인적 지식과 규정 숙지가 필수**인 작업
1.1.2. 정보가 정형화되어 있지 않고 여러 문서(KMS, 약관, FAQ, 정책)에서 찾아야 함
→ 단순 “스크립트”로 해결되지 않음
※ 콜센터 업무는 광범위한 *customer support knowledge work*이며, 많은 정보 소스를 동시에 처리해야 하는 경향이 있음(academic call center research). ([ResearchGate][1])

---

## 2. 상담사 업무 부담의 구조적 요인

### 2.1. **정보 과부하(Information Overload)**

2.1.1. 상담사 업무는 단순 대화 응대가 아니라 다수 **정보 소스 동시에 조회/활용**이 필요함
→ 스크립트/약관/정책/예외 규정/지원 케이스 등 여러 데이터 소스 교차 *실시간 의사결정*
2.1.2. 고객 문제마다 참조 문서가 다르며, 즉각적 해답을 찾기 어려움
→ 고객 대기 시간이 증가하고 상담사 스트레스가 가중됨

공통 연구도 지적:

* 상담/콜센터 업무는 *고도의 정보 처리 · 빠른 의사결정 · 대량 통화*를 동시에 수행해야 하는 고강도 업무임. ([Hiver][2])

---

### 2.2. **답변 표준성 및 규정 준수 준법 부담**

2.2.1. 특히 금융/카드 도메인에서는 **규정 및 약관 준수와 법적 책임**이 매우 높음
→ 오답/과장 안내는 민원·분쟁·법적 리스크로 직결
2.2.2. 내부 정책/약관이 자주 업데이트될 경우
→ 상담사는 최신 내용을 *항상 숙지·참조*해야 하는 부담이 발생

---

### 2.3. **감정 노동(Emotional Labor)**

3rd-party 연구에서도 콜센터 업무는 **정서적 노동강도(job demands)**가 큰 직무로 분류됨
→ 고객 불만을 처리하는 과정에서 감정적 소진(emotional exhaustion)이 주요 스트레스 요인으로 나타남. ([science.gov][3])

---

### 2.4. **후속 업무(After-Call Work) 비율 증가**

상담이 끝난 후 상담사는 아래와 같은 **후처리 업무**를 수행해야 함:

2.4.1. 상담 요약 기록
2.4.2. 분류/태깅 처리
2.4.3. CRM/티켓 시스템 업데이트
2.4.4. 고객 요구사항 이관·업무 처리 요청

이 과정은 반복적인 *문서 입력·검수·증거 첨부*가 필요하여 단순 통화보다 더 많은 시간과 집중도를 요구함.

## 3. KPI 관점에서 본 상담사 부담

### 3.1. 핵심 KPI 정의

3.1.1. *평균 처리 시간(AHT — Average Handle Time)*: 상담 1건을 마무리하는 데 걸리는 총 시간
→ 상담 내용 숙지 + 문서 검색 + 응답 + 후속 처리 포함
3.1.2. *First Contact Resolution(FCR)*: 첫 통화에서 문제를 해결하는 비율
→ 재통화 횟수 감소가 곧 상담사 부담·대기 시간 개선과 직결
※ FCR은 콜센터의 가장 중요한 운영 메트릭이며, 불완전 정보/불충분 문서 검색으로 낮아지는 경향이 있음. ([위키백과][4])

## 4. 상담사 업무 부담과 정보 접근 문제: 구체 예

### 4.1. **상담 중 다수 시스템/문서 확인 필요**

다음과 같은 사례가 상담 중 현실적으로 발생함:

4.1.1. 고객이 행사 혜택·포인트 적립 기준을 물음
→ 약관, 혜택표, 이벤트 조건을 모두 확인해야 함
4.1.2. 한도 변경·연체 정책 질문
→ 최신 규정, 금리 적용 기간, 준법 가이드라인 확인 필요
4.1.3. 분실신고 후 비용·보험 적용 여부 문의
→ 보험 약관 + 카드 정책 + 예외 규정 조합으로 답변 산출
→ 문서 검색이 지연될수록 고객 대기 시간 증가

이러한 *다중 정보 소스 접근*은 현재 대부분의 상담 지원 시스템에서 자동화되지 않아 상담사가 수동으로 처리하는 경우가 많음.

## 5. 상담사 지원 시스템의 필요성 (우리 시스템 관점)

### 5.1. **실시간 데이터 기반 정보 탐색 자동화**

5.1.1. 상담 중 고객 발화/텍스트를 기반으로
→ *즉시 관련 문서 검색/요약/근거 스니펫 제공*
→ 상담사가 *즉시 근거 기반 답변 마련*

이를 통해 상담사는

* 고객 대기 시간 감소
* 정확한 답변 제공률 상승
* 후속 처리 시간 절감
  등을 기대할 수 있음.

---

### 5.2. **후처리 자동화/구조화**

5.2.1. 상담이 끝난 후 시스템이
→ *요약/분류/티켓 자동 완성*
→ 상담사의 반복 입력 부담 감소

이것은 상담사의 “후속 처리 작업 부담”을 크게 낮출 수 있는 기능적 요건임.

## 7. 논리적 결론

7.1. **카드 상담사는 정보 탐색 + 규정/약관 숙지 + 감정 노동 + 후처리까지 모두 수행해야 하는 복합 업무 구조**임
→ 이는 단순 FAQ 조회보다 훨씬 고도화된 지식형 작업임.

7.2. **우리 시스템이 필요한 이유**

* 실시간 *문서 검색/요약/정답 제시* 기능이 없다면 상담사의 처리 시간(특히 AHT)은 높아질 수밖에 없음.
* 후속 입력 부담 자동화가 없다면 상담사는 휴식 없이 반복 입력/정합 검증 작업을 수행해야 함.
  → 정확도·효율성·상담사 만족도 측면에서 모두 개선 여지가 큼.
