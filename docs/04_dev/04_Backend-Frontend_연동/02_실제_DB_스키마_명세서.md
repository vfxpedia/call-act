## 개요

이 문서는 **실제 Backend DB 구조**를 프론트엔드 개발자에게 전달하기 위해 작성되었습니다. 현재 프론트엔드에서 사용 중인 Mock 데이터(`mockData.ts`, `scenarios.ts`)와 실제 DB 구조 간의 매핑 정보를 제공합니다.

### 데이터베이스 환경
- **DBMS**: PostgreSQL 16+
- **Extensions**:
  - `pgvector` - 벡터 유사도 검색 (RAG)
  - `pg_trgm` - 텍스트 패턴 매칭
- **벡터 차원**: 1536 (OpenAI `text-embedding-3-small`)
- **인코딩**: UTF-8
- **타임존**: Asia/Seoul (KST)

## 1. 데이터베이스 구조 개요

### 1.1 논리적 데이터베이스 구분 (3개 영역)

```
CALL:ACT Database
├── 1. 카드 정보 DB (Card Information)
│   ├── card_products        - 카드 상품 마스터
│   ├── card_benefits        - 카드 혜택 상세
│   ├── fee_info            - 수수료 정보
│   ├── point_policy        - 포인트 정책
│   ├── promotions          - 프로모션 정보
│   └── customer_cards      - 고객-카드 연결
│
├── 2. 서비스 가이드 DB (Service Guide)
│   ├── notices                    - 공지사항 (+ 벡터 임베딩)
│   ├── frequent_inquiries         - 자주 찾는 문의
│   ├── inquiry_view_log           - 문의 조회 로그
│   └── service_guide_documents    - 서비스 가이드 (+ 벡터 임베딩)
│
└── 3. 상담 사례 DB (Consultation Cases)
    ├── employees                    - 직원(상담사) 정보
    ├── consultations               - 상담 마스터
    ├── consultation_transcripts    - 상담 전문 (STT)
    ├── consultation_summaries      - 상담 요약
    ├── consultation_feedback       - 감정 분석/피드백
    ├── stt_keywords               - STT 키워드
    ├── consultation_documents      - 상담 문서 (+ 벡터 임베딩)
    ├── training_scenarios         - 교육 시나리오
    ├── scenario_scripts           - 시나리오 스크립트
    ├── scenario_evaluation_criteria - 평가 기준
    ├── scenario_attempts          - 시나리오 시도 기록
    ├── best_practices             - 우수 상담 사례
    └── keyword_dictionary         - 키워드 사전
```

## 3. 테이블 스키마 상세

### 3.1 employees (직원/상담사)

```sql
CREATE TABLE employees (
  id            VARCHAR(50) PRIMARY KEY,  -- 'EMP-001'
  name          VARCHAR(100) NOT NULL,
  email         VARCHAR(100) UNIQUE,
  role          VARCHAR(50),              -- '상담사', '매니저', '관리자'
  department    VARCHAR(100),             -- '상담1팀', '상담2팀', 'IT'
  hire_date     DATE,
  status        status DEFAULT 'active',

  -- 성과 지표 (DB에서 자동 계산됨)
  consultations INTEGER,                  -- 상담 건수
  fcr           INTEGER,                  -- FCR 비율 (0-100)
  avgTime       VARCHAR(10),              -- 평균 상담 시간 'MM:SS'
  rank          INTEGER,                  -- 성과 순위

  created_at    TIMESTAMP DEFAULT NOW(),
  updated_at    TIMESTAMP
);
```

| `name` | `name` | VARCHAR(100) | - |

### 3.2 consultations (상담 마스터)

```sql
CREATE TABLE consultations (
  id               VARCHAR(50) PRIMARY KEY,  -- 'CS-20250105-1432'
  customer_id      VARCHAR(50) NOT NULL,     -- 외부 시스템 참조 (FK 없음)
  agent_id         VARCHAR(50) NOT NULL,     -- FK → employees.id
  status           consultation_status DEFAULT 'in_progress',
  category         consultation_category NOT NULL,
  title            TEXT,                     -- '카드 분실 신고 및 재발급 요청'
  call_date        DATE NOT NULL,
  call_time        TIME NOT NULL,
  call_duration    VARCHAR(20),              -- '5:23' 형식
  fcr              BOOLEAN,                  -- First Call Resolution
  is_best_practice BOOLEAN DEFAULT false,
  quality_score    INTEGER,                  -- 0-100
  created_at       TIMESTAMP DEFAULT NOW(),
  updated_at       TIMESTAMP,

  FOREIGN KEY (agent_id) REFERENCES employees(id)
);
```

**Frontend Mock 데이터 매핑** (`mockData.ts` → `consultations`):

| Mock 필드 | DB 컬럼 | 타입 | 비고 |
|-----------|---------|------|------|
| `id` | `id` | VARCHAR(50) | 'CS-20250105-1432' |
| `agent_id` | `agent_id` | VARCHAR(50) | FK → employees |
| `customer` | `customer_id` | VARCHAR(50) | 고객명이 아닌 ID |
| `category` | `category` | ENUM | DB는 영문 ENUM |
| `status` | `status` | ENUM | '완료'→'completed' 등 |
| `content` | `title` | TEXT | 상담 제목 |
| `datetime` | `call_date` + `call_time` | DATE + TIME | 분리 저장 |
| `duration` | `call_duration` | VARCHAR(20) | - |
| `isBestPractice` | `is_best_practice` | BOOLEAN | - |
| `fcr` | `fcr` | BOOLEAN | - |
| `memo` | - | - | **별도 테이블** (consultation_summaries) |

### 3.3 consultation_documents (상담 문서 + VectorDB)

```sql
CREATE TABLE consultation_documents (
  id                  VARCHAR(50) PRIMARY KEY,  -- 'DOC-CONSULT-001'
  consultation_id     VARCHAR(50),              -- FK → consultations.id
  document_type       VARCHAR(50),              -- 'past_consultation', 'training_scenario'
  category            consultation_category NOT NULL,
  title               VARCHAR(300) NOT NULL,
  content             TEXT NOT NULL,
```

### 3.8 keyword_dictionary (키워드 사전)

```sql
CREATE TABLE keyword_dictionary (
  id               SERIAL PRIMARY KEY,
  keyword          VARCHAR(100) NOT NULL,    -- 정규 형태
  category         VARCHAR(100) NOT NULL,
  priority         INTEGER DEFAULT 5,         -- 1-10
  urgency          VARCHAR(20) DEFAULT 'medium',  -- 'high', 'medium', 'low'
  context_hints    TEXT[],                   -- 컨텍스트 힌트
  weight           DECIMAL(3,2) DEFAULT 1.0, -- 카테고리 내 가중치
  synonyms         TEXT[],                   -- 동의어 배열
  variations       TEXT[],                   -- 변형 배열
  compound_patterns JSONB,                   -- 복합 패턴
  ambiguity_rules  JSONB,                    -- 모호성 해소 규칙
  usage_count      INTEGER DEFAULT 0,        -- RAG 검색 시 증가
  created_at       TIMESTAMP DEFAULT NOW(),
  updated_at       TIMESTAMP,

  UNIQUE(keyword, category)
);
```

```sql
  emotion_start            emotion_type,    -- 초반 감정

  emotion_end              emotion_type,    -- 후반 감정
  quality_score            quality_rating,  -- '상/중/하' → 'high/medium/low'
  processing_time_score    INTEGER,         -- 0-100
  gratitude_score          INTEGER,         -- 감사 표현 비율
  emotion_shift_score      INTEGER,         -- 감정 전환 점수
  manual_compliance_score  INTEGER,         -- 매뉴얼 준수 점수
  created_at               TIMESTAMP DEFAULT NOW(),

  FOREIGN KEY (consultation_id) REFERENCES consultations(id)
);
```

### 4.2 벡터 검색 쿼리 예시

```sql
-- 유사도 기반 문서 검색
SELECT
  id,
  title,
  content,
  keywords,
  1 - (embedding <=> query_embedding) AS similarity
FROM consultation_documents
WHERE embedding IS NOT NULL
ORDER BY embedding <=> query_embedding
LIMIT 4;
```
