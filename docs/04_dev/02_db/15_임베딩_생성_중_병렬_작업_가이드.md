- ✅ Step 1: 데이터 변환 완료

## 임베딩 생성 중 병렬 작업 가능 여부

### 가능한 작업

임베딩 생성은 네트워크 I/O 중심 작업이므로, 다음 작업들을 병렬로 진행할 수 있습니다:

1. ✅ **DB 스키마 확장** (빠름, 약 5-10분)
2. ✅ **Docker 컨테이너 실행 확인** (빠름, 약 1-2분)
3. ✅ **Cloudflare Tunnel 설정 준비** (독립적, 약 5-10분)
4. ✅ **문서 작성 및 검토** (독립적)

### 주의사항

- 임베딩 생성은 OpenAI API 호출을 많이 하므로 네트워크 대역폭 사용
- 하지만 로컬 작업(DB 스키마 생성, Docker 설정)은 병렬로 진행 가능
- Cloudflare Tunnel 설정도 네트워크 작업이지만 임베딩과는 독립적

---

## 병렬 작업 순서

### 작업 1: Docker 컨테이너 실행 확인 및 DB 스키마 준비

**목적**: 임베딩 생성 완료 후 즉시 DB 적재할 수 있도록 준비

```bash
# 1. Docker 컨테이너 실행 확인
docker ps
# callact_db_container가 실행 중이어야 함

# 2. Docker 컨테이너가 없으면 실행
cd backend_dev/docker
docker-compose up -d

# 3. DBeaver 연결 확인 (로컬)
# Host: localhost, Port: 5432, Database: callact_db
# Username: callact_admin, Password: callact_pwd1
```

**예상 소요 시간**: 약 1-2분

---

### 작업 2: DB 스키마 확장 (테디카드 데이터용)

**목적**: 테디카드 데이터를 적재할 수 있는 테이블 구조 생성

**현재 상태**:
- ✅ 기본 스키마 (`db_setup.sql`): `employees`, `consultations`, `consultation_documents` 테이블 존재
- ❌ 테디카드 테이블: `service_guide_documents`, `card_products`, `notices` 테이블 필요

**스키마 확장 방법**:

**방법 1: DBeaver 사용 (권장)**
1. DBeaver에서 `callact_db` 연결
2. SQL 편집기 열기
3. `backend_dev/app/db/scripts/02_setup_tedicard_tables.sql` 파일 내용 복사/붙여넣기
4. 실행 (F5 또는 실행 버튼)

**방법 2: psql 명령어**
```bash
psql -h localhost -U callact_admin -d callact_db -f backend_dev/app/db/scripts/02_setup_tedicard_tables.sql
```

**생성되는 테이블**:
- `card_products`: 카드 상품 마스터
- `service_guide_documents`: 서비스 가이드 문서 + RAG 검색용 VectorDB
- `notices`: 공지사항

**생성되는 Enum 타입**:
- `card_type`: credit, debit
- `brand_type`: visa, mastercard, amex, unionpay
- `notice_category`: system, service, emergency
- `notice_priority`: normal, important, urgent

**확인**:
```sql
-- DBeaver에서 실행
SELECT table_name FROM information_schema.tables 
WHERE table_schema = 'public' 
ORDER BY table_name;

-- 필요한 테이블 확인:
-- - card_products
-- - service_guide_documents
-- - notices
-- - employees (이미 존재)
-- - consultations (이미 존재)
-- - consultation_documents (이미 존재)
```

**예상 소요 시간**: 약 5-10분

---

### 작업 3: Cloudflare Tunnel 설정 준비

**목적**: 팀원들이 DBeaver로 DB에 연결할 수 있도록 원격 접근 설정

**참고 문서**: `docs/04_dev/02_db/스텝1_DB_설치_및_적재/20260111_07_Cloudflare_Tunnel_DB_연결_가이드.md`

**준비 사항**:
1. Cloudflare 계정 필요 (무료 계정 가능)
2. cloudflared 설치 필요
3. Named Tunnel 생성 (고정 URL용)

**예상 소요 시간**: 약 5-10분

**주의**: 실제 설정은 임베딩 생성 완료 후 DB 적재 전에 완료하면 됨

**권장 방법**: Named Tunnel 사용 (고정 URL)

---

## 권장 작업 순서

### 즉시 가능한 작업 (임베딩 생성 중)

1. **Docker 컨테이너 확인/실행** (1-2분)
   ```bash
   docker ps
   # 없으면: cd backend_dev/docker && docker-compose up -d
   ```

2. **DB 스키마 확장** (5-10분)
   - DBeaver에서 `02_setup_tedicard_tables.sql` 실행
   - 또는: `psql -h localhost -U callact_admin -d callact_db -f backend_dev/app/db/scripts/02_setup_tedicard_tables.sql`
   - 테이블 생성 확인

3. **Cloudflare Tunnel 설정 문서 검토** (5분)
   - 기존 문서 확인
   - 설정 방법 이해
   - 필요 시 실제 설정 (임베딩 완료 후에도 가능)

### 임베딩 생성 완료 후 작업

1. **임베딩 생성 확인**
   ```bash
   # 체크포인트 확인
   python -c "import json; cp = json.load(open('data-preprocessing_dev/preprocessing/output/embedding_checkpoint.json', 'r', encoding='utf-8')); print(f'처리 완료: {cp.get(\"processed_count\", 0)}/{cp.get(\"total_documents\", 0)}')"
   ```

2. **출력 파일 확인**
   - `data-preprocessing_dev/preprocessing/output/teddycard_service_guides_with_embeddings.json`
   - `data-preprocessing_dev/preprocessing/output/teddycard_card_products_with_embeddings.json`
   - `data-preprocessing_dev/preprocessing/output/teddycard_notices_with_embeddings.json`

3. **DB 적재** (우선 진행)
   - enriched 파일(with_embeddings.json)에서 DB로 적재
   - 적재 스크립트 필요 (향후 작성)
   - **목적**: 데이터를 DB에 저장하여 팀원들이 접근할 수 있도록 준비

4. **Cloudflare Tunnel 설정 완료** (DB 적재 후 진행)
   - 팀원 연결 가능하도록 설정
   - **목적**: 팀원들이 DBeaver로 DB에 연결할 수 있도록 원격 접근 설정
   - **주의**: DB 적재가 완료된 후에 설정하면 팀원들이 즉시 데이터를 확인할 수 있음
