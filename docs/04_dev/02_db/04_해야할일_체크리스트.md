   - `load_hana_to_db.py` 실행

## 📝 참고 사항

### 환경 변수 Path 설정 (필요한 경우)

**Windows**:
1. 시스템 속성 → 고급 → 환경 변수
2. 시스템 변수 → Path 편집
3. 다음 경로 추가:
   - `C:\Users\[사용자명]\anaconda3\Scripts`
   - `C:\Users\[사용자명]\anaconda3\envs\final_env\Scripts`

**확인 방법**:
```bash
# PowerShell
python --version
conda --version
```
