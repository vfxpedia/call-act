## 3. 유사도 점수 분석

### 3.1 점수 범위 설명

**Cosine Similarity 점수 기준**:
- 0.8 이상: 매우 유사 (거의 동일한 의미)
- 0.6-0.8: 유사 (관련성 높음) ⭐ 현재 범위
- 0.4-0.6: 보통 (관련성 있음)
- 0.4 미만: 덜 유사

### 3.2 점수가 0.6 정도인 이유

1. **짧은 쿼리**: "카드 분실 신고"는 매우 짧은 문구
2. **문서 길이**: 실제 문서는 더 긴 내용을 포함
3. **자연스러운 범위**: OpenAI embedding에서 0.6-0.7도 충분히 관련성이 있는 수준

### 3.3 검색 정확도

**검색 결과 분석**:
- 상위 5개 결과 모두 "도난/분실 신청/해제" 카테고리로 정확하게 검색됨
- 시스템이 의도한 대로 동작하고 있음을 확인

## 5. 환경 변수 관리

### 5.1 .env 파일 구조

**프로젝트 루트** (메인 관리):
- `.env`: 실제 비밀번호 및 API 키 저장
- Git에 커밋하지 않음

**각 레포지토리**:
- `.env.example`: 템플릿만 제공 (비밀번호 제외)
- 팀원은 `.env.example`을 복사하여 `.env` 생성

### 5.2 .env.example 내용

```env
# OpenAI API Key
OPENAI_API_KEY=

# PostgreSQL Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_USER=callact_admin
DB_PASSWORD=  # 실제 비밀번호 입력 (팀원과 안전하게 공유)
DB_NAME=callact_db

# OpenAI Embedding Model
OPENAI_EMBEDDING_MODEL=text-embedding-3-small
OPENAI_EMBEDDING_DIMENSION=1536
```

## 6. 팀원 공유 가이드

### 6.1 팀원이 해야 할 작업

1. **Docker 컨테이너 실행**:

   docker-compose up -d

2. **DBeaver 연결**:

   - Port: `5432`
   - Database: `callact_db`
   - Username: `callact_admin`
   - Password: `callact_pwd1` (담당자와 안전하게 공유)

3. **DB 스키마 확인**:
   - DBeaver에서 `callact_db` 연결 후 테이블 목록 확인
