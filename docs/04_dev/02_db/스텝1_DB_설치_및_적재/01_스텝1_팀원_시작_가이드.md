## 2. 환경 설정

### 2.1 Conda 가상환경 생성

**⚠️ 중요**: 팀 규칙에 따라 Python 3.11을 사용합니다.

```powershell
# 프로젝트 루트에서 실행
cd C:\Users\[사용자명]\projects\call-act

# Conda 환경 생성
conda env create -f backend/environment.yml

# 생성 확인
conda env list
# final_env가 보이면 정상
```

**예상 시간**: 2-3분

### 2.2 패키지 설치

```powershell
# 가상환경 활성화 (Anaconda Prompt 권장)
conda activate final_env

# Python 버전 확인 (3.11이어야 함)
python --version
# 출력: Python 3.11.14

# pip 업그레이드
python -m pip install --upgrade pip

# 패키지 설치
pip install -r backend/requirements.txt
```

**설치 확인**:
```powershell
pip list | Select-String "psycopg2|python-dotenv|tqdm|openai"
# psycopg2-binary, python-dotenv, tqdm, openai가 보이면 정상
```

**예상 시간**: 3-5분

### 2.3 PowerShell에서 Conda 환경 활성화 문제 해결

**문제**: PowerShell에서 `conda activate final_env`가 제대로 작동하지 않을 수 있습니다.

**해결 방법**:

#### 방법 1: Anaconda Prompt 사용 (권장) ⭐

1. Windows 검색에서 "Anaconda Prompt" 실행
2. `conda activate final_env` 실행
3. 모든 작업을 Anaconda Prompt에서 진행

#### 방법 2: 절대 경로 사용

```powershell
# PowerShell에서 직접 Python 실행 시
C:\Users\[사용자명]\anaconda3\envs\final_env\python.exe 스크립트경로
```

#### 방법 3: conda run 사용

```powershell
conda run -n final_env python 스크립트경로
```

## 3. Docker 설정

### 3.1 Docker Desktop 실행 확인

1. Docker Desktop 실행
2. 상태 확인: 시스템 트레이에서 Docker 아이콘이 녹색이어야 함

### 3.2 PostgreSQL 컨테이너 실행

```powershell
# 프로젝트 루트에서 실행
```

- **Host**: `localhost`
- **Port**: `5432`
- **Database**: `callact_db` ⚠️ **주의**: `call_act_db`가 아님!
- **Username**: `callact_admin`
- **Password**: `callact_pwd1`

**⚠️ 중요**: 
- 데이터베이스 이름은 **`callact_db`**입니다 (언더스코어 없음).

## 4. DB 스키마 생성

### 4.1 DBeaver에서 연결 생성 (권장)

1. **DBeaver 실행**
2. **새 연결 생성**:
   - 데이터베이스 선택: **PostgreSQL**
   - 호스트: `localhost`
   - 포트: `5432`
   - **데이터베이스**: `callact_db` ⚠️
   - 사용자 이름: `callact_admin`
   - 비밀번호: `callact_pwd1`
3. **연결 테스트** → ✅ "연결이 성공적으로 완료되었습니다" 확인
4. **SQL 편집기 열기** (Ctrl+Shift+Enter)
5. **SQL 파일 열기**: `backend/db_setup.sql`
6. **전체 내용 실행** (F5 키)
7. **성공 확인**:
   ```
   DB 설정이 완료되었습니다.
   - pgvector 확장 설치됨
   - employees 테이블 생성됨
   - consultations 테이블 생성됨
   - consultation_documents 테이블 생성됨
   - 기본 상담사 생성됨 (EMP-TEDI-DEFAULT)
   - 벡터 인덱스 생성됨
   ```

**⚠️ 이전 연결 삭제 방법**:
- DBeaver 좌측 패널에서 `call_act_db` 연결 우클릭 → "연결 삭제"
- 또는 기존 연결을 수정: 우클릭 → "연결 편집" → Database를 `callact_db`로 변경

### 4.2 Python 스크립트로 실행 (대안)

```powershell
# Anaconda Prompt에서 실행
conda activate final_env
cd C:\Users\[사용자명]\projects\call-act\backend

# 환경 변수 설정 (PowerShell)
$env:DB_USER="callact_admin"
$env:DB_PASSWORD="callact_pwd1"
$env:DB_NAME="callact_db"
$env:DB_HOST="localhost"
$env:DB_PORT="5432"

# 스키마 생성 실행
python setup_db.py
```

**예상 시간**: 1-2분

### 4.3 스키마 생성 확인

**DBeaver에서 확인**:
```sql
-- 테이블 목록 확인
SELECT table_name 
FROM information_schema.tables 
WHERE table_schema = 'public';

-- 결과: employees, consultations, consultation_documents 3개 테이블
```

**기본 상담사 확인**:
```sql
SELECT id, name, email, role, department 
FROM employees 
WHERE id = 'EMP-TEDI-DEFAULT';

-- 결과: EMP-TEDI-DEFAULT | 테디카드 기본 상담사 | ...
```

## 7. 오류 대응

자세한 오류 대응은 `docs/04_dev/02_db/스텝1_DB_설치_및_적재/03_오류_대응_가이드.md`를 참조하세요.

### 7.1 주요 오류 요약

| 오류 | 원인 | 해결 |
|------|------|------|
| `conda activate` 작동 안함 | PowerShell 환경 문제 | Anaconda Prompt 사용 |
| Python 3.13.x 사용됨 | base 환경 사용 중 | `final_env` 환경 사용 |
| `call_act_db does not exist` | DB 이름 불일치 | `callact_db` 사용 확인 |
| `password authentication failed` | 연결 정보 오류 | 환경 변수 확인 |
| `ModuleNotFoundError: psycopg2` | 패키지 미설치 | `pip install -r backend/requirements.txt` |
