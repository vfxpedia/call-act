## 실행 방법

### 방법 1: .env 파일 사용 (권장) ⭐

**가장 간단한 방법**: `.env` 파일을 사용하면 환경 변수 설정이 필요 없습니다.

**⚠️ 중요**: 
- **팀원**: 프로젝트 루트에 `.env` 파일 생성 (`call-act/.env`)
- **개인 개발**: `scripts/db_loading/.env` 파일 생성 가능 (우선 사용)
- 스크립트는 `scripts/db_loading/.env` → 프로젝트 루트 `.env` 순서로 읽습니다

**1. .env 파일 확인/생성**:

```bash
# Anaconda Prompt에서 (프로젝트 루트)
cd C:\Users\AI-WS01\projects\call-act

# 프로젝트 루트 .env 파일이 있는지 확인
# 없으면 backend/.env.example 참고하여 생성
# 또는 scripts/db_loading/.env에 개인 파일 생성
```

**2. .env 파일 내용** (프로젝트 루트 `.env` 또는 `scripts/db_loading/.env`):

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=callact_admin
DB_PASSWORD=callact_pwd1
DB_NAME=callact_db
```

**3. 실행**:

```bash
# Anaconda Prompt에서
conda activate final_env
python --version  # 3.11.14 확인
cd C:\Users\AI-WS01\projects\call-act\scripts\db_loading

# .env 파일이 있으면 바로 실행 가능
python load_hana_to_db.py
python verify_db_load.py
```

### 방법 2: cmd.exe 환경 변수 사용 (Anaconda Prompt)

**`.env` 파일이 없는 경우**:

```bash
# Anaconda Prompt (cmd.exe)에서 실행
conda activate final_env
cd C:\Users\AI-WS01\projects\call-act\scripts\db_loading

# 환경 변수 설정 (cmd.exe 문법, 공백 없음!)
set DB_USER=callact_admin
set DB_PASSWORD=callact_pwd1
set DB_NAME=callact_db
set DB_HOST=localhost
set DB_PORT=5432

# 실행
python load_hana_to_db.py
python verify_db_load.py
```

### 방법 3: 절대 경로 사용 (PowerShell에서 직접)

**PowerShell에서 한 번에 실행**:

```powershell
# 작업 디렉토리 이동
cd C:\Users\AI-WS01\projects\call-act\scripts\db_loading

# 환경 변수 설정
$env:DB_USER="callact_admin"
$env:DB_PASSWORD="callact_pwd1"
$env:DB_NAME="callact_db"
$env:DB_HOST="localhost"
$env:DB_PORT="5432"

# Python 3.11 환경으로 실행
C:\Users\AI-WS01\anaconda3\envs\final_env\python.exe load_hana_to_db.py

# 검증 실행
C:\Users\AI-WS01\anaconda3\envs\final_env\python.exe verify_db_load.py
```

- **총 소요 시간**: **약 15-20분**

## 완료 후 확인

### DBeaver에서 확인

```sql
-- 전체 데이터 개수 확인
SELECT 
    (SELECT COUNT(*) FROM consultations) as consultations,
    (SELECT COUNT(*) FROM consultation_documents) as documents,
    (SELECT COUNT(*) FROM consultation_documents WHERE embedding IS NOT NULL) as documents_with_embedding;

-- 예상 결과: consultations=5371, documents=5371, documents_with_embedding=5371
```
