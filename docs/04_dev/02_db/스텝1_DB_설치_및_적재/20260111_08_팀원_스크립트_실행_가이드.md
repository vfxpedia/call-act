## 목적

팀원들이 Git에서 받은 데이터 파일(`hana_vectordb_with_embeddings.json` 등)과 담당자가 `backend` 폴더에 올린 스크립트를 사용하여 로컬에서 데이터베이스를 직접 적재하는 방법을 안내합니다.

**⚠️ 중요**: 
- 이 가이드는 **담당자 DB를 사용하지 않고 직접 실행하는 경우**를 위한 것입니다
- 대부분의 팀원은 [팀원 DB 연결 가이드](./20260111_01_팀원_DB_연결_가이드.md)를 따라 담당자 DB를 사용하는 것을 권장합니다
- 이 가이드는 로컬에서 직접 테스트하거나 개발이 필요한 경우를 위한 것입니다
- 스크립트 파일들(`setup_db.py`, `load_hana_to_db.py`, `verify_db_load.py` 등)은 담당자가 `backend` 폴더에 올렸습니다
- `scripts` 폴더는 Git에 올라가지 않으며, 필요한 파일들은 `backend` 폴더에 있습니다

## 담당자 DB 사용 vs 직접 실행 비교

| 항목 | 담당자 DB 사용 (권장) | 직접 실행 (이 가이드) |
|------|---------------------|---------------------|
| 설정 시간 | ⭐ 10-15분 | ⭐⭐⭐ 30-40분 |
| 필요한 작업 | DBeaver 연결만 | 환경 설정 + 스크립트 실행 |
| Docker 필요 | ❌ 불필요 | ✅ 필요 |
| Conda 환경 필요 | ❌ 불필요 | ✅ 필요 |
| 데이터 적재 시간 | ❌ 불필요 (이미 완료) | ⚠️ 15-20분 |
| 추천 상황 | 대부분의 팀원 | 로컬 테스트 필요시 |

**결론**: 대부분의 팀원은 **담당자 DB를 사용**하는 것을 권장합니다.

## 사전 준비

### 1. Git 클론 또는 Pull

**⚠️ 중요**: 팀원들은 일반 클론 또는 pull만 하면 됩니다.

```bash
# Git 클론 (일반 클론)
git clone <repository-url>
cd call-act

# 또는 기존 레포 업데이트
git pull
```

**참고**: `data-preprocessing` 폴더의 데이터 파일(`hana_vectordb_with_embeddings.json` 등)은 담당자가 이미 data-preprocessing 레포에 직접 추가했습니다.

### 2. 필요한 파일 확인

다음 파일들이 있어야 합니다:

```powershell
# PowerShell에서 확인
Test-Path "data-preprocessing\data\hana\hana_vectordb_with_embeddings.json"
# True가 나와야 함 (담당자가 이미 Git에 추가함)

Test-Path "data-preprocessing\data\hana\hana_rdb_metadata.json"
# True가 나와야 함

# 담당자가 backend 폴더에 올린 스크립트 파일 확인
Test-Path "backend\db_setup.sql"
# True가 나와야 함 (담당자가 backend 폴더에 올림)
```

**⚠️ 중요**: 
- 스크립트 파일들(`setup_db.py`, `load_hana_to_db.py`, `verify_db_load.py` 등)은 담당자가 `backend` 폴더에 올렸습니다
- `scripts` 폴더는 Git에 올라가지 않습니다
- 파일이 없으면 Git pull로 최신 상태로 업데이트하거나 담당자에게 확인 요청

### 3. 환경 설정

#### 3.1 Conda 환경 생성

```bash
# Conda 환경 생성
# 담당자가 backend 폴더에 environment.yml을 올렸는지 확인
conda env create -f backend/environment.yml

# 또는 담당자가 다른 위치에 올린 경우 해당 경로 사용
# conda env create -f [담당자가 안내한 경로]/environment.yml

# 가상환경 활성화 (Anaconda Prompt 권장)
conda activate final_env

# Python 버전 확인 (3.11.14이어야 함)
python --version
```

#### 3.2 패키지 설치

```bash
# pip 업그레이드
python -m pip install --upgrade pip

# 패키지 설치 (담당자가 backend 폴더에 올린 requirements.txt 사용)
pip install -r backend/requirements.txt
```

#### 3.3 Docker 설정

```bash
# Docker Desktop 실행 확인
docker --version

# PostgreSQL 컨테이너 실행
# 담당자가 backend 폴더에 docker-compose.yml을 올렸는지 확인
cd backend
docker-compose up -d

# 또는 담당자가 다른 위치에 올린 경우 해당 경로로 이동
# cd [담당자가 안내한 경로]
# docker-compose up -d

# 실행 확인
docker ps
# callact_db_container가 "healthy" 상태로 보이면 정상
```

#### 3.4 .env 파일 설정

프로젝트 루트에 `.env` 파일 생성:

```bash
# backend/.env.example 참고하여 .env 파일 생성
Copy-Item backend\.env.example .env
```

`.env` 파일 내용:

```env
# PostgreSQL Database Configuration
DB_HOST=localhost
DB_PORT=5432
DB_USER=callact_admin
DB_PASSWORD=callact_pwd1
DB_NAME=callact_db

# OpenAI API Key (임베딩 생성 시에만 필요, 이미 임베딩 파일이 있으면 생략 가능)
OPENAI_API_KEY=your_openai_api_key_here
```

**⚠️ 참고**: `hana_vectordb_with_embeddings.json`이 이미 있으므로 임베딩 생성은 필요 없습니다.

## 스크립트 실행 순서

### 1. DB 스키마 생성

#### 방법 1: DBeaver 사용 (권장)

1. **DBeaver 실행**
2. **새 연결 생성**:
   - Host: `localhost`
   - Port: `5432`
   - Database: `callact_db`
   - Username: `callact_admin`
   - Password: `callact_pwd1`
3. **SQL 편집기 열기** (Ctrl+Shift+Enter)
4. **SQL 파일 열기**: `backend/db_setup.sql` (담당자가 backend 폴더에 올림)
5. **전체 내용 실행** (F5 키)
6. **성공 확인**:
   ```
   DB 설정이 완료되었습니다.
   - pgvector 확장 설치됨
   - employees 테이블 생성됨
   - consultations 테이블 생성됨
   - consultation_documents 테이블 생성됨
   - 기본 상담사 생성됨 (EMP-TEDI-DEFAULT)
   - 벡터 인덱스 생성됨
   ```

#### 방법 2: Python 스크립트 사용

### 2. 데이터 적재

**⚠️ 중요**: 이미 `hana_vectordb_with_embeddings.json` 파일이 있으므로 임베딩 생성은 필요 없습니다.

## 문제 해결

### 1. 데이터 파일이 없음

**증상**: `hana_vectordb_with_embeddings.json` 파일을 찾을 수 없음

**해결**:
```bash
# Git pull로 최신 상태로 업데이트
git pull

# 파일 확인
Test-Path "data-preprocessing\data\hana\hana_vectordb_with_embeddings.json"
```

**참고**: 
- `hana_vectordb_with_embeddings.json` 파일은 담당자가 data-preprocessing 레포에 직접 추가했습니다
- 파일이 여전히 없으면 담당자에게 확인 요청

### 2. `ModuleNotFoundError: psycopg2`

**원인**: 패키지가 설치되지 않음

**해결**:
```bash
conda activate final_env
pip install -r backend/requirements.txt
```

### 3. `FATAL: database "callact_db" does not exist`

**원인**: Docker 컨테이너는 실행 중이지만 데이터베이스가 생성되지 않음

**해결**:
- `docker-compose.yml`에서 `POSTGRES_DB: callact_db` 확인
- 컨테이너 재생성: `docker-compose down && docker-compose up -d`

### 4. 데이터 적재 실패

**원인**: 파일 경로 문제 또는 데이터 형식 문제

**해결**:
1. 파일 경로 확인:
   ```powershell
   Test-Path "data-preprocessing\data\hana\hana_vectordb_with_embeddings.json"
   ```
2. 스크립트가 올바른 경로를 찾는지 확인
3. 오류 메시지 확인 및 [오류 대응 가이드](./20260111_04_오류_대응_가이드.md) 참조

### 5. 검증 실패

**증상**: `Orphaned Documents` 또는 `Documents without Embedding` 발견

**해결**:
- 데이터를 다시 적재: `cd backend && python load_hana_to_db.py`
- Foreign Key 관계 확인
- [오류 대응 가이드](./20260111_04_오류_대응_가이드.md) 참조
