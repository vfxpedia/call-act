## 목적

담당자가 Docker DB를 팀원들에게 공유하기 전에 확인해야 할 체크리스트입니다.

## 배포 전 체크리스트

### 1. Docker 및 데이터베이스

- [ ] Docker Desktop 실행 중
- [ ] PostgreSQL 컨테이너 실행 중 (`callact_db_container`)
- [ ] 컨테이너 상태가 "healthy"인지 확인
- [ ] 데이터베이스에 모든 데이터 정상 적재 확인
- [ ] 데이터 개수 확인 (예: consultations 5,371건)
- [ ] 기본 상담사 (`EMP-TEDI-DEFAULT`) 존재 확인

**확인 명령어**:
```bash
# Docker 컨테이너 상태 확인
docker ps

# 데이터베이스 연결 테스트
docker exec callact_db_container psql -U callact_admin -d callact_db -c "SELECT COUNT(*) FROM consultations;"
```

### 2. Tailscale VPN 설정

- [ ] Tailscale 설치 완료
- [ ] Tailscale 로그인 및 연결 확인
- [ ] Tailscale IP 확인 (`tailscale ip` 명령어)
- [ ] Tailscale IP 주소 기록 (팀원에게 공유할 IP)
- [ ] 팀원들을 Tailscale 네트워크에 초대 (필요시)

**확인 명령어**:
```bash
# Tailscale IP 확인
tailscale ip

# Tailscale 상태 확인
tailscale status
```

### 3. 네트워크 및 방화벽

- [ ] Docker 컨테이너 포트 바인딩 확인 (`0.0.0.0:5432`)
- [ ] Windows 방화벽에서 5432 포트 허용 확인 (Tailscale 네트워크)
- [ ] Tailscale을 통한 연결 테스트 (다른 기기에서)

**확인 방법**:
1. Docker 컨테이너가 `0.0.0.0:5432`로 바인딩되어 있는지 확인
2. 방화벽 고급 설정 → 인바운드 규칙 → PostgreSQL 포트 (5432) 확인

## 배포 단계

### Step 1: Git 커밋 및 푸시

```bash
# 변경사항 확인
git status

# 변경사항 추가
git add .

# 커밋
git commit -m "feat: Add DB loading scripts and Tailscale connection guide"

# 팀 repo에 푸시
git push origin main
```

**⚠️ 주의**: 
- `.env` 파일은 커밋하지 않았는지 확인
- `embedding_checkpoint.json`, `embedding_generation.log`는 커밋하지 않았는지 확인

### Step 2: 서브모듈 업데이트 (필요시)

`data-preprocessing` 서브모듈에 `hana_vectordb_with_embeddings.json`이 있다면:

```bash
cd data-preprocessing
git add data/hana/hana_vectordb_with_embeddings.json
git commit -m "Add hana_vectordb_with_embeddings.json"
git push origin main

# 메인 레포에서 서브모듈 포인터 업데이트
cd ..
git add data-preprocessing
git commit -m "Update data-preprocessing submodule"
git push origin main
```

1. **연결 정보 공유** (안전한 채널):
   ```

   Host: [Tailscale IP 주소]
   Port: 5432
   Database: callact_db
   Username: callact_admin
   Password: callact_pwd1
   
   Tailscale 설치 필요: https://tailscale.com/download
   상세 가이드: docs/04_dev/02_db/스텝1_DB_설치_및_적재/20260111_05_Tailscale_DB_연결_가이드.md
   ```

2. **문서 공유**:

   - 문서 경로 안내

3. **Tailscale 네트워크 초대** (필요시):
   - Tailscale 관리 페이지에서 팀원 초대
   - 또는 팀원이 같은 계정으로 로그인

## 문제 발생 시

### Docker 컨테이너 중단

**해결**:
```bash
# 컨테이너 재시작
cd backend_dev/docker
docker-compose restart

# 또는
docker restart callact_db_container
```

### Tailscale 연결 문제

**해결**:
1. Tailscale 재시작
2. 네트워크 상태 확인 (`tailscale status`)
3. 팀원들의 Tailscale 연결 상태 확인

### 데이터베이스 접근 불가

**해결**:
1. Docker 컨테이너 상태 확인 (`docker ps`)
2. 포트 바인딩 확인 (`0.0.0.0:5432`)
3. 방화벽 설정 확인
4. Tailscale IP 확인
