### 🛠️ 사전 준비 사항

워크플로우를 작성하기 전에 **Personal Access Token (PAT)**이 필요합니다.

**Settings > Developer settings > Personal access tokens (classic)**에서 토큰을 생성하세요.

권한(Scope)은 repo, project, workflow를 선택해야 합니다.

생성한 토큰을 해당 레포지토리의 Settings > Secrets and variables > Actions에 CALLACT_TOKEN이라는 이름으로 저장하세요.
