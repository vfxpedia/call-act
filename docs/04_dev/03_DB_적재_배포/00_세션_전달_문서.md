## 2. 프로젝트 이해

### 2.1 프로젝트 개요

**프로젝트명**: CALL:ACT  
**목적**: 카드사 상담사를 위한 AI 기반 실시간 상담 지원 시스템  
**주요 기술**: Speech-to-Text, RAG, LLM

**참고 문서**: `README.md`

### 2.2 프로젝트 구조

**데이터 흐름**:
```
데이터 수집 → 전처리 → DB 적재 → RAG 검색 → LLM 응답 생성
```

**주요 컴포넌트**:
- **Frontend**: React + TypeScript (실시간 상담 UI)
- **Backend**: FastAPI + PostgreSQL + pgvector (RAG 검색)
- **Data Preprocessing**: Python 스크립트 (데이터 전처리 및 임베딩 생성)

### 2.3 데이터베이스 구조

**테이블 구성**:
- `service_guide_documents`: 서비스 가이드 문서 (임베딩 포함)
- `card_products`: 카드 상품 정보 (structured 필드 포함)
- `notices`: 공지사항 (임베딩 포함)
- `keyword_dictionary`: 키워드 사전 (우선순위, 긴급성 포함)
- `keyword_synonyms`: 키워드 동의어 매핑

**참고 문서**: 
- `docs/04_dev/03_DB_적재_배포/11_통합_DB_설정_가이드.md`
- `docs/04_dev/03_DB_적재_배포/06_DB_스키마_에러_해결_가이드.md`
