## 개요

개발 환경(`_dev`)과 프로덕션 환경(`data-preprocessing`) 간 경로 전환을 쉽게 하기 위해 중앙 설정 파일(`config.py`)을 사용합니다.

---

## 1. 설정 파일 구조

### 1.1 config.py 위치

```
data-preprocessing_dev/preprocessing/teddycard/config.py
```

### 1.2 주요 설정 항목

#### 경로 설정
- `ENV_TYPE`: 'dev' 또는 'prod' (기본값: 'dev')
- `PROJECT_ROOT`: 프로젝트 루트 디렉토리
- `DATA_DIR`: 데이터 디렉토리 (dev/prod 자동 전환)
- `OUTPUT_DIR`: 출력 디렉토리

#### 임베딩 설정 (`EMBEDDING_CONFIG`)
- `model`: 임베딩 모델명
- `dimension`: 임베딩 차원
- `batch_size`: 배치 크기
- `max_retries`: 최대 재시도 횟수
- `retry_delay`: 재시도 대기 시간 (초)
- `request_delay`: 요청 간 딜레이 (초)

#### LLM 설정 (`LLM_CONFIG`)
- `model`: LLM 모델명
- `temperature`: Temperature 값
- `max_tokens`: 최대 토큰 수

#### 구조화 설정 (`STRUCTURE_CONFIG`)
- `use_parallel`: 병렬 처리 사용 여부 (기본값: False)
- `max_workers`: 병렬 처리 시 worker 수
- `rate_limit_per_minute`: 분당 요청 수 제한

#### 청킹 설정 (`CHUNKING_CONFIG`)
- `max_tokens`: 최대 토큰 수
- `chunk_max_tokens`: 청크 최대 토큰 수
- `chunk_overlap_tokens`: 청크 overlap 토큰 수

## 2. 경로 전환 방법

### 2.1 개발 → 프로덕션 전환

**방법 1: config.py 수정**
```python
# config.py
ENV_TYPE = 'prod'  # 'dev' → 'prod'
```

**방법 2: 환경 변수 사용**
```bash
# .env 파일에 추가
PREPROCESSING_ENV=prod
```

### 2.2 자동 경로 전환

`ENV_TYPE`에 따라 자동으로 경로가 전환됩니다:

**dev 모드**:
- `DATA_DIR`: `data-preprocessing_dev`
- `PREPROCESSING_DIR`: `data-preprocessing_dev/preprocessing`
- `OUTPUT_DIR`: `data-preprocessing_dev/preprocessing/output`

**prod 모드**:
- `DATA_DIR`: `data-preprocessing`
- `PREPROCESSING_DIR`: `data-preprocessing/preprocess`
- `OUTPUT_DIR`: `data-preprocessing/preprocess/output`

## 3. 설정 파일 사용 방법

### 3.1 스크립트에서 사용

```python
# config.py에서 필요한 설정 import
from config import (
    PROJECT_ROOT, OUTPUT_DIR, 
    EMBEDDING_CONFIG, LLM_CONFIG, STRUCTURE_CONFIG
)

# 사용 예시
INPUT_DIR = OUTPUT_DIR
EMBEDDING_MODEL = EMBEDDING_CONFIG["model"]
REQUEST_DELAY = EMBEDDING_CONFIG["request_delay"]
```

### 3.2 환경 변수 오버라이드

일부 설정은 환경 변수로 오버라이드 가능:

```bash
# .env 파일
STRUCTURE_USE_PARALLEL=true
STRUCTURE_MAX_WORKERS=5
```

코드에서:
```python
USE_PARALLEL = os.getenv("STRUCTURE_USE_PARALLEL", str(STRUCTURE_CONFIG["use_parallel"])).lower() == "true"
```

- ✅ **API 키만 포함**: 보안상 중요한 정보만
- ✅ **Git에 커밋하지 않음**: `.gitignore`에 포함

## 5. 팀 레포지토리로 복사 시

### 5.1 config.py 수정

팀 레포지토리로 복사할 때:

1. **경로 수정**: `ENV_TYPE = 'prod'`로 변경
2. **경로 확인**: `data-preprocessing/preprocess` 경로 확인
3. **설정 검토**: 필요시 설정 값 조정

### 5.2 스크립트 복사

스크립트는 `config.py`를 사용하므로 경로 수정 불필요:

```bash
# 복사만 하면 됨
cp data-preprocessing_dev/preprocessing/teddycard/*.py \
   data-preprocessing/preprocess/teddycard/
```
