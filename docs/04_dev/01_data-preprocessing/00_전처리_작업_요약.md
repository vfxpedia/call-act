# 테디카드 전처리 작업 요약

## 작성일: 2026-01-11
## 상태: 완료

---

## 작업 개요

테디카드 통합을 위한 데이터 전처리 작업을 수행했습니다. 신한, 현대, 삼성, 스페셜 카드 데이터를 통합하고, 텍스트 치환, 데이터 보강, 키워드 추출, 임베딩 생성을 위한 스크립트를 구축했습니다.

---

## 주요 작업 내용

### 1. 데이터 변환 스크립트 (01~05)

**목적**: 원본 데이터를 표준 형식으로 변환하고 텍스트 치환

- `01_convert_shinhan_cards.py`: 신한 카드 정보 변환
- `02_convert_hyundai_guides.py`: 현대 가이드 변환 (merge 포함)
- `03_convert_samsung_guides.py`: 삼성 가이드 변환 + 공지사항 (merge 포함)
- `04_convert_shinhan_terms.py`: 신한 약관 변환 (merge 미적용)
- `05_convert_special_cards.py`: 스페셜 카드 변환 (merge 미적용)

**주요 특징**:
- 텍스트 치환: "신한" → "테디", "현대" → "테디" 등
- 표준 JSON 형식으로 변환
- merge 로직 적용 (삼성, 현대)

### 2. 데이터 보강 스크립트 (07)

**목적**: DB 스키마에 맞게 데이터 보강

- `07_enrich_for_db.py`: 데이터 보강
  - notices: 날짜, 카테고리, 우선순위 결정
  - card_products: 연회비 파싱, 브랜드 추출
  - service_guides: document_source 추가

**주요 기능**:
- LLM 기반 카테고리/우선순위 결정 (선택적)
- 한국어 숫자 파싱 (연회비 등)
- 브랜드 추출 (Local, VISA, Mastercard 등)

### 3. 키워드 추출 스크립트 (08)

**목적**: STT 키워드 추출 및 RAG 검색을 위한 키워드 필드 추가

- `08_extract_keywords.py`: 키워드 추출
  - 단어사전 기반 키워드 매칭
  - LLM 보완 (선택적)

**향후 개선**: hana 데이터에서 키워드 사전 자동 생성

### 4. 임베딩 생성 스크립트 (06)

**목적**: OpenAI Embedding API로 벡터 임베딩 생성

- `06_generate_embeddings.py`: 임베딩 생성
  - 체크포인트 기능 (중단 후 재시작 가능)
  - 로그 기록

## 주요 결정 사항

### 1. 파일명 통일

- 모든 출력 파일명: `teddycard_*.json` (서비스명: 테디카드)

### 2. merge 로직 적용

- ✅ 삼성: merge 적용 (카테고리별 과도한 분할 통합)
- ✅ 현대: merge 적용 (관련 문서 통합)
- ❌ 신한 약관: merge 미적용 (조 단위 독립성 유지)
- ❌ 스페셜 카드: merge 미적용 (category2 구조 없음)

### 3. 키워드 사전

- 현재: 수동 작성된 `keywords_dict.json` 사용
- 향후: hana 데이터에서 자동 생성 (개선 방안 문서화)

### 4. 데이터 구조

- 문서 번호 정보: `title` 필드에 포함 (약관 조 번호 등)
- 문서 식별자: `id` 필드
- 출처 정보: `metadata.original_source`
- 원본 정보: `metadata.original_*` 필드들
