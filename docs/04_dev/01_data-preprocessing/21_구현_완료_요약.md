## 2. 주요 변경 사항

### 2.1 Structured 필드 저장 방식

**이전**: 별도 `_structured.json` 파일 생성  
**현재**: 기존 JSON 파일에 `structured` 필드 추가

**장점**:
- 파일 관리 단순화
- DB 적재 시 바로 사용 가능
- 병합 작업 불필요

### 2.2 병렬 처리 지원

**기본값**: 순차 처리 (안전)  
**선택적**: 병렬 처리 (빠름)

**설정 방법**:
```bash
# .env 파일
STRUCTURE_USE_PARALLEL=true  # 병렬 처리 활성화
STRUCTURE_MAX_WORKERS=5      # Worker 수 (권장: 5)
```

### 2.3 Rate Limit 관리

**자동 관리**:
- 분당 60 requests로 제한 (안전 마진)
- Rate limit 초과 시 자동 대기
- Thread-safe 구현

## 3. OpenAI API 사용 규칙

### 3.1 하나의 API 키로 병렬 처리

✅ **가능**: 단일 노트북에서 5-10 workers 사용 가능

### 3.2 여러 노트북에서 동시 사용

❌ **권장하지 않음**: Rate limit 초과 위험

**권장 방법**:
- 하나의 노트북에서 순차 처리 또는 병렬 처리 (5 workers)
- 안전하게 하나의 노트북에서 처리

## 4. 실행 방법

### 4.1 순차 처리 (기본, 권장)

```bash
# .env 파일에서 STRUCTURE_USE_PARALLEL 설정 안 함
cd data-preprocessing_dev/preprocessing/tedicard
python 11_structured_for_rag.py
```

**예상 시간**: 30-60분 (1000개 문서 기준)

### 4.2 병렬 처리 (선택적)

```bash
# .env 파일
STRUCTURE_USE_PARALLEL=true
STRUCTURE_MAX_WORKERS=5

# 실행
cd data-preprocessing_dev/preprocessing/tedicard
python 11_structured_for_rag.py
```

**예상 시간**: 10-20분 (1000개 문서, 5 workers 기준)
