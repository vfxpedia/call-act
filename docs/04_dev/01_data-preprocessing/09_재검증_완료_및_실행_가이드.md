## 1. 수정 완료 사항

### 1.1 연회비 파싱 로직 개선 ✅

**문제**: 연회비가 모두 `null`로 저장됨

**원인**: 
- 원본 MD 파일의 연회비 테이블 형식을 제대로 파싱하지 못함
- 한국어 숫자("2만 7천원") 파싱 로직 부족

**수정 내용**:
1. `parse_korean_number` 함수 개선:
   - "2만 7천원" → 27000
   - "7천원" → 7000
   - "3만원" → 30000
   - 순수 숫자도 지원

2. `parse_annual_fee` 함수 개선:
   - full_content에서 연회비 테이블을 더 정교하게 파싱
   - 여러 패턴 지원: `| 국내전용 | Local | 2만 7천원 | ...`

3. 해외 연회비(`annual_fee_global`) 파싱 추가:
   - 해외겸용 행에서 직접 추출
   - `| 해외겸용 | VISA | 3만원 | ...`

**파일**: `data-preprocessing_dev/preprocessing/tedicard/07_enrich_for_db.py`

---

### 1.2 브랜드 추출 로직 개선 ✅

**문제**: 일부 카드의 `brand`가 `null`

**원인**: 
- `full_content`에서 브랜드 정보를 찾지 못함
- 연회비 테이블에서 브랜드 정보를 직접 추출하지 않음

**수정 내용**:
1. 연회비 테이블에서 브랜드 정보 직접 추출:
   - `| 국내전용 | Local | ...`
   - `| 해외겸용 | VISA | ...`

2. 국내전용/해외겸용 행 모두 확인:
   - 국내전용이 Local이면 `brand = "local"`
   - 해외겸용이 VISA면 `brand = "visa"` (우선순위)

3. Local, VISA, Mastercard, AMEX 모두 지원

**파일**: `data-preprocessing_dev/preprocessing/tedicard/07_enrich_for_db.py`

### 1.3 기타 확인 사항 ✅

- ✅ `start_date`는 원본 `date` 필드를 올바르게 파싱 (공지사항 게시일)
- ✅ Content의 "2025년 9월 26일"은 사건 발생일이므로 별도 처리 불필요

- ✅ Content에서 종료일 추출 시도 (패턴 매칭)
- ✅ 추출 실패 시 priority 기반 기본값 사용:

#### full_content 중복
- ✅ `main_benefits`: 요약된 정보 (RAG 검색용)
- ✅ `full_content`: 전체 정보 (임베딩 생성 및 상세 조회용)
- ✅ `metadata.full_content`: 원본 보존용 (DB 적재 시 제외)

### 2.2 결과 검증

#### 연회비 검증
```python
import json
from pathlib import Path

# 보강된 파일 로드
file_path = Path("output/teddycard_card_products_enriched.json")
with open(file_path, 'r', encoding='utf-8') as f:
    cards = json.load(f)

# 연회비가 null이 아닌 카드 확인
cards_with_fee = [c for c in cards if c.get("annual_fee_domestic") is not None]
print(f"연회비가 파싱된 카드: {len(cards_with_fee)}/{len(cards)}")

# 샘플 확인
for card in cards_with_fee[:5]:
    print(f"ID: {card['id']}")
    print(f"  국내 연회비: {card.get('annual_fee_domestic')}원")
    print(f"  해외 연회비: {card.get('annual_fee_global')}원")
    print()
```

#### 브랜드 검증
```python
# 브랜드가 null이 아닌 카드 확인
cards_with_brand = [c for c in cards if c.get("brand") is not None]
print(f"브랜드가 추출된 카드: {len(cards_with_brand)}/{len(cards)}")

# 브랜드별 통계
from collections import Counter
```

## 6. 문제 해결

### 6.1 연회비가 여전히 null인 경우

**원인**: 
- 원본 MD 파일의 테이블 형식이 예상과 다를 수 있음
- 파싱 패턴이 해당 형식을 커버하지 못함

**해결**:
1. 문제가 있는 카드의 원본 MD 파일 확인
2. 테이블 형식 확인
3. 필요 시 파싱 패턴 추가

### 6.2 브랜드가 여전히 null인 경우

**원인**:
- 원본 MD 파일에 브랜드 정보가 없을 수 있음
- 테이블 형식이 예상과 다를 수 있음

**해결**:
1. 문제가 있는 카드의 원본 MD 파일 확인
2. 브랜드 정보 위치 확인
3. 필요 시 추출 로직 개선
