## 파라미터 설정 근거

### 1. tolerance (허용 편차)
- **값**: 4
- **의미**: 전체 최소 건수와의 차이를 4건 이내로 허용
- **근거**: 
  - 기존 10건에서 4건으로 축소하여 더 균등한 배분
  - 너무 작으면 (1~2) 후보가 부족하여 배분이 어려움
  - 너무 크면 (10+) 불균등 배분 발생

### 2. random_ratio (랜덤 배분 비율)
- **값**: 0.05 (5%)
- **의미**: 전체 배정 중 5%는 랜덤 배정
- **근거**:
  - 기존 10%에서 5%로 축소하여 더 예측 가능한 배분
  - 완전 순차 배정(0%)은 다양성 부족
  - 너무 높으면 (10%+) 불균등 배분 발생

### 3. random_seed (랜덤 시드)
- **값**: 42
- **의미**: 재현 가능한 랜덤 배정
- **근거**:
  - 동일한 입력에 대해 항상 동일한 결과 보장
  - 팀원들이 재적재 시에도 동일한 데이터 확인 가능

### 4. 후보 선택 로직
- **1차 후보**: 전체 최소 건수와의 차이가 tolerance(4) 이내인 상담사
- **2차 후보**: 1차 후보가 없으면 풀 내 최소 건수 상담사
- **3차 후보**: 후보가 여러 명이면 차이가 2건 이내인 상담사만 선택

## 배정 알고리즘 개요

### 단계별 프로세스
1. **대분류 매핑**: 세부 카테고리 → 대분류 변환
2. **풀 생성**: 대분류별 상담사 풀 생성 (중복 최소화)
3. **후보 선택**: tolerance 기반 후보 상담사 선택
4. **배정 실행**: 95% 순차 + 5% 랜덤 배정
5. **건수 추적**: 상담사별 건수 실시간 업데이트

### 중복 최소화 전략

- 단, "기타"는 모든 상담사가 포함되므로 제외 대상에서 제외
- 상담 건수가 많은 대분류부터 풀 생성하여 중복 최소화
