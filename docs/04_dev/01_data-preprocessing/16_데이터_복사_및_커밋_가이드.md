---

## 개요

이 가이드는 `data-preprocessing_dev` 폴더에서 완료한 테디카드 전처리 작업 결과를 `data-preprocessing` 서브모듈(팀 레포)로 복사하고 Git에 커밋하는 과정을 안내합니다.

### 작업 흐름

```
data-preprocessing_dev (개인 개발)
  ↓
복사 (최종 출력 파일)
  ↓
data-preprocessing (서브모듈, 팀 레포)
  ↓
Git 커밋 (feat/data-merge 브랜치)
  ↓
메인 레포 서브모듈 포인터 업데이트
```

### 2.3 경로 수정 (복사한 파일만)

**중요**: 원본(`data-preprocessing_dev`) 파일은 수정하지 않습니다. 복사한 파일만 수정합니다.

**수정 대상 파일**:
다음 파일들의 경로를 `data-preprocessing_dev` → `data-preprocessing`으로 변경해야 합니다:

1. `00_analyze_document_lengths.py`
2. `01_convert_shinhan_cards.py`
3. `02_convert_hyundai_guides.py`
4. `03_convert_samsung_guides.py`
5. `04_convert_shinhan_terms.py`
6. `05_convert_special_cards.py`
7. `06_generate_embeddings.py` (INPUT_DIR, OUTPUT_DIR 둘 다 수정)
8. `07_enrich_for_db.py`
9. `08_extract_keywords.py`
10. `09_check_merge_candidates.py`

**수정 방법**:

각 파일에서 다음 패턴을 찾아 수정합니다:

**패턴 1: OUTPUT_DIR (대부분의 파일)**
```python
# 변경 전
OUTPUT_DIR = BASE_DIR / "data-preprocessing_dev" / "preprocessing" / "output"

# 변경 후
OUTPUT_DIR = BASE_DIR / "data-preprocessing" / "preprocessing" / "output"
```

**패턴 2: INPUT_DIR (06_generate_embeddings.py만)**
```python
# 변경 전
INPUT_DIR = BASE_DIR / "data-preprocessing_dev" / "preprocessing" / "output"

# 변경 후
INPUT_DIR = BASE_DIR / "data-preprocessing" / "preprocessing" / "output"
```

**경로 수정 스크립트 (PowerShell)**:

일괄 수정이 필요하면 다음 PowerShell 명령어를 사용할 수 있습니다:

```powershell
# data-preprocessing/preprocessing/teddycard 폴더에서 실행
cd data-preprocessing\preprocessing\teddycard

# Python 파일에서 일괄 치환
Get-ChildItem -Filter *.py | ForEach-Object {
    (Get-Content $_.FullName -Raw) -replace 'data-preprocessing_dev', 'data-preprocessing' | Set-Content $_.FullName
}
```

**또는 수동 수정**:
각 파일을 열어서 `data-preprocessing_dev`를 `data-preprocessing`으로 변경합니다.

## 트러블슈팅

### 문제 1: "modified content" 에러

**증상**:
```bash
git status
# modified: data-preprocessing (modified content)
```

**원인**: 서브모듈 내부에 커밋되지 않은 변경사항이 있음

**해결**:
```bash
cd data-preprocessing
git status
git add .
git commit -m "변경사항 커밋"
git push
cd ..
git add data-preprocessing
git commit -m "서브모듈 업데이트"
```

### 문제 2: 브랜치 충돌

**증상**: `git push` 시 브랜치 충돌

**해결**:
```bash
git pull origin feat/data-merge
# 충돌 해결 후
git push origin feat/data-merge
```

### 문제 3: 파일 크기 확인

**증상**: 복사한 파일이 0바이트

**원인**: 원본 파일이 생성되지 않았거나 복사 중단

**해결**:
1. 원본 파일 확인: `data-preprocessing_dev/preprocessing/output/`
2. 파일 크기 확인: `ls -lh` 또는 파일 속성에서 확인
3. 재복사
