## ⚙️ 설정 확인

### 1. 환경 변수 (.env)

`.env` 파일은 프로젝트 루트(`C:\Users\AI-WS01\projects\call-act\.env`)에 위치하며, **API 키만** 포함합니다:

```env
OPENAI_API_KEY=sk-...
```

### 2. 설정 파일 (config.py)

임베딩 관련 상수는 `config.py`에서 관리됩니다:

- `EMBEDDING_CONFIG`: 임베딩 모델, 배치 크기, 딜레이 등
- `LLM_CONFIG`: LLM 모델, temperature, max_tokens 등
- `STRUCTURE_CONFIG`: 병렬 처리, rate limit 등
- `CHUNKING_CONFIG`: 청킹 관련 설정

**경로 전환**: `config.py`의 `ENV_TYPE`을 변경하면 자동으로 경로가 전환됩니다:
- `ENV_TYPE = 'dev'`: `data-preprocessing_dev` 사용
- `ENV_TYPE = 'prod'`: `data-preprocessing` 사용

## 🔧 문제 해결

### 문제 1: ModuleNotFoundError: No module named 'config'

**원인**: 작업 디렉토리가 잘못됨

**해결**:
```bash
# 올바른 디렉토리로 이동
cd C:\Users\AI-WS01\projects\call-act\data-preprocessing_dev\preprocessing\teddycard
```

### 문제 2: 하나카드 데이터 파일을 찾을 수 없음

**원인**: 파일 경로 문제

**해결**: `config.py`에서 `HANA_DATA_FILE` 경로 확인

### 문제 3: OPENAI_API_KEY 없음

**원인**: `.env` 파일에 API 키가 없음

**해결**: 프로젝트 루트의 `.env` 파일에 `OPENAI_API_KEY` 추가
