- **현재 작업 디렉토리**: `data-preprocessing_dev/preprocessing/tedicard/`

## 2. 실행 순서

### 2.1 전체 워크플로우

```
1. 원본 데이터 수집 (완료)
   ↓
2. 텍스트 치환 (신한→테디 등) - 01~05 스크립트
   ↓
3. 데이터 보강 (07_enrich_for_db.py) ← 현재 단계
   ↓
4. 임베딩 생성 (06_generate_embeddings.py) ← 다음 단계
   ↓
5. DB 적재 (backend_dev/app/db/scripts/)
```

### 2.2 단계별 실행

#### Step 1: 데이터 변환 (01~05 스크립트)

```bash
# 각 데이터 소스별 변환
python 01_convert_shinhan_cards.py      # 신한 카드 정보
python 02_convert_hyundai_guides.py     # 현대 가이드 (merge 포함)
python 03_convert_samsung_guides.py     # 삼성 가이드 + 공지사항 (merge 포함)
python 04_convert_shinhan_terms.py      # 신한 약관
python 05_convert_special_cards.py      # 스페셜 카드
```

#### Step 2: 데이터 보강 (07_enrich_for_db.py)

```bash
python 07_enrich_for_db.py
```

**출력 파일**:
- `output/teddycard_notices_enriched.json`
- `output/teddycard_card_products_enriched.json`
- `output/teddycard_service_guides_enriched.json`

**확인 사항**:
- [ ] 모든 보강 파일이 생성되었는지 확인
- [ ] 파일 크기가 0이 아닌지 확인

#### Step 3: 키워드 추출 (08_extract_keywords.py) - 새로 추가

```bash
# 단어사전만 사용 (빠름, 권장)
python 08_extract_keywords.py

# 또는 LLM 보완 포함 (더 정확하지만 느림)
python 08_extract_keywords.py --use-llm
```

**출력**: 기존 JSON 파일에 `keywords` 필드가 추가됩니다.

**확인 사항**:
- [ ] 모든 문서에 `keywords` 필드가 있는지 확인
- [ ] 키워드가 빈 배열이 아닌 문서가 있는지 확인

#### Step 4: 임베딩 생성

```bash
# 처음 실행
python 06_generate_embeddings.py

# 또는 중단 후 재시작
python 06_generate_embeddings.py --resume
```

**출력 파일**:
- `output/teddycard_service_guides_with_embeddings.json`
- `output/teddycard_card_products_with_embeddings.json`
- `output/teddycard_notices_with_embeddings.json`
- `output/embedding_checkpoint.json` (진행 상황 저장)
- `output/embedding_generation.log` (로그 파일)

**예상 소요 시간**: 약 3-5분 (1,791건 기준)

## 4. 재시작 기능

### 4.1 중단 후 재시작

임베딩 생성 중 중단되면 `--resume` 옵션으로 재시작:

```bash
python 06_generate_embeddings.py --resume
```

**동작 방식**:
1. `embedding_checkpoint.json`에서 이미 처리된 문서 ID 목록 로드
2. 해당 문서들은 제외하고 나머지만 처리
3. 50개마다 체크포인트 저장 (중단 시 손실 최소화)

### 4.2 체크포인트 저장 주기

- **기본**: 50개 문서마다 자동 저장
- **최종**: 모든 문서 처리 완료 시 저장
- **에러 발생 시**: 즉시 저장

## 5. 문제 해결

### 5.1 파일을 찾을 수 없음

**증상**: `FileNotFoundError` 또는 파일 경로 오류

**해결**:
1. 작업 디렉토리 확인: `cd data-preprocessing_dev/preprocessing/tedicard`
2. 파일 존재 확인: `ls output/*.json` 또는 `Get-ChildItem output/*.json`
3. 파일명 확인: `teddycard_`로 시작하는지 확인

### 5.2 API 키 오류

**증상**: `OPENAI_API_KEY not found`

**해결**:
1. `.env` 파일 확인: 프로젝트 루트(`call-act/`)에 존재하는지 확인
2. 환경 변수 확인: `echo $env:OPENAI_API_KEY` (PowerShell)
3. 스크립트 내 환경 변수 로드 확인

### 5.3 모듈 없음 오류

**증상**: `ModuleNotFoundError: No module named 'openai'`

**해결**:
```bash
# Conda 환경 활성화 확인
conda activate final_env

# 패키지 설치
pip install openai python-dotenv tqdm
```

### 5.4 체크포인트 파일 손상

**증상**: JSON 파싱 오류

**해결**:
1. 체크포인트 파일 백업
2. 수동으로 JSON 형식 확인 및 수정
3. 또는 체크포인트 파일 삭제 후 처음부터 재실행

## 7. 완료 후 확인 사항

### 7.2 임베딩 포함 여부 확인

```python
import json
from pathlib import Path

# 예시: service_guides 파일 확인
file_path = Path("output/teddycard_service_guides_with_embeddings.json")
with open(file_path, 'r', encoding='utf-8') as f:
    data = json.load(f)

# 첫 번째 문서 확인
if data:
    first_doc = data[0]
    print(f"ID: {first_doc.get('id')}")
    print(f"임베딩 포함: {'embedding' in first_doc}")
    if 'embedding' in first_doc:
        print(f"임베딩 차원: {len(first_doc['embedding'])}")
```
