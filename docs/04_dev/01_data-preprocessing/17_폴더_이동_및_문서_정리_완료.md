### 6. 문서 복사 방법

**PowerShell 명령어**:
```powershell
# 소스 디렉토리
$source = "docs\04_dev\01_data-preprocessing"
$dest1 = "data-preprocessing\docs\teddycard_preprocessing"
$dest2 = "docs\04_dev\01_data-preprocessing\teddycard_preprocessing"

# 모든 MD 파일 복사 (README 제외)
Get-ChildItem "$source\*.md" | Where-Object { $_.Name -ne "README.md" } | ForEach-Object {
    Copy-Item $_.FullName -Destination "$dest1\$($_.Name)" -Force
    Copy-Item $_.FullName -Destination "$dest2\$($_.Name)" -Force
    Write-Host "Copied: $($_.Name)"
}
```

**또는 수동 복사**:
1. `docs\04_dev\01_data-preprocessing\` 폴더에서 위 문서 목록의 파일들을 선택
2. `data-preprocessing\docs\teddycard_preprocessing\` 폴더에 복사
