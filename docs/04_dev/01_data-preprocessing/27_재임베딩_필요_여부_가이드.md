# 재임베딩 필요 여부 가이드

## 질문: structured 필드를 추가한 후 재임베딩이 필요한가?

## 답변: **재임베딩 불필요**

## 이유

### 1. structured 필드는 메타데이터

- `structured` 필드는 프론트엔드 표시를 위한 메타데이터입니다
- 본문(`text`, `content`, `main_benefits`)은 변경되지 않았습니다
- 임베딩은 본문 기반으로 생성되므로 기존 임베딩이 그대로 유효합니다

### 2. 임베딩 생성 기준

임베딩은 다음 필드를 기준으로 생성됩니다:
- `service_guides`: `text` 또는 `content` 필드
- `notices`: `text` 또는 `content` 필드
- `card_products`: `main_benefits` 필드

`structured` 필드는 이 과정에 포함되지 않습니다.

### 3. DB 적재 시 처리

DB 적재 시:
- `embedding` 필드: 기존 임베딩 벡터 그대로 사용
- `structured` 필드: JSON으로 저장 (별도 컬럼 또는 JSONB)

두 필드는 독립적으로 저장되므로 재임베딩이 필요 없습니다.

## 언제 재임베딩이 필요한가?

다음 경우에만 재임베딩이 필요합니다:

### 1. 본문 내용 변경

- `text`, `content`, `main_benefits` 필드가 수정된 경우
- 예: 오타 수정, 내용 추가/삭제

### 2. 임베딩 모델 변경

- 다른 임베딩 모델로 변경하는 경우
- 예: `text-embedding-3-small` → `text-embedding-3-large`

### 3. 임베딩 차원 변경

- 임베딩 차원을 변경하는 경우
- 예: 1536차원 → 3072차원

## 현재 상황

### 변경 사항

- ✅ `structured` 필드 추가 (메타데이터)
- ❌ 본문 내용 변경 없음
- ❌ 임베딩 모델 변경 없음
- ❌ 임베딩 차원 변경 없음

### 결론

**재임베딩 불필요** - 기존 `_with_embeddings.json` 파일을 그대로 사용하면 됩니다.

## 실행 순서

1. ✅ `11_structured_for_rag.py` 실행 (structured 필드 생성)
2. ✅ `12_propagate_structured.py` 실행 (structured 필드 전파)
3. ✅ `_with_embeddings.json` 파일 확인 (structured 필드 포함 여부)
4. ➡️ DB 적재 진행 (기존 임베딩 + structured 필드 함께 저장)

## 검증 방법

### 1. 임베딩 유효성 확인

```python
# 임베딩 벡터 길이 확인 (1536차원)
import json

with open('data-preprocessing_dev/preprocessing/output/teddycard_notices_with_embeddings.json', 'r', encoding='utf-8') as f:
    data = json.load(f)
    
if data:
    embedding = data[0].get('embedding', [])
    print(f"임베딩 차원: {len(embedding)}")  # 1536이어야 함
    print(f"structured 필드 존재: {'structured' in data[0]}")
```

### 2. 본문 일치 확인

원본과 임베딩 파일의 본문이 일치하는지 확인:

```python
import json

# 원본 파일
with open('data-preprocessing_dev/preprocessing/output/teddycard_notices.json', 'r', encoding='utf-8') as f:
    original = json.load(f)

# 임베딩 파일
with open('data-preprocessing_dev/preprocessing/output/teddycard_notices_with_embeddings.json', 'r', encoding='utf-8') as f:
    with_embeddings = json.load(f)

# 첫 번째 문서 비교
if original and with_embeddings:
    orig_text = original[0].get('text', '')
    embed_text = with_embeddings[0].get('text', '')
    print(f"본문 일치: {orig_text == embed_text}")
```
