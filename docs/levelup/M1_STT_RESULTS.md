## 5. 결론 및 권장사항

### 프로덕션 STT 엔진 권장: **faster-whisper-large-v3**

1. **속도**: RTF 0.066 (whisper-1의 2배, qwen3-asr의 2배)
2. **정확도**: 키워드 보존율 91% (최고)
3. **숫자 처리**: 아라비아 숫자 유지 (58,000원, 2002년) → 키워드 매칭에 유리
4. **비용**: 무료 (로컬 GPU ~3GB)
5. **환각 없음**: whisper-1의 반복 환각이나 qwen3-asr의 출력 끊김 없음

### 남은 과제
- **"테디카드" 오인식**: faster-whisper도 "테리카드"로 전사 → WHISPER_PROMPT에 "테디카드" 추가 필요
- **"이의" 오인식**: "이의 신청"을 "2일 신청"으로 → 후처리 교정 또는 prompt 튜닝
- **"김다솜" 오인식**: 3개 엔진 모두 "김다송"으로 → 고유명사 후처리 필요
- **청크 모드 테스트**: 실제 프로덕션은 1.5초 VAD 청크 → 청크 모드에서도 비교 필요
