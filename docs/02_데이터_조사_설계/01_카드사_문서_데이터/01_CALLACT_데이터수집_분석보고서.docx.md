# **CALL-ACT 프로젝트**

삼성카드·신한카드 데이터 수집 가능성 분석 보고서

작성일: 2025년 12월 30일 | 버전: 1.0

# **1\. Executive Summary**

본 보고서는 CALL-ACT(카드사 상담사 AI 지원 서비스) 프로젝트의 RAG 기반 문서 검색 시스템 구축을 위해 삼성카드와 신한카드의 데이터 수집 가능성을 분석한 결과입니다.

## **핵심 결론**

* **약관 데이터: PDF 형식으로 수동 다운로드 가능 (삼성 10개 \+ 신한 10개)**  
* **FAQ 데이터: HTML 페이지에서 수동 수집 필요 (총 200+ 문항)**  
* **상품 정보: 상품설명서 PDF 다운로드 가능, 혜택 정보는 HTML 스크래핑 필요**  
* **크롤링 제한: robots.txt에 의해 자동 크롤링 차단, 수동 수집 권장**

# **5\. 기술적 제약 사항 분석**

## **5.1 크롤링 제한 (robots.txt)**

**⚠️ CRITICAL:** 삼성카드 및 신한카드 웹사이트는 robots.txt에 의해 자동 크롤링이 차단되어 있습니다. (Error: ROBOTS\_DISALLOWED)

### **권장 수집 방법**

1. **수동 다운로드 (1순위):** PDF 파일 직접 다운로드  
2. **수동 복사 (2순위):** HTML 페이지 텍스트 복사-붙여넣기  
3. **API 요청 (3순위):** 카드사 공식 데이터 제휴 문의

## **5.2 데이터 형식별 처리 방안**

| 데이터 형식 | 처리 도구 | 고려 사항 |
| ----- | ----- | ----- |
| PDF | PyPDF2, pdfplumber, Adobe Extract API | 표, 이미지 추출 시 OCR 필요 가능성 |
| HTML | BeautifulSoup, Selenium | 동적 페이지는 Selenium 필요 |
| 텍스트 | 직접 처리 | 인코딩 확인 필요 (UTF-8) |

## **5.3 법적 고려 사항**

* **저작권:** 공개된 약관/상품정보는 출처 명시 시 내부 사용 가능  
* **이용 제한:** 데이터 재배포 불가, 교육/연구 목적 내부 사용만 허용  
* **권장 사항:** 공식 제휴 문의로 데이터 제공 요청 검토

**8\. RAG 시스템용 데이터 구조화 방안**

## **8.1 청킹 전략**

* **약관:** 조항 단위 청킹 (제1조, 제2조 등)  
* **FAQ:** Q\&A 쌍 단위 (질문+답변을 하나의 청크로)  
* **상품 정보:** 카드별 혜택, 연회비, 이용조건 분리  
* **청크 크기:** 300\~500 토큰 권장 (검색 정확도와 컨텍스트 균형)

## **8.2 메타데이터 스키마**

*모든 데이터에 다음 메타데이터를 태깅하여 검색 정확도 향상:*

| 필드명 | 설명 | 예시 |
| ----- | ----- | ----- |
| document\_type | 문서 유형 | 약관, FAQ, 상품, 서식 |
| card\_company | 카드사 | 삼성카드, 신한카드 |
| category | 분류 카테고리 | 개인, 법인, 체크카드 |
| effective\_date | 시행일/수집일 | 2024-10-17 |
| source\_url | 출처 URL | https://... |
| keywords | 관련 키워드 | \["연회비", "해지", "분실"\] |

## **8.3 예상 데이터 규모**

* 약관: 20개 문서 (삼성 10개 \+ 신한 10개)  
* FAQ: 200+ 문항  
* 카드 상품: 60+ 종  
* 총 텍스트: 약 500,000 토큰  
* 예상 청크 수: 2,000\~5,000개 (청크 크기 300\~500 토큰 기준)  
* 총 용량: 50\~100MB (PDF 포함)
