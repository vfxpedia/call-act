## 목적
CALL-ACT의 **모든 AI 기능의 기반**인 STT 시스템 구축을 위한 한국어 음성 인식 모델, API, 데이터셋 조사 및 **WER < 0.1, RTF < 0.5** 달성 가능성 검증

## 배경
- **핵심 요구사항**:
  - **WER (Word Error Rate) < 0.1**: 단어 오류율 10% 미만
  - **RTF (Real Time Factor) < 0.5**: 실시간 처리 (1분 음성을 30초 이내 변환)
  - **금융 도메인 전문 용어** 정확 인식 (카드명, 혜택명, 금융 용어)
  - **실시간 스트리밍**: 통화 중 실시간 텍스트 변환
- **활용 목적**:
  - RAG 시스템 입력 (자동 문서 검색)
  - 감정 분석 입력 (텍스트 기반)
  - 상담 후처리 (전문 작성, 요약)
  - 대화 가이드 (실시간 스크립트 제공)

## 1. 성능 지표 정의

### 1.1 WER (Word Error Rate)

**정의**: 음성 인식 정확도를 측정하는 표준 지표

```
WER = (S + D + I) / N

S (Substitutions): 잘못 인식된 단어 수
D (Deletions): 누락된 단어 수
I (Insertions): 잘못 삽입된 단어 수
N (Total Words): 전체 단어 수
```

**목표**: **WER < 0.1** (90% 이상 정확도)

**예시**:
```
정답: "신한카드 딥드림 포인트 적립률은 1퍼센트입니다"
인식: "신한카드 딥드림 포인트 적립률은 일퍼센트입니다"

S = 1 (1퍼센트 → 일퍼센트)
D = 0
I = 0
N = 8
WER = 1/8 = 0.125 (12.5% 오류율) ❌ 목표 미달
```

### 1.2 RTF (Real Time Factor)

**정의**: 음성 인식 처리 속도

```
RTF = 처리 시간 / 음성 재생 시간

RTF < 1.0 → 실시간보다 빠름
RTF = 1.0 → 실시간과 동일
RTF > 1.0 → 실시간보다 느림
```

**목표**: **RTF < 0.5** (1분 음성을 30초 이내 변환)

## 3. 금융 도메인 전문 용어 처리

### 3.1 전문 용어 예시

카드사 상담에서 자주 사용되는 전문 용어:

| 카테고리 | 용어 예시 | STT 오인식 가능성 |
|----------|-----------|-------------------|
| **카드명** | 신한카드 딥드림, 삼성카드 탭탭오, KB국민 위비 | ⚠️ 높음 (고유명사) |
| **혜택명** | 캐시백, 포인트 적립, 할인 | ✅ 낮음 |
| **금융 용어** | 연회비, 할부, 일시불, 리볼빙, 체크카드 | ⚠️ 중간 |
| **수수료** | 해외 사용 수수료, 연체 이자 | ✅ 낮음 |
| **이벤트** | 프로모션, 캠페인, 이벤트 | ✅ 낮음 |

### 3.2 전문 용어 정확도 향상 방법

#### 방법 1: 커스텀 어휘 (Custom Vocabulary)
- **지원 서비스**: Google STT, Azure, AWS
- **방법**: 자주 사용되는 카드명, 금융 용어 리스트 제공
- **효과**: WER 5~10% 개선
- **예시**:
  ```json
  {
    "phrases": [
      "신한카드 딥드림",
      "삼성카드 탭탭오",
      "KB국민 위비",
      "캐시백",
      "리볼빙"
    ]
  }
  ```

#### 방법 2: Fine-tuning (Whisper, Wav2Vec2)
- **방법**: 금융 도메인 음성 데이터로 모델 재학습
- **필요 데이터**: 최소 10~20시간 분량 금융 통화 녹음 + 전사 텍스트
- **효과**: WER 10~20% 개선
- **비용**: 높음 (데이터 수집 + GPU 학습)

#### 방법 3: 후처리 (Post-processing)
- **방법**: STT 출력 텍스트에서 오인식된 용어를 규칙 기반으로 교정
- **예시**:
  ```python
  # "신한 카드 딥 드림" → "신한카드 딥드림"
  corrections = {
      "신한 카드": "신한카드",
      "딥 드림": "딥드림",
      "탭 탭 오": "탭탭오"
  }
  ```
- **효과**: WER 3~5% 개선
- **비용**: 낮음

## 4. 실시간 스트리밍 STT 구현

### 4.1 스트리밍 방식

| 방식 | 설명 | 지연시간 | 정확도 | 적합성 |
|------|------|---------|--------|--------|
| **배치 처리** | 통화 종료 후 전체 음성 파일 변환 | 높음 (통화 종료 후) | 높음 | ❌ 실시간 가이드 불가 |
| **실시간 스트리밍** | 음성을 작은 청크로 나눠 실시간 변환 | 낮음 (< 1초) | 중간 | ✅ 실시간 가이드 가능 |

**권장**: **실시간 스트리밍** (Google STT, CLOVA CSR 지원)

### 4.2 스트리밍 구현 아키텍처

```
[고객 음성]
    ↓ (WebSocket / RTP)
[음성 청크 (0.5초)]
    ↓
[STT API (Google / CLOVA)]
    ↓
[실시간 텍스트 출력]
    ↓
[RAG 자동 검색] + [감정 분석] + [대화 가이드]
```

### 4.3 청크 크기 설정

| 청크 크기 | 지연시간 | 정확도 | 권장 용도 |
|-----------|---------|--------|-----------|
| 0.5초 | 매우 낮음 | 낮음 | 실시간 자막 |
| 1초 | 낮음 | 중간 | 실시간 가이드 |
| 2초 | 중간 | 높음 | 실시간 검색 |
| 5초 | 높음 | 매우 높음 | 배치 처리 |

**권장**: **1~2초** (실시간성과 정확도 균형)

- ✅ 안정적인 인프라
- ✅ Fine-tuning 불필요

**비용 예상** (월 기준):
- 네이버 CLOVA: 1만 통화 × 평균 5분 × 7원/15초 = 약 140만원
- Google STT: 1만 통화 × 평균 5분 × $0.006/15초 = 약 $720 (약 96만원)

---

#### **Phase 2: Whisper Fine-tuning (선택 사항)**
**기간**: 3주
**목표**: 비용 절감 + 금융 도메인 정확도 향상

| 항목 | 세부 내용 |
|------|-----------|
| 모델 | Whisper Medium |
| 데이터셋 | AI Hub 한국어 음성 (1,000시간) + 자체 수집 (10시간) |
| Fine-tuning | 금융 전문 용어 강화 |
| 배포 | AWS SageMaker / Docker |

**장점**:
- ✅ 월 비용 $0 (자체 서버)
- ✅ 금융 도메인 정확도 향상
- ✅ 데이터 외부 유출 없음

**단점**:
- ⚠️ GPU 서버 비용 (월 $200~500)
- ⚠️ 개발 시간 3주 소요
- ⚠️ 유지보수 부담

---

### 6.2 최종 권장 전략

```
1단계 (MVP) → 네이버 CLOVA CSR 사용 (즉시 구현)
2단계 (최적화) → Whisper Fine-tuning으로 비용 절감 (선택)
```

**근거**:

- 프로덕션에서 비용 문제 발생 시 → Whisper로 전환
