## 📋 문서 개요

이 문서는 CALL:ACT(카드사 콜센터용 AI 기반 상담 지원 시스템)의 전문적인 UI/UX 디자인을 Figma Make AI로 생성하기 위한 상세한 자연어 프롬프트를 제공합니다.

**언어 전략**:
- 프롬프트: 한국어 (팀 내 검토 및 협업용)
- UI 텍스트: 한국어 (실제 화면 출력)
- 영문 버전: `Figma_Make_Prompts.md` (Figma Make AI용)

**개발 연계**:
- Figma 디자인 → Figma Dev Mode → 코드 추출

- 데이터 구조: API/DB 스키마와 일치하는 JSON 형식

## 🎨 1. 프로젝트 개요

### 1.1 프로젝트 아이덴티티

**프로젝트명**: CALL:ACT
**의미**: Call + Correct (정확한 정보) + Act (효율적 행동/마무리)

**슬로건 (한글)**: "상담사에게 올바른 정보를 즉시 제공, 전화 한 통으로 완벽한 마무리를 제공하는 ONESTOP 서비스"

**슬로건 (영문)**: "ONESTOP: Correct answers at your fingertips, Every call, perfectly handled."

**핵심 가치**:
- ONESTOP: 모든 정보를 한 곳에서
- Correct: 정확한 정보
- Immediate: 즉시 접근
- Complete: 완벽한 마무리

### 1.2 대상 사용자

- 주 사용자: 카드사 고객 상담사
- 부 사용자: 콜센터 관리자 및 슈퍼바이저
- 기타 사용자: 신입 사원 교육 대상자

### 1.3 핵심 차별점

1. **상담사 보조형 AI** (고객 대체 AI가 아님) - ONESTOP 서비스
2. **실시간 STT + RAG 기반 문서 검색** - 칸반보드 형태 정보 제공
3. **실제 상담 사례 기반 시뮬레이션** - AI 페르소나 + TTS
4. 통화 중 감정 분석 + 상담 후 시각화 (부가 기능)

### 1.4 주요 기능

- **실시간 상담 (CSU)**: STT 키워드 추출, AI 칸반보드 문서 검색, 상담 가이드
- **상담 후 처리 (ACW)**: 감정 분석, 품질 피드백, AI 생성 요약, 유사 사례 참고
- **교육 시뮬레이션 (EDU)**: AI 페르소나 생성, 시나리오 연습, 평가 시스템
- **대시보드 (DASH)**: 상담 통계, 공지사항 관리, 금주의 이슈
- **관리자 관리 (ADM)**: 사원 관리, 상담 감독, 우수 사례 등록
- **프로필 & 게이미피케이션 (PROF)**: 배지 시스템, 랭킹, 월간 통계

### 3.3 실시간 상담 화면 (CSU) 🎯

#### 페이지 목적
고객 상담사가 실시간 통화 중 AI 지원을 받는 핵심 서비스 화면. STT로 추출된 키워드, 칸반보드 형태의 AI 기반 문서 검색 결과, 고객 히스토리, 직접 KMS 검색을 표시.

#### 사용자 시나리오
1. 상담사가 인입 전화 수락
2. STT가 실시간으로 키워드 추출 ("카드분실", "해외결제")
3. AI가 관련 문서를 칸반보드로 표시 (현재 상황 + 다음 단계)
4. 상담사가 권장 안내 멘트 참고
5. 상담사가 메모장에 메모 작성
6. AI가 놓친 정보는 KMS에서 직접 검색
7. 통화 종료 후 상담 후 처리로 이동

## 5. 문서 요약 및 사용 가이드

### 5.1 페이지 개요

이 문서는 **9개 메인 페이지 + 4개 공통 모달**을 위한 종합 Figma Make 프롬프트를 포함합니다:

**우선순위 1 (핵심 서비스)**:
1. 로그인 페이지
2. 메인 대시보드
3. 실시간 상담 (CSU) - 3열 레이아웃
4. 상담 후 처리 (ACW) - 2열 레이아웃

**우선순위 2 (높은 중요도)**:
5. 교육 시뮬레이션 (4개 하위 화면)
6. 관리자 - 총괄 현황
7. 관리자 - 사원 관리
8. 관리자 - 상담 관리 (인라인 오디오 플레이어 포함)

**우선순위 3 (지원 기능)**:
9. 프로필 페이지 (게이미피케이션 포함)

**공통 모달**:
- 상담 상세보기 모달
- 문서 상세보기 모달
- 공지사항/이슈 상세보기 모달
- 우수 사례 등록 모달

### 5.2 프롬프트 사용 방법

1. **원하는 페이지의 프롬프트 복사** 위의 코드 블록에서
2. **Figma Make에 붙여넣기** (AI 디자인 생성 기능)
3. **생성된 디자인 검토** 및 필요에 따라 반복
4. **Figma Dev Mode로 내보내기** React 코드 추출
5. **Mock 데이터와 통합** 초기에, 이후 FastAPI 백엔드 + PostgreSQL 연결

### 5.3 디자인 시스템 일관성

모든 프롬프트는 확립된 디자인 시스템을 따릅니다:
- **색상**: Primary Blue (#0047AB), Success Green (#34A853) 등
- **타이포그래피**: Pretendard 글꼴 패밀리, 일관된 크기 스케일
- **간격**: 8px 베이스 그리드
- **컴포넌트**: 표준화된 버튼, 입력, 카드, 모달

### 5.4 데이터 구조 통합

각 프롬프트는 다음을 포함합니다:
- **컴포넌트 네이밍** (PascalCase): `CallHistoryCard`, `KanbanBoard`
- **데이터 필드 네이밍** (camelCase): `consultationId`, `customerId`
- **Mock 데이터 예시** 향후 API/DB 스키마와 일치하는 JSON 형식

### 5.5 다음 단계

Figma 디자인 완료 후:
1. 일관성을 위해 모든 디자인 검토

4. Figma Dev Mode에서 코드 내보내기

6. FastAPI 백엔드 연결
7. PostgreSQL 데이터베이스와 통합
8. 실제 사용자와 배포 및 테스트
