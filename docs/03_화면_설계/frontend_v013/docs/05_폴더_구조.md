#### 2.2.3 /contexts (Context API)

```
src/app/contexts/
└── SidebarContext.tsx          # 사이드바 상태 관리
```

**SidebarContext**:
```tsx
interface SidebarContextType {
  isSidebarOpen: boolean;        // 사이드바 열림/닫힘 상태
  toggleSidebar: () => void;     // 토글 함수
}
```

**사용법**:
```tsx
import { useSidebar } from '@/app/contexts/SidebarContext';

function MyComponent() {
  const { isSidebarOpen, toggleSidebar } = useSidebar();
  return <button onClick={toggleSidebar}>토글</button>;
}
```

## 6. Import Path Alias

### 6.1 @ Alias 사용

Vite 설정으로 `@`를 `/src`로 매핑했습니다:

```typescript
// ✅ 올바른 import (권장)
import { Button } from '@/app/components/ui/button';
import { mockData } from '@/data/mockData';
import '@/styles/index.css';

// ❌ 상대 경로 (지양)
import { Button } from '../../../components/ui/button';
import { mockData } from '../../data/mockData';
```

### 6.2 Import 순서

**권장 순서**:
1. React 및 외부 라이브러리
2. 내부 컴포넌트 (`@/app/components`)
3. 페이지 (`@/app/pages`)
4. 유틸리티 (`@/app/utils`)
5. 데이터 (`@/data`)
6. 스타일 (`@/styles`)

```typescript
// 1. React 및 외부 라이브러리
import { useState, useEffect } from 'react';
import { useNavigate } from 'react-router-dom';

// 2. 내부 컴포넌트
import { Button } from '@/app/components/ui/button';
```
