## 1. 개요

### 1.1 목적
RealTimeConsultationPage(실시간 상담 페이지)에서 AI 검색 어시스턴트를 통한 '검색 레이어' 시스템을 구현합니다. 기존 칸반보드(현재 상황 + 다음 단계 예상 카드) 영역에 검색 결과를 표시하는 별도 레이어를 추가하여, 휠/키보드로 두 레이어 간 전환이 가능하도록 합니다.

### 1.2 핵심 요구사항 요약
- 검색 레이어와 칸반 레이어 간 슬라이딩 전환
- 모든 해상도에서 스크롤 없이 fit하게 표시 (비율 유지)
- 검색 결과는 세션 내내 유지, 새 상담 시작 시 초기화
- 타임스탬프, 검색 카드 스타일, 빈 공간 디자인 등 UI 세부사항

## 2. 레이어 시스템

### 2.1 레이어 구성
| 레이어 | 설명 | 표시 조건 |
|--------|------|----------|
| **칸반 레이어** | 기존 화면 (현재 상황 2개 + 다음 단계 예상 2개) | 기본 상태 |
| **검색 레이어** | 검색 결과 카드들 (최대 4개, 2x2 그리드) | 검색 실행 시 |

### 2.2 레이어 전환 방식
- **전환 방향**: 항상 **위에서 아래로 슬라이딩**
- **전환 트리거**:
  - 검색 실행 직후 → 자동으로 검색 레이어로 전환
  - 휠 다운 → 레이어 전환
  - 아래 방향키 → 레이어 전환 (카드 2개 이후)
- **무한 순환**: 검색 레이어 → 칸반 레이어 → 검색 레이어 → ...

### 2.3 시나리오별 동작

#### Case 1: 대기 중 검색 → 인입 발생
```
[대기 중]
검색 "포인트 조회" → 검색 레이어 (검색 1, 2)
         ↓
[인입 발생]
→ 칸반 레이어로 자동 전환
→ 검색 레이어는 유지 (휠/키로 다시 접근 가능)
```

#### Case 2: 상담 중 검색 (기존 검색 있음)
```
[상담 중]
기존: 검색 레이어 (검색 1, 2 / 빈 공간)
새 검색 "적립 실패" 실행
         ↓
검색 레이어 업데이트:
┌─────┬─────┐
│검색3│검색4│ ← 최신 (방금 검색)
├─────┼─────┤
│검색1│검색2│ ← 이전 (대기 중 검색)
└─────┴─────┘
```

#### Case 3: 상담 중 검색 (검색 없음)
```
[상담 중]
검색 "포인트 조회" → 검색 레이어 생성
┌─────┬─────┐
│검색1│검색2│
├─────┼─────┤
│빈공간│빈공간│
└─────┴─────┘
```

**핵심**: 검색 레이어는 세션 내내 유지, 새 검색은 위에 쌓임

## 5. 검색 기능 명세

### 5.1 검색 로딩

| 항목 | 값 |

### 5.2 검색 이력 드롭다운

| 항목 | 값 |
|------|-----|
| **위치** | AI 검색 어시스턴트 하단 |

| **초기화 조건** | 새 상담 시작 시 (다른 대기콜 잡거나 새 통화 시작) |

### 5.3 검색 버튼 위치
- **검색창 하단에 배치** (우측 아님)

### 5.4 상담 대기 중 검색 기능 ⚠️ 중요

| 상태 | 검색 활성화 | 검색 결과 표시 | 검색 이력 저장 |
|------|------------|---------------|---------------|
| **대기 중 (대기콜 선택 전)** | ✅ 활성화 | ✅ 검색 레이어 | ✅ 저장 |
| **대기 중 (대기콜 선택 후)** | ✅ 활성화 | ✅ 검색 레이어 | ✅ 저장 |
| **상담 중 (통화 중)** | ✅ 활성화 | ✅ 검색 레이어 | ✅ 저장 |

> **핵심**: 검색 기능과 이력 저장은 **항상 활성화** 상태. 대기 중/통화 중 구분 없이 검색 가능하고 이력 저장됩니다.

#### 대기 중 검색 시나리오
```
[대기 중 - 대기콜 없음 또는 선택됨]
상담사가 미리 "포인트 조회" 검색
         ↓
검색 결과 카드 2개 표시 (검색 레이어)
- 타임스탬프: "14:30 (방금 전)"
- 검색 이력: ✅ 저장됨
         ↓
[인입 발생 - 통화 시작]
→ 칸반 레이어로 자동 전환 (AI 추천 카드 표시)
→ 검색 레이어는 그대로 유지 (휠/방향키로 다시 접근 가능)
→ 대기 중 검색 이력도 유지됨
```

#### ⚠️ 후처리 참조 문서 vs 검색 이력 (중요 구분)

| 구분 | 검색 이력 | 후처리 참조 문서 |
|------|----------|-----------------|
| **목적** | UI 표시용 (드롭다운) | 업무 기록용 (후처리 페이지) |
| **저장 시점** | 검색 실행 시 (항상) | 통화 중 문서 참조 시 |
| **대기 중 검색** | ✅ 저장 | ❌ 반영 안함 |
| **통화 중 검색** | ✅ 저장 | ✅ 반영 |

> **후처리 참조 문서 규칙**: 실제 **통화 중**에 **검색 실행**된 문서만 후처리 페이지 참조 문서 리스트에 반영됩니다.
>
> **향후 확장 예정**: 대기 중 검색했지만 통화 중 다시 참조(클릭)한 문서도 포함하도록 확장 가능 (별도 명세 예정)

#### 구현 코드 (상태 구조)

```tsx
// 검색 결과 블록 타입
interface SearchBlock {
  id: string;
  cards: [ScenarioCard, ScenarioCard]; // 항상 2개
  searchedAt: string; // ISO timestamp
}

// 검색 레이어 상태
const [searchBlocks, setSearchBlocks] = useState<SearchBlock[]>([]);
const [currentBlockIndex, setCurrentBlockIndex] = useState(0); // 드래그로 변경

// 새 검색 시 블록 추가
const addSearchResult = (newCards: ScenarioCard[]) => {
  const newBlock: SearchBlock = {
    id: `SEARCH-BLOCK-${Date.now()}`,
    cards: [newCards[0], newCards[1]],
    searchedAt: new Date().toISOString()
  };

  setSearchBlocks(prev => [...prev, newBlock]);
  setCurrentBlockIndex(prev => prev + 1); // 최신 블록으로 이동
};

// 화면에 표시할 2x2 계산
const getVisibleCards = () => {
  const totalBlocks = searchBlocks.length;
  if (totalBlocks === 0) return { row1: null, row2: null };

  // 현재 블록 인덱스 기준으로 2x2 구성
  const blockPairIndex = Math.floor(currentBlockIndex / 2);
  const row1Block = searchBlocks[blockPairIndex * 2 + 1]; // 최신
  const row2Block = searchBlocks[blockPairIndex * 2];     // 이전

  return {
    row1: row1Block?.cards || null,
    row2: row2Block?.cards || null
  };
};
```

#### 드래그 제스처 구현

```tsx
// 드래그로 과거 블록 조회
const handleDragEnd = (info: PanInfo) => {
  const threshold = 100; // 드래그 임계값
  const maxBlockPairs = Math.ceil(searchBlocks.length / 2);

  if (info.offset.x > threshold) {
    // 우→좌 드래그: 과거 블록으로
    setCurrentBlockIndex(prev => Math.max(0, prev - 2));
  } else if (info.offset.x < -threshold) {
    // 좌→우 드래그: 최신 블록으로
    setCurrentBlockIndex(prev => Math.min((maxBlockPairs - 1) * 2, prev + 2));
  }
};
```

## 5A. 키보드/휠 네비게이션 기능 명세

### 5A.1 개요 - 네비게이션 원칙

#### 핵심 규칙: "경계 벗어남 = 전환"

| 입력 방식 | 역할 | 동작 |
|----------|------|------|
| **방향키** | 정밀 카드 네비게이션 | 카드 → 카드 이동, 경계 벗어나면 레이어/Step 전환 |
| **휠** | 빠른 레이어 전환 | 즉시 레이어 전환 (카드 위치 무관) |

#### Step 흐름 방향 (칸반 레이어)

```
← 과거 (좌)                                      최신 (우) →
┌───────────┐      ┌───────────┐      ┌───────────┐
│  Step 1   │  ←   │  Step 2   │  ←   │  Step 3   │
│ (최초     │      │ (추가     │      │ (최신     │
│  키워드)  │      │  키워드)  │      │  키워드)  │
└───────────┘      └───────────┘      └───────────┘

※ 새 키워드 발생 시 → 우측에 새 Step 추가, 기존 Step은 좌측으로 이동
```

### 5A.2 단축키 목록

| 단축키 | 기능 | 동작 상세 |
|--------|------|----------|
| `↑` (위 방향키) | 위 카드로 이동 | 2x2 내 위로 이동, 맨 위 경계에서 → 레이어 전환 |
| `↓` (아래 방향키) | 아래 카드로 이동 | 2x2 내 아래로 이동, 맨 아래 경계에서 → 레이어 전환 |
| `←` (왼쪽 방향키) | 왼쪽 카드/Step 이동 | 2x2 내 왼쪽 이동, 좌측 경계에서 → 이전 Step으로 |
| `→` (오른쪽 방향키) | 오른쪽 카드/Step 이동 | 2x2 내 오른쪽 이동, 우측 경계에서 → 다음 Step으로 |
| `Enter` | 검색 실행 | 검색창 포커스 + 텍스트 입력 시 |
| `Esc` | 검색 취소 / 모달 닫기 | 검색창 포커스 해제 또는 모달 닫기 |
| `/` (슬래시) | 검색창 포커싱 | 다른 입력 필드에 포커스 없을 때 |

### 5A.3 방향키 카드 네비게이션 상세

#### 2x2 카드 그리드 내 이동

```
┌─────────┬─────────┐
│ [0,0]   │ [0,1]   │  ← 현재 상황 카드 (상단)
│ 카드1   │ 카드2   │
├─────────┼─────────┤
│ [1,0]   │ [1,1]   │  ← 다음 단계 예상 카드 (하단)
│ 카드3   │ 카드4   │
└─────────┴─────────┘

방향키 이동 예시:
- 카드1 → ↓ → 카드3
- 카드1 → → → 카드2
- 카드2 → ↓ → 카드4
- 카드3 → ↑ → 카드1
```

#### 경계 벗어남 시 동작

**상하 경계 (레이어 전환)**:
```
[검색 레이어]
┌─────┬─────┐
│검색1│검색2│ ← 여기서 ↑ → 칸반 레이어 맨 아래로 진입
├─────┼─────┤
│검색3│검색4│ ← 여기서 ↓ → 칸반 레이어 맨 위로 진입
└─────┴─────┘
      ↕ (양방향 순환)
[칸반 레이어]
┌─────┬─────┐
│현재1│현재2│ ← 여기서 ↑ → 검색 레이어 맨 아래로 진입
├─────┼─────┤
│예상1│예상2│ ← 여기서 ↓ → 검색 레이어 맨 위로 진입
└─────┴─────┘
```

**좌우 경계 (Step 전환 - 칸반 레이어만)**:
```
Step 1 (과거)              Step 2 (최신)
┌─────┬─────┐           ┌─────┬─────┐
│카드1│카드2│ ←← 좌측   │카드1│카드2│
├─────┼─────┤  경계에서  ├─────┼─────┤
│카드3│카드4│ ←← ← 누름  │카드3│카드4│
└─────┴─────┘           └─────┴─────┘

※ Step 1 좌측 경계 → ← 누름 → 더 이상 이동 없음 (끝)
※ 최신 Step 우측 경계 → → 누름 → 더 이상 이동 없음 (끝)
```

#### 레이어 전환 시 진입 위치 규칙

| 나간 방향 | 진입 위치 | 예시 |
|----------|----------|------|
| 맨 아래에서 ↓ | 다음 레이어 **맨 위** | 칸반 맨 아래 → ↓ → 검색 맨 위 |
| 맨 위에서 ↑ | 다음 레이어 **맨 아래** | 칸반 맨 위 → ↑ → 검색 맨 아래 |

> **UX 원칙**: 연속 스크롤 느낌 - 아래로 나가면 위에서 진입, 위로 나가면 아래에서 진입

#### 구현 코드

```tsx
// 필요한 상태
const [focusedCard, setFocusedCard] = useState<{row: number, col: number}>({row: 0, col: 0});
const [activeLayer, setActiveLayer] = useState<'kanban' | 'search'>('kanban');
const [currentStep, setCurrentStep] = useState(0); // 칸반 레이어의 현재 Step

useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    // 입력 필드에 포커스 있으면 무시
    if (e.target instanceof HTMLInputElement ||
        e.target instanceof HTMLTextAreaElement) {
      return;
    }

    const { row, col } = focusedCard;
    const maxRow = 1; // 2x2 그리드 (0, 1)
    const maxCol = 1;

    switch (e.key) {
      case 'ArrowUp':
        e.preventDefault();
        if (row > 0) {
          // 2x2 내부 이동
          setFocusedCard({ row: row - 1, col });
        } else {
          // 맨 위 경계 → 다른 레이어 맨 아래로 전환
          setActiveLayer(prev => prev === 'kanban' ? 'search' : 'kanban');
          setFocusedCard({ row: maxRow, col }); // 맨 아래로 진입
        }
        break;

      case 'ArrowDown':
        e.preventDefault();
        if (row < maxRow) {
          // 2x2 내부 이동
          setFocusedCard({ row: row + 1, col });
        } else {
          // 맨 아래 경계 → 다른 레이어 맨 위로 전환
          setActiveLayer(prev => prev === 'kanban' ? 'search' : 'kanban');
          setFocusedCard({ row: 0, col }); // 맨 위로 진입
        }
        break;

      case 'ArrowLeft':
        e.preventDefault();
        if (col > 0) {
          // 2x2 내부 이동
          setFocusedCard({ row, col: col - 1 });
        } else if (activeLayer === 'kanban' && currentStep > 0) {
          // 칸반 레이어: 이전 Step으로 전환
          setCurrentStep(prev => prev - 1);
          setFocusedCard({ row, col: maxCol }); // 우측 카드로 진입
        }
        // 검색 레이어는 좌측 경계에서 아무 동작 없음
        break;

      case 'ArrowRight':
        e.preventDefault();
        if (col < maxCol) {
          // 2x2 내부 이동
          setFocusedCard({ row, col: col + 1 });
        } else if (activeLayer === 'kanban' && currentStep < maxStep - 1) {
          // 칸반 레이어: 다음 Step으로 전환
          setCurrentStep(prev => prev + 1);
          setFocusedCard({ row, col: 0 }); // 좌측 카드로 진입
        }
        // 검색 레이어는 우측 경계에서 아무 동작 없음
        break;

      case '/':
        e.preventDefault();
        searchInputRef.current?.focus();
        break;

      case 'Escape':
        if (document.activeElement === searchInputRef.current) {
          searchInputRef.current?.blur();
        } else if (isModalOpen) {
          setIsModalOpen(false);
        }
        break;
    }
  };

  window.addEventListener('keydown', handleKeyDown);
  return () => window.removeEventListener('keydown', handleKeyDown);
}, [focusedCard, activeLayer, currentStep, isModalOpen]);
```

### 5A.4 휠 스크롤 레이어 전환

#### 동작 규칙

| 동작 | 결과 | 진입 위치 |
|------|------|----------|
| 휠 다운 (아래로 스크롤) | 다른 레이어로 전환 | 맨 위에서 진입 |
| 휠 업 (위로 스크롤) | 다른 레이어로 전환 | 맨 아래에서 진입 |

> **휠 특징**: 현재 카드 위치와 무관하게 **즉시 레이어 전환** (방향키와 차별화)

#### 구현 코드

```tsx
const [isWheelThrottled, setIsWheelThrottled] = useState(false);

useEffect(() => {
  const handleWheel = (e: WheelEvent) => {
    // 카드 영역 내에서만 레이어 전환
    const cardArea = document.getElementById('card-layer-area');
    if (!cardArea?.contains(e.target as Node)) return;

    // 쓰로틀링 (400ms) - 과도한 전환 방지
    if (isWheelThrottled) return;
    setIsWheelThrottled(true);
    setTimeout(() => setIsWheelThrottled(false), 400);

    if (e.deltaY > 0) {
      // 휠 다운 → 다른 레이어, 맨 위로 진입
      setActiveLayer(prev => prev === 'kanban' ? 'search' : 'kanban');
      setFocusedCard({ row: 0, col: focusedCard.col });
    } else if (e.deltaY < 0) {
      // 휠 업 → 다른 레이어, 맨 아래로 진입
      setActiveLayer(prev => prev === 'kanban' ? 'search' : 'kanban');
      setFocusedCard({ row: 1, col: focusedCard.col });
    }
  };

  window.addEventListener('wheel', handleWheel, { passive: false });
  return () => window.removeEventListener('wheel', handleWheel);
}, [isWheelThrottled, focusedCard.col]);
```

    const result = await simulateSearch(query);

    if (isCallActive && result.cards.length > 0) {
      const historyItem = saveSearchHistory(result);

    setSearchQuery('');
  }
