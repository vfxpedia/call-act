## 3. 시스템 아키텍처 개요

### 3.1 기술 스택

- **Frontend**: React + TypeScript + Tailwind CSS
- **Backend**: FastAPI + Python
- **Database**: PostgreSQL (RDB, VectorDB)
- **AI/ML**: OpenAI gpt-4.1-mini, Embedding API
- **STT**: 음성인식 시스템 (Whisper 등)

### 3.2 핵심 기능

1. **실시간 상담 지원**: STT 기반 키워드 추출 → RAG 검색 → 칸반보드 자동 표시
2. **AI 검색 어시스턴트**: 상담사 질문에 즉시 답변 (GPT-4 기반)
3. **상담 후처리 자동화**: AI 요약, 유사 사례 추천
4. **통계 대시보드**: 실시간 상담 통계 및 트렌드 분석

## 4. 데이터 흐름

### 4.1 실시간 상담

```
고객 전화 → STT → 키워드 추출 → VectorDB 검색 → 칸반보드 표시
```

### 4.2 상담 후처리

```
상담 종료 → 전문 저장 → AI 요약 → 유사 사례 검색 → 문서 저장
```
