## 1. 프론트엔드

### 1.1 코어 프레임워크

#### React 18.3.1
- **용도**: UI 라이브러리

### 1.2 빌드 도구

#### Vite 6.3.5
- **용도**: 차세대 프론트엔드 빌드 도구
- **특징**:
  - ⚡ 빠른 개발 서버 시작 (콜드 스타트 < 1초)
  - 🔥 Hot Module Replacement (HMR)
  - 📦 최적화된 프로덕션 빌드
  - 🎯 네이티브 ESM 지원
- **성능**:
  - 개발 서버 시작: **0.5초**
  - HMR: **50ms 이하**
  - 프로덕션 빌드: **10-15초**

```bash
# 개발 서버 실행
npm run dev  # → http://localhost:5173

# 프로덕션 빌드
npm run build  # → /dist 폴더에 출력
```

### 3.2 벡터 데이터베이스

#### pgvector
- **용도**: PostgreSQL 벡터 검색 확장
- **특징**:
  - 🔍 벡터 유사도 검색
  - 📈 고차원 벡터 지원 (최대 2,000차원)
  - ⚡ 빠른 검색 속도 (HNSW 인덱스)
  - 🔧 PostgreSQL과 완벽 통합
- **사용 범위**:
  - 문서 임베딩 저장
  - RAG 검색
  - 유사 상담 사례 검색
- **벡터 검색 방식**:
  - Cosine Similarity (코사인 유사도)
  - L2 Distance (유클리드 거리)
  - Inner Product (내적)

```sql
-- pgvector 사용 예시
CREATE EXTENSION vector;

CREATE TABLE documents (
  id SERIAL PRIMARY KEY,
  content TEXT,
  embedding vector(1536)  -- OpenAI Embedding 차원
);

-- 유사도 검색
SELECT * FROM documents
ORDER BY embedding <-> '[0.1, 0.2, ...]'
LIMIT 5;
```

- **용도**: 자연어 처리, 답변 생성

  - 상담 자동 요약
  - Next Action 제안
- **API 호출 예시**:
  ```python
  response = openai.ChatCompletion.create(
    model="gpt-4.1-mini",
    messages=[

      {"role": "user", "content": "카드 분실 신고 방법"}

  ```
