## 2. Layout 컴포넌트

### 2.1 MainLayout

#### 2.1.1 개요

**경로**: `/src/app/components/layout/MainLayout.tsx`

**역할**: 대부분의 페이지에서 사용하는 기본 레이아웃 (Header + Sidebar + Content)

**사용 페이지**: Dashboard, RealTimeConsultation, ConsultationHistory 등 (LandingPage, LoginPage 제외)

#### 2.1.2 구조

```tsx
import Header from './Header';
import Sidebar from './Sidebar';
import { SidebarProvider } from '../../contexts/SidebarContext';

export default function MainLayout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <div className="flex h-screen overflow-hidden bg-gray-50">
        {/* 좌측 사이드바 */}
        <Sidebar />
        
        <div className="flex flex-col flex-1 overflow-hidden">
          {/* 상단 헤더 */}
          <Header />
          
          {/* 메인 콘텐츠 */}
          <main className="flex-1 overflow-auto p-6">
            {children}
          </main>
        </div>
      </div>
    </SidebarProvider>
  );
}
```

#### 2.1.3 사용 방법

```tsx
// DashboardPage.tsx
import MainLayout from '../components/layout/MainLayout';

export default function DashboardPage() {
  return (
    <MainLayout>
      <h1>대시보드</h1>
      {/* 페이지 내용 */}
    </MainLayout>
  );
}
```

#### 2.3.1 개요

**경로**: `/src/app/components/layout/Sidebar.tsx`

**역할**: 좌측 사이드바 네비게이션

#### 2.3.2 메뉴 구조

```typescript
const menuItems = [
  {
    title: '대시보드',
    icon: <LayoutDashboard />,
    path: '/dashboard',

  },
  {

    role: 'agent' // 상담사만
  },
  {
    title: '상담 이력',
    icon: <Clock />,
    path: '/consultation/history',
    role: 'agent'
  },
  {
    title: '사원 관리',
    icon: <Users />,
    path: '/employees',
    role: 'admin' // 관리자만
  },
  {
    title: '통계',
    icon: <BarChart />,
    path: '/admin/stats',
    role: 'admin'
  },
  {
    title: '공지사항',
    icon: <Bell />,
    path: '/notice',
    role: 'all'
  }
];
```

#### 2.3.3 권한 기반 메뉴 표시

```tsx
const userRole = localStorage.getItem('userRole') || 'agent';

const visibleMenuItems = menuItems.filter(item => {
  if (item.role === 'all') return true;
  if (item.role === 'admin' && userRole !== 'admin') return false;
  if (item.role === 'agent' && userRole === 'admin') return true;
  return true;
});

return (
  <aside className="sidebar">
    {visibleMenuItems.map(item => (
      <Link 
        key={item.path} 
        to={item.path}
        className={cn(
          "menu-item",
          location.pathname === item.path && "active"
        )}
      >
        {item.icon}
        <span>{item.title}</span>
      </Link>
    ))}
  </aside>
);
```

#### 2.3.4 접기/펼치기 기능

```tsx
import { useSidebar } from '../../contexts/SidebarContext';

const { isSidebarOpen } = useSidebar();

<aside className={cn(
  "sidebar",
  isSidebarOpen ? "w-64" : "w-20"
)}>
  {/* 메뉴 항목 */}
  {isSidebarOpen && <span>{item.title}</span>}
</aside>
```

### 3.5 ChangePasswordModal

#### 3.5.1 개요

**경로**: `/src/app/components/modals/ChangePasswordModal.tsx`

**역할**: 비밀번호 변경 모달

#### 3.5.2 Props

```typescript
interface ChangePasswordModalProps {
  isOpen: boolean;
  onClose: () => void;
  onSubmit: (oldPassword: string, newPassword: string) => void;
}
```

#### 3.5.3 폼 구조

```tsx
<form onSubmit={handleSubmit}>
  <div className="space-y-4">
    <div>
      <Label htmlFor="oldPassword">현재 비밀번호</Label>
      <Input 
        id="oldPassword" 
        type="password"
        value={oldPassword}
        onChange={(e) => setOldPassword(e.target.value)}
        required
      />
    </div>
    
    <div>
      <Label htmlFor="newPassword">새 비밀번호</Label>
      <Input 
        id="newPassword" 
        type="password"
        value={newPassword}
        onChange={(e) => setNewPassword(e.target.value)}
        required
        minLength={8}
      />
      <p className="text-xs text-gray-600 mt-1">
        최소 8자 이상, 영문/숫자/특수문자 조합
      </p>
    </div>
    
    <div>
      <Label htmlFor="confirmPassword">새 비밀번호 확인</Label>
      <Input 
        id="confirmPassword" 
        type="password"
        value={confirmPassword}
        onChange={(e) => setConfirmPassword(e.target.value)}
        required
      />
      {confirmPassword && newPassword !== confirmPassword && (
        <p className="text-xs text-red-600 mt-1">
          비밀번호가 일치하지 않습니다
        </p>
      )}
    </div>
  </div>
  
  <div className="mt-6 flex justify-end gap-2">
    <Button type="button" variant="outline" onClick={onClose}>
      취소
    </Button>
    <Button type="submit" disabled={newPassword !== confirmPassword}>
      변경
    </Button>
  </div>
</form>
```

#### 4.2.1 Button

**파일**: `button.tsx`

**사용법**:
```tsx
import { Button } from '@/app/components/ui/button';

<Button>기본 버튼</Button>
<Button variant="outline">아웃라인</Button>
<Button variant="destructive">삭제</Button>
<Button variant="ghost">고스트</Button>
<Button size="sm">작은 버튼</Button>
<Button size="lg">큰 버튼</Button>
<Button disabled>비활성화</Button>
```

**Variants**:
- `default`: 기본 (블루 배경)
- `outline`: 테두리만
- `ghost`: 투명 배경
- `destructive`: 위험 (빨강)
- `link`: 링크 스타일

**Sizes**:
- `sm`: 작은 크기
- `default`: 기본 크기
- `lg`: 큰 크기
- `icon`: 아이콘 전용 (정사각형)

### 5.2 필터링 가능한 테이블

```tsx
import { Table, TableHeader, TableHead, TableBody, TableRow, TableCell } from '@/app/components/ui/table';
import { Input } from '@/app/components/ui/input';
import { Select } from '@/app/components/ui/select';
import { Badge } from '@/app/components/ui/badge';
import Pagination from '@/app/components/ui/Pagination';

function ConsultationTable() {
  const [searchQuery, setSearchQuery] = useState('');
  const [categoryFilter, setCategoryFilter] = useState('전체');
  const [currentPage, setCurrentPage] = useState(1);
  
  const itemsPerPage = 10;
  
  const filteredData = consultationsData.filter(c => {
    if (categoryFilter !== '전체' && c.category !== categoryFilter) return false;
    if (searchQuery && !c.id.includes(searchQuery)) return false;
    return true;
  });
  
  const totalPages = Math.ceil(filteredData.length / itemsPerPage);
  const startIndex = (currentPage - 1) * itemsPerPage;
  const currentData = filteredData.slice(startIndex, startIndex + itemsPerPage);
  
  return (
    <div>
      {/* 필터 */}
      <div className="flex gap-4 mb-4">
        <Input 
          placeholder="상담 ID 검색"
          value={searchQuery}
          onChange={(e) => setSearchQuery(e.target.value)}
        />
        <Select value={categoryFilter} onValueChange={setCategoryFilter}>
          <SelectTrigger>
            <SelectValue />
          </SelectTrigger>
          <SelectContent>
            <SelectItem value="전체">전체</SelectItem>
            <SelectItem value="카드분실">카드분실</SelectItem>
            <SelectItem value="해외결제">해외결제</SelectItem>
          </SelectContent>
        </Select>
      </div>
      
      {/* 테이블 */}
      <Table>
        <TableHeader>
          <TableRow>
            <TableHead>ID</TableHead>
            <TableHead>카테고리</TableHead>
            <TableHead>고객명</TableHead>
            <TableHead>상태</TableHead>
          </TableRow>
        </TableHeader>
        <TableBody>
          {currentData.map(c => (
            <TableRow key={c.id}>
              <TableCell>{c.id}</TableCell>
              <TableCell>
                <Badge>{c.category}</Badge>
              </TableCell>
              <TableCell>{c.customer}</TableCell>
              <TableCell>{c.status}</TableCell>
            </TableRow>
          ))}
        </TableBody>
      </Table>
      
      {/* 페이지네이션 */}
      <Pagination 
        currentPage={currentPage}
        totalPages={totalPages}
        onPageChange={setCurrentPage}
      />
    </div>
  );
}
```

## 6. 커스텀 컴포넌트 작성 가이드

### 6.1 컴포넌트 파일 구조

```tsx
// /src/app/components/MyComponent.tsx
import { useState } from 'react';
import { Button } from './ui/button';
import { Card } from './ui/card';

interface MyComponentProps {
  title: string;
  onSubmit: (value: string) => void;
}

export default function MyComponent({ title, onSubmit }: MyComponentProps) {
  const [value, setValue] = useState('');
  
  const handleSubmit = () => {
    onSubmit(value);
    setValue('');
  };
  
  return (
    <Card>
      <h2>{title}</h2>
      <input 
        value={value}
        onChange={(e) => setValue(e.target.value)}
      />
      <Button onClick={handleSubmit}>제출</Button>
    </Card>
  );
}
```

### 6.2 Props 타입 정의

```typescript
// TypeScript 인터페이스 사용
interface ComponentProps {
  // 필수 props
  title: string;
  count: number;
  
  // 선택 props
  subtitle?: string;
  
  // 함수 props
  onClick: () => void;
  onChange: (value: string) => void;
  
  // React Node (JSX 허용)
  children?: React.ReactNode;
  
  // 배열
  items: string[];
  
  // 객체 배열
  users: Array<{ id: string; name: string }>;
}
```

### 6.3 네이밍 컨벤션

**컴포넌트명**: PascalCase
```tsx
// ✅ 올바른 예
function UserProfile() {}
function ConsultationTable() {}

// ❌ 잘못된 예
function userProfile() {}
function consultation_table() {}
```

**Props명**: camelCase
```tsx
// ✅ 올바른 예
interface Props {
  userName: string;
  isActive: boolean;
  onButtonClick: () => void;
}

// ❌ 잘못된 예
interface Props {
  UserName: string;
  is_active: boolean;
  OnButtonClick: () => void;
}
```

### 6.4 컴포넌트 재사용성 팁

**1. Props로 데이터 전달**
```tsx
// ❌ 나쁜 예: 컴포넌트 내부에서 데이터 가져오기
function UserList() {
  const users = JSON.parse(localStorage.getItem('users'));
  return <ul>{users.map(u => <li>{u.name}</li>)}</ul>;
}

// ✅ 좋은 예: Props로 데이터 받기
function UserList({ users }) {
  return <ul>{users.map(u => <li>{u.name}</li>)}</ul>;
}
```

**2. 이벤트 핸들러는 Props로 전달**
```tsx
// ✅ 좋은 예
function Button({ onClick, children }) {
  return <button onClick={onClick}>{children}</button>;
}

// 사용
<Button onClick={() => console.log('Clicked!')}>클릭</Button>
```

**3. Children 활용**
```tsx
function Card({ children }) {
  return <div className="card">{children}</div>;
}

// 사용
<Card>
  <h2>제목</h2>
  <p>내용</p>
</Card>
```
