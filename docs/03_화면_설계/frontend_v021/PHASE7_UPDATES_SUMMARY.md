## 🔧 사용자 요청사항

### 엑셀 다운로드
> "엑셀에 고객명 -> 개인 정보이 때문에 우리는 고객명을 저장하지 않고 customer_id 로 명시합니다.
> 그래서 고객 DB에도 우리는 customer_id로 고객명을 불러올 생각입니다. -> 보안상
> 그래서 엑셀에도 customer_id로 진행하는 것이 좋을 것 같습니다.
> 그리고 전화번호도 현재 상담 내역, 상담 관리 컬럼에는 없으니 해당 컬럼은 뺄까요?
> 그리고 실제로 excel을 다운로드 했는데, 상담 내용에 해당하는 내용은 저장이 되지 않네요?
> 이 부분도 실제 DB에서 가져올 것이지만, 현재 엑셀 다운로드에 '요약'이라는 컬럼이라고 있지만, 상담 내용에 대한 내용은 기재 되지 않습니다."

**✅ 해결:**
- customer_id 사용
- 전화번호 제거
- content 필드 사용하여 실제 상담 내용 저장
