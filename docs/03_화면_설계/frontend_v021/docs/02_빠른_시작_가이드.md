## 4. 환경 변수 설정

### 4.1 .env 파일 생성

프로젝트 루트에 `.env` 파일을 생성합니다:

```bash
# .env 파일 생성
touch .env
```

### 4.2 환경 변수 설정 (개발 환경)

`.env` 파일에 다음 내용을 추가합니다:

```env
# 개발 환경 설정
VITE_API_URL=http://localhost:8000
VITE_WS_URL=ws://localhost:8000/ws

# OpenAI API (선택 사항 - 백엔드에서 사용)
# VITE_OPENAI_API_KEY=your-api-key-here

# 환경 구분
VITE_ENV=development
```

### 4.3 환경 변수 설명

| 변수명 | 설명 | 기본값 | 필수 여부 |
|--------|------|--------|-----------|
| `VITE_API_URL` | 백엔드 API 서버 주소 | http://localhost:8000 | ✅ 필수 |
| `VITE_WS_URL` | WebSocket 서버 주소 | ws://localhost:8000/ws | ✅ 필수 |
| `VITE_OPENAI_API_KEY` | OpenAI API 키 | - | ❌ 선택 |
| `VITE_ENV` | 환경 구분 | development | ❌ 선택 |

**⚠️ 주의**: `.env` 파일은 `.gitignore`에 포함되어 있어 Git에 커밋되지 않습니다.

## 5. 개발 서버 실행

### 5.1 프론트엔드 서버 실행

현재 프로젝트는 **Vite 빌드 전용**으로 설정되어 있습니다.

개발 서버를 실행하려면 다음과 같이 `package.json`을 수정해야 합니다:

#### 5.1.1 package.json 수정

```json
{
  "scripts": {
    "dev": "vite",          // 추가
    "build": "vite build",
    "preview": "vite preview" // 추가 (선택)
  }
}
```

#### 5.1.2 개발 서버 시작

```bash
# 개발 서버 실행
npm run dev
```

#### 5.1.3 접속 확인

브라우저에서 다음 주소로 접속합니다:

```
http://localhost:5173
```

**성공 화면**: Landing Page가 표시됩니다.

### 5.2 백엔드 서버 실행 (선택 사항)

백엔드 API 서버가 준비된 경우:

```bash
# 백엔드 디렉토리로 이동
cd backend

# 가상환경 활성화 (Python)
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# FastAPI 서버 실행
uvicorn main:app --reload --port 8000
```

### 5.3 자동 새로고침

Vite는 **Hot Module Replacement (HMR)**를 지원합니다:

- ✅ 코드 수정 시 자동 새로고침
- ✅ 상태 유지 (State Preservation)
- ✅ 빠른 빌드 속도

## 6. 빌드 및 배포

### 6.1 프로덕션 빌드

```bash
# 프로덕션 빌드 실행
npm run build
```

빌드 결과물은 `/dist` 폴더에 생성됩니다.

### 6.2 빌드 결과 확인

```bash
# 빌드 결과 미리보기 (선택 사항)
npm run preview
```

```
http://localhost:4173
```

### 6.3 빌드 최적화

Vite는 자동으로 다음 최적화를 수행합니다:

- ✅ 코드 압축 (Minification)
- ✅ Tree Shaking (사용하지 않는 코드 제거)
- ✅ 청크 분할 (Code Splitting)
- ✅ 이미지 최적화

### 6.4 배포

빌드된 `/dist` 폴더를 서버에 배포합니다:

```bash
# 예시: AWS S3 배포
aws s3 sync dist/ s3://your-bucket-name/

# 예시: Netlify 배포
netlify deploy --prod --dir=dist

# 예시: Vercel 배포
vercel --prod
```

## 7. 트러블슈팅

### 7.1 일반적인 문제

#### 문제 1: `npm install` 실패

**증상**: 패키지 설치 중 오류 발생

**해결 방법**:
```bash
# npm 캐시 삭제
npm cache clean --force

# node_modules 삭제 후 재설치
rm -rf node_modules package-lock.json
npm install
```

#### 문제 2: 포트 충돌

**증상**: `EADDRINUSE: address already in use :::5173`

**해결 방법**:
```bash
# 포트 사용 중인 프로세스 종료 (Mac/Linux)
lsof -ti:5173 | xargs kill -9

# 또는 다른 포트로 실행
vite --port 3000
```

#### 문제 3: TypeScript 오류

**증상**: `Cannot find module` 또는 타입 오류

**해결 방법**:
```bash
# TypeScript 캐시 삭제
rm -rf node_modules/.vite

# 개발 서버 재시작
npm run dev
```

### 7.2 환경별 문제

#### Windows 사용자

**문제**: Git Bash에서 명령어 오류

**해결 방법**: PowerShell 또는 CMD 사용

```powershell
# PowerShell에서 실행
npm install
npm run dev
```

#### Mac 사용자

**문제**: Permission denied 오류

**해결 방법**:
```bash
# sudo 없이 npm 사용 설정
sudo chown -R $USER /usr/local/lib/node_modules
```

### 7.3 성능 문제

#### 문제: 빌드 속도 느림

**해결 방법**:
```bash
# Vite 캐시 삭제
rm -rf node_modules/.vite

# 재빌드
npm run build
```

#### 문제: 개발 서버 느림

**해결 방법**:
- VS Code에서 불필요한 확장 비활성화
- `node_modules` 폴더를 바이러스 검사 제외 목록에 추가
- 메모리 부족 시 Chrome 탭 정리
