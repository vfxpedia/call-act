# 📁 루트 폴더 문서 정리 가이드

> 루트 폴더에 있는 문서들을 `docs/archive` 폴더로 이동하는 방법

---

## 📋 이동할 파일 목록

루트 폴더(`/`)에 있는 다음 문서들을 `/docs/archive`로 이동합니다:

```
/ATTRIBUTIONS.md
/BACKEND_INTEGRATION.md
/FINAL_SUMMARY.md
/KEYWORD_DISPLAY_FIX.md
/KEYWORD_SYNC_AND_DIALOGUE_FIX.md
/REVIEW_REPORT.md
/SYNC_FIX_EXPLANATION.md
/TECHNICAL_ANSWERS.md
/TEMP_KEYWORD_MAP_SECTION.txt
```

---

## 🔧 이동 방법

### 방법 1: Git 명령어 사용 (권장)

```bash
# docs/archive 폴더로 이동
git mv ATTRIBUTIONS.md docs/archive/
git mv BACKEND_INTEGRATION.md docs/archive/
git mv FINAL_SUMMARY.md docs/archive/
git mv KEYWORD_DISPLAY_FIX.md docs/archive/
git mv KEYWORD_SYNC_AND_DIALOGUE_FIX.md docs/archive/
git mv REVIEW_REPORT.md docs/archive/
git mv SYNC_FIX_EXPLANATION.md docs/archive/
git mv TECHNICAL_ANSWERS.md docs/archive/
git mv TEMP_KEYWORD_MAP_SECTION.txt docs/archive/

# 변경사항 커밋
git add .
git commit -m "chore: 루트 폴더 문서들을 docs/archive로 이동"
```

**장점**: Git 히스토리가 유지됨

---

### 방법 2: 파일 탐색기 사용

#### Windows
1. 파일 탐색기에서 프로젝트 루트 폴더 열기
2. 위 목록의 파일들을 선택 (Ctrl 클릭)
3. 잘라내기 (Ctrl+X)
4. `docs/archive` 폴더로 이동
5. 붙여넣기 (Ctrl+V)

#### Mac
1. Finder에서 프로젝트 루트 폴더 열기
2. 위 목록의 파일들을 선택 (Cmd 클릭)
3. 잘라내기 (Cmd+X)
4. `docs/archive` 폴더로 이동
5. 붙여넣기 (Cmd+V)

---

### 방법 3: 터미널 명령어 (Linux/Mac)

```bash
# 프로젝트 루트로 이동
cd /path/to/call-act

# 파일 이동
mv ATTRIBUTIONS.md docs/archive/
mv BACKEND_INTEGRATION.md docs/archive/
mv FINAL_SUMMARY.md docs/archive/
mv KEYWORD_DISPLAY_FIX.md docs/archive/
mv KEYWORD_SYNC_AND_DIALOGUE_FIX.md docs/archive/
mv REVIEW_REPORT.md docs/archive/
mv SYNC_FIX_EXPLANATION.md docs/archive/
mv TECHNICAL_ANSWERS.md docs/archive/
mv TEMP_KEYWORD_MAP_SECTION.txt docs/archive/
```

## ✅ 이동 후 확인

### 1. 파일 존재 확인
```bash
# archive 폴더 확인
ls docs/archive/

# 예상 출력:
# ATTRIBUTIONS.md
# BACKEND_INTEGRATION.md
# FINAL_SUMMARY.md
# ...
```

### 2. 루트 폴더 정리 확인
```bash
# 루트 폴더에 .md 파일이 없는지 확인
ls *.md

# 예상 출력: (아무것도 없음)
# 또는 README.md만 있어야 함
```

### 3. Git 상태 확인
```bash
git status

# 예상 출력:
# renamed: ATTRIBUTIONS.md -> docs/archive/ATTRIBUTIONS.md
# renamed: BACKEND_INTEGRATION.md -> docs/archive/BACKEND_INTEGRATION.md
# ...
```

### 1. README.md 업데이트 (선택사항)

루트 폴더의 `README.md` 파일에 문서 위치 안내 추가:

```markdown
## 📚 문서

모든 프로젝트 문서는 `/docs` 폴더에 있습니다.

- **메인 문서**: `/docs`
- **아카이브 (히스토리)**: `/docs/archive`

자세한 내용은 [문서 네비게이션](/docs/00_README.md)을 참고하세요.
```

앞으로 루트 폴더에 임시 문서가 생기는 것을 방지:

```bash
# .gitignore에 추가
/*.md
!README.md
```

## ❓ FAQ

### Q1. 이동한 문서를 다시 참조해야 하는데 어디에 있나요?
**A:** `/docs/archive/` 폴더에서 찾을 수 있습니다.

### Q2. archive 폴더의 문서들은 삭제해도 되나요?
**A:** 권장하지 않습니다. 히스토리 참고용으로 보관하는 것이 좋습니다.

### Q3. Git 히스토리가 사라지지 않을까요?
**A:** `git mv` 명령을 사용하면 히스토리가 유지됩니다.
