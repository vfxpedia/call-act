### 프로세스 흐름:
1. 시나리오 선택 → Step 1의 키워드를 incomingKeywords에 설정
2. STT 대화 진행 → 단어 단위로 키워드 매칭 검사
3. 키워드 감지 → displayedKeywords에 추가
4. 첫 키워드 감지 → 칸반보드 표시 (isKeywordDetected = true)
5. 다음 Step 키워드 감지 → Step 전환 + incomingKeywords 업데이트
