### 1.3 Step 구조

각 시나리오는 **3개의 Step**으로 구성:

```
시나리오 1: 카드 분실
├── Step 1: 즉시 조치 (분실 신고, 긴급 정지)
├── Step 2: 재발급 절차 (재발급 신청, 배송)
└── Step 3: 사후 관리 (수령 확인, 활성화, 분실 보험)
```

### 1.4 카드 구성

각 Step은 **4개의 카드**로 구성:

```
Step 1: 즉시 조치
├── 카드 1: 현재 상황 - 즉시 카드 정지
├── 카드 2: 현재 상황 - 분실 신고 접수
├── 카드 3: 다음 단계 - 재발급 신청 방법
└── 카드 4: 다음 단계 - 배송 옵션 선택
```

## 2. 데이터 구조

### 2.1 TypeScript 인터페이스

#### 2.1.1 Scenario (시나리오)

```typescript
interface Scenario {
  id: string;                          // 시나리오 ID
  category: string;                    // 카테고리
  customer: CustomerInfo;              // 고객 정보
  recentConsultations: RecentConsultation[]; // 최근 상담 이력
  sttDialogue: ScenarioSTT[];          // STT 대화 내용
  steps: ScenarioStep[];               // 3개 Step
}
```

#### 2.1.2 CustomerInfo (고객 정보)

```typescript
interface CustomerInfo {
  id: string;                          // 고객 ID
  name: string;                        // 이름
  phone: string;                       // 전화번호
  cardNumber: string;                  // 카드 번호 (마스킹)
  cardType: string;                    // 카드 종류
  grade: string;                       // 등급 (VIP, Gold, Silver)
}
```

**예시**:
```typescript
customer: {
  id: 'CUST-20241215-001',
  name: '김민지',
  phone: '010-2345-6789',
  cardNumber: '1234-5678-****-****',
  cardType: '테디카드 프리미엄',
  grade: 'VIP'
}
```

#### 2.1.3 ScenarioSTT (대화 내용)

```typescript
interface ScenarioSTT {
  speaker: 'customer' | 'agent';       // 발화자
  message: string;                     // 대화 내용
  timestamp: number;                   // 통화 시작 후 몇 초
}
```

**예시**:
```typescript
sttDialogue: [
  { 
    speaker: 'agent', 
    message: '안녕하세요, 테디카드 상담센터입니다.', 
    timestamp: 1 
  },
  { 
    speaker: 'customer', 
    message: '카드를 잃어버렸어요!', 
    timestamp: 3 
  }
]
```

#### 2.1.4 ScenarioStep (Step)

```typescript
interface ScenarioStep {
  stepNumber: number;                  // Step 번호 (1, 2, 3)
  keywords: ScenarioKeyword[];         // 이 Step에서 등장하는 키워드
  currentSituationCards: ScenarioCard[]; // 현재 상황 카드 2개
  nextStepCards: ScenarioCard[];       // 다음 단계 카드 2개
  guidanceScript: string;              // 상담 안내 멘트
}
```

#### 2.1.5 ScenarioKeyword (키워드)

```typescript
interface ScenarioKeyword {
  text: string;                        // 키워드 텍스트
  appearTime: number;                  // 통화 시작 후 몇 초에 등장
}
```

**예시**:
```typescript
keywords: [
  { text: '카드분실', appearTime: 4 },
  { text: '긴급정지', appearTime: 7 },
  { text: '본인확인', appearTime: 10 }
]
```

#### 2.1.6 ScenarioCard (카드)

```typescript
interface ScenarioCard {
  id: string;                          // 카드 ID
  title: string;                       // 제목
  keywords: string[];                  // 관련 키워드
  content: string;                     // 요약 내용
  systemPath: string;                  // 시스템 경로
  requiredChecks: string[];            // 필수 확인 사항
  exceptions: string[];                // 예외 사항
  time: string;                        // 소요 시간
  note: string;                        // 주의사항
  regulation: string;                  // 근거 규정
  fullText: string;                    // 약관 형식 상세 내용
}
```

## 4. Step별 카드 구성

### 4.1 카드 구조

각 Step의 4개 카드는 다음과 같이 구성:

```
Step N
├── 카드 1: 현재 상황 (Primary)
├── 카드 2: 현재 상황 (Secondary)
├── 카드 3: 다음 단계 (Preview 1)
└── 카드 4: 다음 단계 (Preview 2)
```

### 4.2 카드 1 예시: 즉시 카드 정지

```typescript
{
  id: 'card-1-1-1',
  title: '즉시 카드 정지',
  keywords: ['카드분실', '긴급정지', '부정사용방지'],
  content: '고객님의 카드를 즉시 정지 처리하여 부정 사용을 방지합니다.',
  systemPath: '고객정보조회 > 카드관리 > 긴급정지',
  requiredChecks: [
    '본인 확인 (생년월일, 주소)',
    '카드 번호 뒷 4자리',
    '분실 일시 및 장소'
  ],
  exceptions: [
    '법인카드: 법인 담당자 승인 필요',
    '가족카드: 주카드 회원 동의 필요'
  ],
  time: '즉시',
  note: '정지 후에는 재활성화 불가',
  regulation: '여신전문금융업법 제16조',
  fullText: `
제1조 (카드 정지)
1. 카드 분실 신고 접수 즉시 해당 카드의 모든 사용이 정지됩니다.
2. 정지된 카드는 즉시 사용이 불가능하며, 재활성화할 수 없습니다.
3. 정지 처리는 시스템에 즉시 반영되며, 해외 가맹점도 포함됩니다.

제2조 (부정 사용 차단)
1. 정지 처리 후 발생한 거래는 모두 차단됩니다.
2. 정지 전 발생한 부정 거래는 분실 신고 시점 기준으로 책임 소재를 판단합니다.
3. 신고 접수 72시간 이내 부정 거래는 면책됩니다.

제3조 (본인 확인)
1. 카드 정지를 위해서는 본인 확인이 필수입니다.
2. 생년월일, 주소, 카드 번호 뒷 4자리를 확인합니다.
3. 본인 확인 실패 시 추가 인증 수단을 요청할 수 있습니다.

제4조 (법적 근거)
여신전문금융업법 제16조에 따라 회원의 분실 신고 시 즉시 정지 처리합니다.
  `
}
```

```
제1조 (카드 정지)

제2조 (부정 사용 차단)

2. 정지 전 발생한 부정 거래는 분실 신고 시점 기준으로 책임 소재를 판단합니다.

여신전문금융업법 제16조

#### 5.2.2 해외 사용 - 수수료

```
제1조 (해외 사용 수수료)

2. 수수료는 원화로 환산된 금액에 대해 적용됩니다.

제2조 (환율 적용)
1. 국제브랜드사(VISA, MasterCard) 기준 환율이 적용됩니다.
2. 환율은 매출 접수일 기준으로 적용되며, 결제일과 다를 수 있습니다.

제3조 (수수료 면제)
1. 프리미엄 등급 이상 회원은 연간 100만원까지 수수료 면제

## 6. 화면 연동

### 6.1 RealTimeConsultationPage

**데이터 흐름**:

```
SimulationPage
    ↓
시나리오 선택 (1~6)
    ↓
RealTimeConsultationPage로 전달
    ↓
시나리오 데이터 로드
    ↓
STT 시뮬레이션 시작
    ↓
키워드 자동 태깅
    ↓
Step 자동 전환
    ↓
칸반보드 카드 표시
```

### 6.2 키워드 태깅 로직

```typescript
// RealTimeConsultationPage.tsx
const currentScenario = scenarios[selectedScenarioIndex];
const currentStep = currentScenario.steps[currentStepIndex];

// STT 대화에서 키워드 추출
const processSTT = (message: string, timestamp: number) => {
  currentStep.keywords.forEach(kw => {
    if (timestamp >= kw.appearTime && message.includes(kw.text)) {
      // 키워드 태깅
      addKeyword(kw.text);
    }
  });
};
```

### 6.3 Step 자동 전환

```typescript
// Step 전환 조건: 현재 Step의 모든 키워드가 태깅되면
const checkStepTransition = () => {
  const currentKeywords = currentStep.keywords.map(k => k.text);
  const taggedKeywords = keywords.map(k => k.text);
  
  const allTagged = currentKeywords.every(k => 
    taggedKeywords.includes(k)
  );
  
  if (allTagged && currentStepIndex < 2) {
    // 다음 Step으로 전환 (슬라이딩 애니메이션)
    setCurrentStepIndex(prev => prev + 1);
  }
};
```

### 6.4 칸반보드 카드 표시
