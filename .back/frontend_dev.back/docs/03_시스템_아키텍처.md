### 1.2 레이어 구조

| 레이어 | 기술 스택 | 역할 |
|--------|-----------|------|
| **Presentation Layer** | React, Tailwind CSS | UI 렌더링, 사용자 인터랙션 |
| **Application Layer** | React Router, Context API | 라우팅, 상태 관리, 비즈니스 로직 |
| **API Layer** | FastAPI, WebSocket | REST API, 실시간 통신 |
| **Service Layer** | Python, OpenAI API | AI 추론, RAG 검색, STT 처리 |
| **Data Layer** | PostgreSQL, pgvector, Redis | 데이터 저장, 벡터 검색, 캐싱 |

## 4. 데이터 플로우

### 4.1 실시간 상담 플로우

```
1. 고객 전화 연결
   └─> STT 시작 (WebSocket 연결)

2. 음성 → 텍스트 변환
   └─> Backend: STT Service
       └─> 실시간 텍스트 전송 (WebSocket)

3. 키워드 추출
   └─> Frontend: wordQueueProcessor.ts
       └─> 단어 큐에 추가
       └─> 키워드 매칭 (단어 사전)

4. 키워드 태깅
   └─> Frontend: 키워드 목록 업데이트
       └─> 화면에 표시 (#0047AB 태그)

5. RAG 검색
   └─> Backend: RAG Service
       ├─> Embedding 생성 (OpenAI)
       ├─> pgvector 검색 (유사도 기반)
       └─> 관련 문서 반환 (Top 5)

6. 칸반보드 표시
   └─> Frontend: RealTimeConsultationPage
       ├─> Step별 카드 자동 배치
       ├─> 수평 슬라이딩 애니메이션
       └─> 카드 클릭 시 fullText 모달

7. Step 자동 전환
   └─> Frontend: 키워드 조건 충족 시
       └─> 우→좌 슬라이딩 애니메이션
       └─> 다음 Step으로 전환
```

### 4.2 AI 검색 어시스턴트 플로우

```
1. 상담사 질문 입력
   └─> Frontend: 검색창에 질문 입력

2. API 요청
   └─> Backend: /api/rag/search
       └─> Payload: { query: "질문 내용" }

3. RAG 검색
   └─> Backend: RAG Service
       ├─> Embedding 생성
       ├─> pgvector 검색
       └─> 컨텍스트 구성 (Top 3 문서)

4. GPT-4 답변 생성
   └─> Backend: OpenAI Service
       ├─> Prompt: "다음 문서를 참고하여 답변하세요"
       └─> GPT-4 API 호출

5. 답변 반환
   └─> Frontend: 답변 표시
       ├─> 답변 내용
       ├─> 출처 (Source) 문서
       └─> 신뢰도 점수
```

### 4.3 상담 후처리 플로우

```
1. 상담 종료
   └─> Frontend: "상담 종료" 버튼 클릭

2. ACW 페이지 이동
   └─> Frontend: /acw 페이지로 리다이렉트

3. AI 자동 요약
   └─> Backend: /api/consultation/summarize
       ├─> 전체 대화 내용 전송
       └─> GPT-4로 요약 생성

4. 유사 사례 검색
   └─> Backend: /api/consultation/similar
       ├─> 상담 내용 Embedding
       ├─> pgvector 검색
       └─> 유사 사례 Top 3 반환

5. 요약 편집 및 저장
   └─> Frontend: 요약 편집 가능
       └─> Backend: /api/consultation/save
           └─> PostgreSQL 저장
```

## 5. 통신 프로토콜

### 5.1 REST API

#### 5.1.1 인증

```
POST /api/auth/login
Body: { username, password }
Response: { token, user }
```

#### 5.1.2 상담

```
GET /api/consultation/history
Headers: { Authorization: Bearer <token> }
Response: { consultations: [...] }
```

### 5.2 WebSocket (STT)

#### 5.2.1 연결

```javascript
const ws = new WebSocket('ws://localhost:8000/ws/stt');

ws.onopen = () => {
  console.log('STT WebSocket 연결됨');
};
```

#### 5.2.2 메시지 형식

```json
// Client → Server (음성 데이터)
{
  "type": "audio",
  "data": "<base64-encoded-audio>"
}

// Server → Client (텍스트 결과)
{
  "type": "transcript",
  "text": "고객님 안녕하세요",
  "timestamp": 1704672000
}

// Server → Client (키워드)
{
  "type": "keyword",
  "keyword": "카드분실",
  "confidence": 0.95
}
```

## 6. 보안 아키텍처

### 6.1 인증 및 권한

#### 6.1.1 JWT 기반 인증

```
1. 로그인 → JWT 토큰 발급
2. 모든 API 요청 시 토큰 포함
3. 백엔드에서 토큰 검증
```

#### 6.1.2 역할 기반 접근 제어 (RBAC)

| 역할 | 권한 |
|------|------|
| **상담사** | 상담, 대시보드, 프로필 |
| **관리자** | 전체 + 사원 관리, 통계 |
| **개발자** | 전체 + 시뮬레이션 |

### 6.2 데이터 보안

- **HTTPS**: 모든 통신 암호화
- **WSS**: WebSocket Secure 사용
- **SQL Injection 방지**: Parameterized Query
- **XSS 방지**: React의 기본 Escaping
- **CSRF 방지**: Token 기반 인증

### 6.3 개인정보 보호

- 고객 개인정보는 암호화 저장
- 민감 정보는 마스킹 처리
- 로그에 개인정보 미포함
