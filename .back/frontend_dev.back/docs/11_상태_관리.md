## 1. 상태 관리 개요

### 1.1 현재 상태 관리 방식

CALL:ACT 프로젝트는 **3가지 상태 관리 방식**을 조합하여 사용합니다:

| 방식 | 용도 | 범위 | 영속성 |
|------|------|------|--------|
| **Context API** | 전역 UI 상태 | 전체 앱 | ❌ (세션) |
| **LocalStorage** | 사용자 데이터, 인증 | 전체 앱 | ✅ (영구) |
| **Component State** | 컴포넌트 로컬 상태 | 단일 컴포넌트 | ❌ (마운트) |

### 1.2 상태 관리 아키텍처

```
┌─────────────────────────────────────────────┐
│           Application State                 │
├─────────────────────────────────────────────┤
│                                             │
│  ┌──────────────┐  ┌──────────────┐       │
│  │   Context    │  │ LocalStorage │       │
│  │   API        │  │              │       │
│  ├──────────────┤  ├──────────────┤       │
│  │ - Sidebar    │  │ - user       │       │
│  │   상태       │  │ - employees  │       │
│  │ - UI 상태    │  │ - notices    │       │
│  │              │  │ - consultations│     │
│  └──────────────┘  └──────────────┘       │
│                                             │
│  ┌──────────────────────────────┐         │
│  │    Component State           │         │
│  ├──────────────────────────────┤         │
│  │ - Form inputs               │         │
│  │ - Modal open/close          │         │
│  │ - Loading states            │         │
│  │ - Temporary data            │         │
│  └──────────────────────────────┘         │
│                                             │
└─────────────────────────────────────────────┘
```

### 1.3 왜 Redux/Zustand를 사용하지 않는가?

**이유**:
1. **프로젝트 규모**: MVP 단계로 복잡한 상태 관리 불필요
2. **Context API 충분**: 전역 상태가 많지 않음 (현재 1개)
3. **LocalStorage 활용**: 대부분의 데이터는 LocalStorage로 관리 가능
4. **학습 곡선**: Context API가 더 간단하고 React 기본 기능

**향후 확장 시**: Redux Toolkit 또는 Zustand 도입 검토

## 2. Context API

### 2.1 SidebarContext

#### 2.1.1 개요

**경로**: `/src/app/contexts/SidebarContext.tsx`

**용도**: 사이드바 열림/닫힘 상태 관리

**범위**: 전체 애플리케이션

#### 2.1.2 Context 정의

```typescript
// SidebarContext.tsx
import { createContext, useContext, ReactNode, useState } from 'react';

interface SidebarContextType {
  isSidebarExpanded: boolean;              // 사이드바 펼침 여부
  setIsSidebarExpanded: (expanded: boolean) => void;
  isPinned: boolean;                       // 사이드바 고정 여부
  setIsPinned: (pinned: boolean) => void;
}

const SidebarContext = createContext<SidebarContextType>({ 
  isSidebarExpanded: false,
  setIsSidebarExpanded: () => {},
  isPinned: false,
  setIsPinned: () => {}
});

// 커스텀 훅
export const useSidebar = () => useContext(SidebarContext);
```

#### 2.1.3 Provider 구현

```typescript
// SidebarContext.tsx (계속)
interface SidebarProviderProps {
  children: ReactNode;
}

export function SidebarProvider({ children }: SidebarProviderProps) {
  const [isSidebarExpanded, setIsSidebarExpanded] = useState(false);
  const [isPinned, setIsPinned] = useState(false);
  
  return (
    <SidebarContext.Provider 
      value={{ 
        isSidebarExpanded, 
        setIsSidebarExpanded, 
        isPinned, 
        setIsPinned 
      }}
    >
      {children}
    </SidebarContext.Provider>
  );
}
```

### 2.2 Context API 작성 가이드

#### 2.2.1 새 Context 생성 템플릿

```typescript
// /src/app/contexts/MyContext.tsx
import { createContext, useContext, ReactNode, useState } from 'react';

// 1. Context 타입 정의
interface MyContextType {
  value: string;
  setValue: (value: string) => void;
}

// 2. Context 생성 (기본값 포함)
const MyContext = createContext<MyContextType>({ 
  value: '',
  setValue: () => {}
});

// 3. 커스텀 훅 (사용 편의성)
export const useMyContext = () => {
  const context = useContext(MyContext);
  if (!context) {
    throw new Error('useMyContext must be used within MyProvider');
  }
  return context;
};

// 4. Provider Props 타입
interface MyProviderProps {
  children: ReactNode;
}

// 5. Provider 컴포넌트
export function MyProvider({ children }: MyProviderProps) {
  const [value, setValue] = useState('');
  
  return (
    <MyContext.Provider value={{ value, setValue }}>
      {children}
    </MyContext.Provider>
  );
}
```

## 3. LocalStorage

### 3.1 LocalStorage 사용 개요

#### 3.1.1 저장되는 데이터

| 키 | 데이터 | 크기 | 용도 |
|-----|--------|------|------|
| `user` | 로그인 사용자 정보 | 1KB | 인증, 프로필 |
| `isLoggedIn` | 로그인 여부 | 10B | 인증 체크 |
| `employees` | 사원 데이터 (45명) | 20KB | 사원 관리 |
| `notices` | 공지사항 (15개) | 10KB | 공지 관리 |
| `consultations` | 상담 이력 (100+개) | 50KB | 상담 이력 |

**총 용량**: 약 80KB (LocalStorage 제한: 5-10MB)

#### 3.1.2 LocalStorage 초기화 (App.tsx)

```typescript
// App.tsx
import { employeesData } from '../data/mockData';

useEffect(() => {
  // 초기 데이터 로드
  const savedEmployees = localStorage.getItem('employees');
  if (!savedEmployees) {
    localStorage.setItem('employees', JSON.stringify(employeesData));
    console.log('✅ Initial employee data loaded to LocalStorage');
  }
}, []);
```

### 3.2 LocalStorage 패턴

#### 3.2.1 데이터 읽기

```typescript
// 기본 읽기
const user = JSON.parse(localStorage.getItem('user') || '{}');

  console.error('Failed to parse employees', error);
  employees = employeesData; // Fallback
```

```typescript
// 기본 쓰기

localStorage.setItem('employees', JSON.stringify(updatedEmployees));
```

### 3.3 LocalStorage Hook (커스텀)

#### 3.3.1 useLocalStorage Hook

```typescript
// /src/app/hooks/useLocalStorage.ts
import { useState, useEffect } from 'react';

export function useLocalStorage<T>(key: string, initialValue: T) {
  // State to store our value
  const [storedValue, setStoredValue] = useState<T>(() => {
    try {
      const item = window.localStorage.getItem(key);
      return item ? JSON.parse(item) : initialValue;
    } catch (error) {
      console.error(error);
      return initialValue;
    }
  });

  // Return a wrapped version of useState's setter function that ...
  // ... persists the new value to localStorage.
  const setValue = (value: T | ((val: T) => T)) => {
    try {
      // Allow value to be a function so we have same API as useState
      const valueToStore = value instanceof Function ? value(storedValue) : value;
      
      // Save state
      setStoredValue(valueToStore);
      
      // Save to local storage
      window.localStorage.setItem(key, JSON.stringify(valueToStore));
    } catch (error) {
      console.error(error);
    }
  };

  return [storedValue, setValue] as const;
}
```

#### 3.3.2 사용 예시

```tsx
// EmployeesPage.tsx
import { useLocalStorage } from '../hooks/useLocalStorage';

function EmployeesPage() {
  const [employees, setEmployees] = useLocalStorage('employees', []);
  
  const handleAddEmployee = (newEmployee: Employee) => {
    setEmployees(prev => [...prev, newEmployee]);
    // LocalStorage에 자동 저장됨!
  };
  
  return (
    <div>
      {employees.map(emp => <div key={emp.id}>{emp.name}</div>)}
    </div>
  );
}
```

### 3.4 LocalStorage 주의사항

#### 3.4.1 보안

**⚠️ 주의**: LocalStorage는 XSS 공격에 취약합니다.

```typescript
// ❌ 나쁜 예: 민감 정보를 LocalStorage에 저장
localStorage.setItem('password', 'mypassword123');
localStorage.setItem('creditCard', '1234-5678-9012-3456');

// ✅ 좋은 예: 토큰만 저장 (서버에서 검증)
localStorage.setItem('token', 'jwt-token-here');

// ✅ 더 좋은 예: HttpOnly 쿠키 사용 (백엔드 연동 시)
// 쿠키는 JavaScript에서 접근 불가 → XSS 방어
```

#### 3.4.2 용량 제한

**제한**: 5-10MB (브라우저마다 다름)

```typescript
// 용량 초과 시 에러 처리
try {
  localStorage.setItem('largeData', JSON.stringify(veryLargeArray));
} catch (error) {
  if (error.name === 'QuotaExceededError') {
    console.error('LocalStorage 용량 초과');
    // 오래된 데이터 삭제 또는 서버로 전송
  }
}
```

#### 3.4.3 동기 API

**문제**: LocalStorage는 동기(Synchronous) API → 메인 스레드 블로킹

**해결**: 큰 데이터는 IndexedDB 사용 또는 서버로 전송

```typescript
// ❌ 나쁜 예: 매우 큰 데이터를 LocalStorage에 저장
const hugeData = /* 5MB 데이터 */;
localStorage.setItem('hugeData', JSON.stringify(hugeData)); // 메인 스레드 블로킹!

// ✅ 좋은 예: 서버로 전송
await fetch('/api/data', {
  method: 'POST',
  body: JSON.stringify(hugeData)
});
```

### 4.2 useEffect Hook

#### 4.2.1 기본 사용

```tsx
import { useEffect } from 'react';

function MyComponent() {
  const [data, setData] = useState(null);

  }, []);
```

## 5. 상태 관리 패턴

### 5.1 Lifting State Up (상태 끌어올리기)

#### 5.1.1 문제 상황

```tsx
// ❌ 나쁜 예: 각 컴포넌트가 독립적인 상태
function ComponentA() {
  const [value, setValue] = useState('');
  return <input value={value} onChange={e => setValue(e.target.value)} />;
}

function ComponentB() {
  const [value, setValue] = useState('');
  return <p>{value}</p>; // ComponentA의 value를 표시할 수 없음!
}
```

#### 5.1.2 해결 방법

```tsx
// ✅ 좋은 예: 부모 컴포넌트로 상태 끌어올리기
function Parent() {
  const [value, setValue] = useState('');
  
  return (
    <div>
      <ComponentA value={value} onChange={setValue} />
      <ComponentB value={value} />
    </div>
  );
}

function ComponentA({ value, onChange }) {
  return <input value={value} onChange={e => onChange(e.target.value)} />;
}

function ComponentB({ value }) {
  return <p>{value}</p>;
}
```

### 5.2 Prop Drilling 해결

#### 5.2.1 문제 상황

```tsx
// ❌ Prop Drilling: 중간 컴포넌트들이 불필요하게 props 전달
function App() {
  const [user, setUser] = useState({ name: 'John' });
  
  return <Level1 user={user} />;
}

function Level1({ user }) {
  return <Level2 user={user} />; // Level1은 user를 사용하지 않음
}

function Level2({ user }) {
  return <Level3 user={user} />; // Level2도 user를 사용하지 않음
}

function Level3({ user }) {
  return <p>{user.name}</p>; // 여기서만 사용!
}
```

#### 5.2.2 해결 방법: Context API

```tsx
// ✅ Context API로 해결
const UserContext = createContext();

function App() {
  const [user, setUser] = useState({ name: 'John' });
  
  return (
    <UserContext.Provider value={user}>
      <Level1 />
    </UserContext.Provider>
  );
}

function Level1() {
  return <Level2 />; // props 전달 불필요
}

function Level2() {
  return <Level3 />; // props 전달 불필요
}

function Level3() {
  const user = useContext(UserContext); // 바로 접근!
  return <p>{user.name}</p>;
}
```

### 5.3 복잡한 상태: useReducer

#### 5.3.1 useReducer vs useState

```tsx
// useState: 간단한 상태
const [count, setCount] = useState(0);

// useReducer: 복잡한 상태 로직
import { useReducer } from 'react';

interface State {
  count: number;
  loading: boolean;
  error: string | null;
}

type Action = 
  | { type: 'increment' }
  | { type: 'decrement' }
  | { type: 'setLoading'; payload: boolean }
  | { type: 'setError'; payload: string };

function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'increment':
      return { ...state, count: state.count + 1 };
    case 'decrement':
      return { ...state, count: state.count - 1 };
    case 'setLoading':
      return { ...state, loading: action.payload };
    case 'setError':
      return { ...state, error: action.payload };
    default:
      return state;
  }
}

function Counter() {
  const [state, dispatch] = useReducer(reducer, {
    count: 0,
    loading: false,
    error: null
  });
  
  return (
    <div>
      <p>Count: {state.count}</p>
      <button onClick={() => dispatch({ type: 'increment' })}>+</button>
      <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
    </div>
  );
}
```

```tsx
useEffect(() => {
  const data = JSON.parse(localStorage.getItem('employees') || '[]');
  setEmployees(data);
  setLoading(false);
}, []);
```

#### 6.1.2 React Query 도입 (향후)

```tsx

import { useQuery, useMutation } from '@tanstack/react-query';

function EmployeesPage() {
  const { data: employees, isLoading, error } = useQuery({
    queryKey: ['employees'],
    queryFn: async () => {
      const response = await fetch('/api/employees');
      return response.json();
    }
  });
  
  const mutation = useMutation({
    mutationFn: (newEmployee) => {
      return fetch('/api/employees', {
        method: 'POST',
        body: JSON.stringify(newEmployee)
      });
    },
    onSuccess: () => {
      queryClient.invalidateQueries(['employees']);
    }
  });
  
  if (isLoading) return <div>Loading...</div>;
  if (error) return <div>Error: {error.message}</div>;
  
  return (
    <div>
      {employees.map(emp => <div key={emp.id}>{emp.name}</div>)}
    </div>
  );
}
```

#### 6.2.1 Zustand 도입 (향후)

```typescript
// store.ts
import { create } from 'zustand';

interface StoreState {
  user: User | null;
  employees: Employee[];
  setUser: (user: User) => void;
  setEmployees: (employees: Employee[]) => void;
  addEmployee: (employee: Employee) => void;
}

export const useStore = create<StoreState>((set) => ({
  user: null,
  employees: [],
  setUser: (user) => set({ user }),
  setEmployees: (employees) => set({ employees }),
  addEmployee: (employee) => set((state) => ({ 
    employees: [...state.employees, employee] 
  }))
}));
```
