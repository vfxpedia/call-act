# 선불카드 사용기간

- 선불카드 지원금의 사용기간은 카드유효기간(5년)과 별도로 인천광역시의 정책에 따라 정해지며, 인천광역시가 발행하는 별도의 안내자료에 표기됩니다.
- 사용기간 내 사용하지 못한 잔액은 환불 불가하며 인천광역시로 일괄 귀속됩니다.
- 사용기간이 경과한 카드는 사용이 불가합니다.

# 사용처 · 사용 불가시간

- 사용 업종 : 지자체가 지정한 아동급식 가맹점에서 사용 가능하며, 상세 안내는 해당 지자체로 문의 바랍니다.(편의점, 한식, 중식, 일식, 양식, 제과점, 패스트푸드, 일반대중음식 등)

- 사용 불가시간 : 24시~06:00 (매일 24시부터 익일 오전 6시까지는 선불카드 사용이 불가합니다.)
