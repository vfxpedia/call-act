# 긴급생활지원금

# 신한 선불카드

# 안내 및 유의사항

1. 상기 서비스의 내용은 2022년 6월 기준입니다.
2. 선불카드 사용기간은 22년 12월 31일까지이며, 사용기한 경과한 후 선불카드는 사용할 수 없습니다. (사용기한은 카드표면 상 표기됨, 2022년 12월 31일까지입니다)
3. 사용기간 내 사용하지 못한 잔액 · 승인 · 매입취소 · 환급금액 등은 환불 불가하며 해당 지지체로 일괄 귀속됩니다.
4. 카드표면에 표기된 유효기간은 잔액조회 등의 거래를 위하여 기재하여 교부합니다.
5. 선불카드의 사용처에서 유흥 · 사행성 업종 등 생활안정지원정책과 무관한 업종의 가맹점에서 사용이 제한됩니다.
6. 단, 선불카드 특성상 취급에 어려움이 있는 무승인거래 등은 사용이 불가합니다.

# 4. 지원(충전)금액

급여자격별, 가구원수별 차등 지급

# 5. 사용처

사용지역 제한은 지자체의 정책에 따릅니다.

※ 상세안내는 “지자체 안내장을 참고하시거나” 해당 지자체로 문의바랍니다.

# 6. 카드 분실/도난 대응

- ‘소지자정보 등록’ 을 하지 않은 경우
카드를 수령한 동주민센터(업무시간 限 가능)에 방문하여 카드 재발급 요청
- 발급대상: 보건복지부 지급대상 기준을 충족하는 가구의 가구원 등
- 발급유형: 개인
- 발급구분: 무기명 선불카드

# 7. 카드 소지자 정보 등록 안내

• 소지자정보등록의 장점

1. 소득공제 가능
2. ‘잔액알림SMS신청’ 가능(소지자정보 등록 진행단계에서 신청가능)
3. 카드 분실 시 신한카드 ARS를 통한 분실 및 도난 등록 가능

# • 신청방법

1. 신한카드홈페이지 : 혜택 > 정부지원사업 > 한시 긴급생활지원금 > 기프트(선불)카드 소지자정보등록
(본인 확인 수단 : 개인/본인명의 휴대폰 필요)
2. 신한은행 영업점/신한카드 지점 : 기프트카드 소지자정보 등록 업무 요청
(카드 및 신분증 필요)

# 8. 잔액 및 이용내역 조회 방법

1. 신한카드홈페이지 : 혜택 > 정부지원사업 > 신한선불카드 > 기프트(선불)카드 잔액조회, 내역(카드번호, 유효기간, CVC번호 입력 필요)
2. ARS(1544-7500) : 3. 신한기프트카드이용 > 2. 잔액조회/4. 사용내역조회(카드번호, CVC번호 입력 필요)
