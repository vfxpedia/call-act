# 선불카드 개요

• 국민기초생활보장법 제2조제2호에 따른 수급자나 한부모가족지원법 제5조에 따른 보호대상자 아동 및 저소득층에 해당되는 아동 중에서 결식우려가 있는 아동을 대상으로 발급되는 급식 지원금 지급 전용 선불카드를 말합니다.

• 간편결제 불가

• 실시간 승인절차를 거치치 않는 가맹점 : 전화승인/Key-in 승인/수기전표작성/무승인 직가맹점(공중전화, 비행기 기내판매, 자동차구매, 자판기, 주차장 등)

• 외환(달러 등) 결제 가맹점

• 통신요금 납부 결제 가맹점

• 취소 시 수수료 부과되는 예매가맹점(영화/철도/고속버스 예매 등)

• 부분 취소 가능(항공권)/할부전용 가맹점

# 신청방법

• 주민센터(읍면동)에 본인(또는 대리인)이 방문하여 신청 가능합니다.

# 지원금액

• 선불카드 지원(충전)금액은 지자체의 급식비 지원 정책 기준에 따릅니다.

# 사용처 · 사용 불가시간

• 사용 업종 : 지자체가 지정한 아동급식 가맹점에서 사용 가능하며, 상세 안내는 해당 지자체로 문의 바랍니다.(편의점, 한식, 중식, 일식, 양식, 제과점, 패스트푸드, 일반대중음식 등)

• 사용 불가 업종 : 유흥업소, 사행성 업소 등 지자체가 아동급식 지원금 사용에 부적합하다고 판단한 업소

• 사용 불가시간 : 23:00 ~ 06:00
