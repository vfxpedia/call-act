# Gift 서비스

Weverse 신한카드(신용)는 매년 1회 Weverse가 선정한 Weverse 공식상품(굿즈)이 제공됩니다.

- 카드발급 초년도의 경우, Weverse 공식상품은 발급하신 아티스트의 소장용 카드 Plate로 제공됩니다.
- 카드 발급 2차년도 이후의 경우, Weverse 공식상품은 연회비 납부월 다음달 초부터 Weverse 앱 내의 Weverse Shop 탭을 통해 신청 가능하며, 신청 시 원하시는 주소를 입력하시면 해당 주소로 배송됩니다.
- Gift 서비스는 연회비 납부월 익월부터 익년도 연회비 청구 당월말까지 1년간 신청 가능하며, 신청기간이 경과한 미사용건에 대해서는 소급 신청이 불가합니다.
- 제휴사의 사정(라이선스, 아티스트 또는 그룹 해체 등)으로 공식상품 제공이 불가한 경우 연회비 납부월 익월 초 신한카드에 등록된 고객님의 휴대폰번호로 1만 5천원 상당의 모바일 기프트가 제공됩니다.
