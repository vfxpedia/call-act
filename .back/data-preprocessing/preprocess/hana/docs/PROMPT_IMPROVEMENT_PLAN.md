# LLM 프롬프트 개선 방안

## 현재 문제점

1. **하드코딩된 규칙**: 고정된 규칙만 제공하여 유연성 부족
2. **카테고리 무시**: 카테고리 정보만 전달하고 특화 가이드 없음
3. **예시 부족**: 완성된 시나리오 예시를 참고하지 않음
4. **컨텍스트 미분석**: 입력 텍스트의 문맥을 충분히 분석하지 않음

## 구체적 문제 사례

### test_scenario_20624.txt (연회비 안내)
- 원본: `[금액#1]`, `[금액#2]`, `[금액#3]`, `[금액#4]`, `[금액#5]`, `[금액#6]` 모두 다른 번호
- 문맥상: `[금액#1]`과 `[금액#4]`는 같은 값 (기본 연회비)
- 결과: "15만원", "30만원", "50만원" 등 모두 다른 값으로 치환 (비현실적)
- 문제: 연회비가 15만원은 비현실적 (일반적으로 1-5만원)

### test_scenario_20624.txt:35-36
- 원본: `[카드상품명#2]` 태그가 그대로 남음
- 결과: "제이든 15만원 30만원" 같은 이상한 표현

3. **품질 향상**: 자연스러운 표현, 교육용 시나리오 적합성
