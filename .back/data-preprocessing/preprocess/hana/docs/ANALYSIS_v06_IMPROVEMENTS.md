# v06 시나리오 분석 및 개선안

## 분석 결과

### 개선된 부분
1. **학생명 처리**: v05의 "서울고등학교 학생명 홍길동" → v06의 "서울고등학교 홍길동" (자연스럽게 개선됨)
2. **전화번호 구성요소**: 대부분 자연스럽게 조합됨
3. **금액 다양성**: 대부분 다른 번호에 다른 금액 사용

### 발견된 문제점

#### 1. 서비스업체명 태그 미치환
- **위치**: `test_scenario_22272.txt:37`, `test_scenario_20638.txt:26`
- **문제**: "[서비스업체명#1]" → "서비스업체명" (태그만 제거되고 실제 서비스명으로 치환 안 됨)
- **기대**: "하나페이" 또는 "하나카드 앱" 등 실제 서비스명으로 치환
- **영향**: 교육용 시나리오로 부적절

#### 2. 문맥상 이상한 금액 질문
- **위치**: `test_scenario_20696.txt:18-20`
- **문제**: "15만원은 뭐예요?", "30만원이요?", "50만원은 뭐예요?" - 문맥상 어색함
- **원인**: 원본 데이터의 태깅 문제 또는 LLM의 문맥 파악 부족
- **기대**: 문맥에 맞게 수정 (예: "이 기능은 뭐예요?" 또는 태그 제거)

#### 3. 상담원명 다양성 부족
- **문제**: 대부분 "김민정"으로 통일됨
- **기대**: 시나리오마다 다른 상담원명 사용 (김민정, 이수진, 박지현 등)

## 개선 방안

### 1. LLM 프롬프트 개선
```python
# 추가할 내용:
- [서비스업체명#N]: 실제 서비스명으로 치환
  - 하나카드 관련: "하나페이", "하나카드 앱", "하나카드 앱카드" 등
  - 다른 카드사: "삼성페이", "신한페이" 등 (문맥에 맞게)
  - **절대 "서비스업체명" 그대로 두지 말 것**

- [상담원명#N]: **각 시나리오마다 다른 이름 사용**
  - 시나리오 1: 김민정
  - 시나리오 2: 이수진
  - 시나리오 3: 박지현
  - (다양한 이름 풀에서 랜덤 선택)

- 문맥상 이상한 태그 자동 감지 강화:
  - "[금액#N]은 뭐예요?" → 문맥상 금액 질문이 어색하면 태그 제거하고 자연스러운 표현 사용
  - 예: "이 기능은 뭐예요?", "이 카드는 뭐예요?" 등
```

### 2. 버전 관리 개선 방안

#### 현재 문제점
- 중단 후 재실행 시 버전이 계속 올라감 (v01 → v02 → v03...)
- 미완성 버전이 남아서 지저분함

#### 제안 방안

**방안 A: 미완성 버전 자동 감지 및 재사용 (추천)**
- `generation_summary.json`을 확인하여 완료 여부 체크
- `success_count < total_targets`이면 미완성으로 판단
- 미완성 버전 발견 시:
  - 옵션 1: 자동으로 해당 버전 재사용 (이어서 생성)
  - 옵션 2: 사용자에게 물어보기 (재사용/새 버전/삭제 후 재시작)

**방안 B: 명령줄 옵션 추가**
```bash
# 미완성 버전 재사용
python generate_scenarios.py --resume

# 미완성 버전 삭제 후 새로 시작
python generate_scenarios.py --restart

# 특정 버전 지정
python generate_scenarios.py --version=5
```

**방안 C: 완료된 버전만 유지**
- 완료된 버전만 남기고 미완성 버전은 자동 삭제
- 또는 `.incomplete` 접미사 추가 (예: `scenarios_llm_v05.incomplete`)

**방안 D: 타임스탬프 기반 버전**
- 버전 번호 대신 타임스탬프 사용
- 예: `scenarios_llm_20260107_021500`
- 장점: 중복 걱정 없음
- 단점: 버전 순서 파악 어려움

#### 추천 구현: 방안 A + B 조합
1. 실행 시 미완성 버전 자동 감지
2. 미완성 버전이 있으면:
   - `--resume` 옵션이 있으면 자동 재사용
   - 옵션이 없으면 사용자에게 선택권 제공
3. 완료된 버전은 그대로 유지

## 구현 우선순위

1. **높음**: 서비스업체명 치환 개선
2. **높음**: 상담원명 다양성 확보
3. **중간**: 문맥상 이상한 태그 자동 감지 강화
4. **중간**: 버전 관리 개선 (방안 A 구현)
